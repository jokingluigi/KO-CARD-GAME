현재 KO 카드게임의 개발/테스트용 계정에
"전체 카드/챔피언 해금 + 무제한 프리즘 + 무제한 상점 골드"
기능을 추가해줘.

중요:
오직 기존 TEST USER 같은 전용 테스트 계정에만 적용한다.

일반 User / 실제 운영 계정에는 절대 적용하지 마.

==================================================
1. 테스트 계정 전용
==================================================

기존 Test Auth Helper의 TEST USER를 사용하거나
서버에서 명확하게 식별되는 test account를 사용해.

예:

isTestAccount === true

또는 개발환경 전용 Test User ID.

클라이언트가 임의로 이 값을 설정할 수 없게 해.

Production에서는 이 기능이 절대 활성화되면 안 된다.

==================================================
2. 모든 카드 사용 가능
==================================================

TEST USER는 현재 존재하는 모든:

PUBLISHED CardDefinition

을 소유한 것으로 처리해.

단 반드시 제외:

- isToken === true
- isChampionToken === true

즉 Token류는 테스트 계정이라도
Deck에 직접 넣을 수 없어야 한다.

NORMAL / LEGENDARY 등
일반적으로 덱 편성 가능한 카드는 모두 사용 가능.

==================================================
3. 새 카드 자동 포함
==================================================

매번 테스트 계정 DB에 카드를 수동 지급하지 않아도 되게 해.

앞으로 새로운 PUBLISHED 카드가 추가되면
TEST USER가 자동으로 소유한 것으로 인식되게 해.

카드 이름 하드코딩 금지.

가능하면 테스트 계정 ownership resolver에서:

isTestAccount
→ 모든 eligible PUBLISHED CardDefinition owned

방식으로 처리.

==================================================
4. 카드 수량
==================================================

TEST USER에서는 Deck 테스트를 위해
eligible 카드의 소유 수량이 부족해서
편성이 막히지 않게 해.

테스트 계정에 한해서:

UNLIMITED

또는 충분히 큰 virtual quantity로 처리 가능.

실제 UserCardCollection 경제 규칙은 수정하지 마.

==================================================
5. 모든 Champion 해금
==================================================

TEST USER는 모든:

PUBLISHED ChampionDefinition

을 해금한 것으로 처리해.

새 Champion이 추가되어 PUBLISHED되면
자동으로 TEST USER가 사용할 수 있어야 한다.

Champion Token CardDefinition을
Champion 해금으로 착각하지 마.

==================================================
6. 무제한 프리즘
==================================================

TEST USER의 Prism은 테스트 환경에서:

UNLIMITED

로 처리해.

UI에는 예를 들어:

프리즘 ∞

또는

무제한

으로 표시 가능.

카드 제작 시 Prism 부족 검사를
TEST USER에 한해서 통과시킨다.

중요:
실제 DB에 거대한 숫자를 계속 더하는 방식보다
테스트 계정 전용 unlimited flag/override를 사용해.

일반 User의 Prism 시스템은 그대로 유지.

==================================================
7. 무제한 상점 골드
==================================================

TEST USER의 상점용 계정 재화도:

UNLIMITED

로 처리해.

UI:

골드 ∞

또는
무제한

표시 가능.

Shop 구매 시 TEST USER는
골드 부족으로 구매가 막히지 않게 해.

구매한 Pack은 기존 UserPackInventory에
정상적으로 추가되어야 한다.

==================================================
8. 전투 Gold와 절대 혼동 금지
==================================================

매우 중요:

무제한 Gold는
계정/상점 재화에만 적용한다.

게임 Match 내부 Gold:

1 → 2 → 3 → 4 → 5 → 6

규칙은 그대로 유지.

TEST USER라고 해서
매치 중 무한 Gold를 얻으면 안 된다.

==================================================
9. 실제 시스템 테스트 가능해야 함
==================================================

TEST USER라도:

- Pack 구매
- Pack Inventory 증가
- Pack Opening
- Collection
- Deck
- Prism 제작
- Card Skin
- AI Match

등 실제 시스템 흐름은 그대로 사용해야 한다.

테스트 계정이라는 이유로
게임 기능 자체를 우회하지 마.

단 소유권/경제 자원 제한만 테스트 편의를 위해 해제.

==================================================
10. Admin/Test UI 표시
==================================================

테스트 계정으로 로그인했을 때
작게:

TEST ACCOUNT

표시를 추가해도 된다.

예:

TEST ACCOUNT
모든 카드/챔피언 사용 가능
프리즘 ∞
골드 ∞

일반 User에게는 표시하지 마.

==================================================
11. 보안
==================================================

절대 하지 말 것:

- 모든 User에게 전체 카드 지급
- 일반 User가 isTestAccount 설정
- Production에서 Test Economy 활성화
- Token / Champion Token Deck 사용 허용
- Match Gold 무한화
- 실제 경제 설정 변경

가능하면:

NODE_ENV !== "production"
AND
ENABLE_TEST_AUTH === "true"

환경에서만 동작하게 해.

==================================================
12. 테스트
==================================================

TEST USER로 확인:

- 모든 PUBLISHED 일반 카드 표시
- Token 표시 안 됨
- Champion Token 표시 안 됨
- 모든 PUBLISHED Champion 선택 가능
- 새 PUBLISHED 카드도 자동 사용 가능
- Prism ∞
- 상점 Gold ∞
- Prism 제작 가능
- Shop Pack 구매 가능
- 구매 시 Pack Inventory 정상 증가
- Deck 정상 저장
- Match 내부 Gold는 정상 1~6 규칙 유지

일반 User로 확인:

- 기존 Collection 소유권 그대로
- 기존 Prism 잔액 그대로
- 기존 Gold 잔액 그대로
- 미소유 카드/Champion 사용 불가

Production 환경:

- TEST unlimited 기능 사용 불가

==================================================
최종 목표
==================================================

TEST USER:

모든 PUBLISHED NON-TOKEN 카드
→ 무제한 사용

모든 PUBLISHED Champion
→ 해금

Prism
→ ∞

상점 Gold
→ ∞

단:

Token / Champion Token 직접 편성 금지
Match Gold는 기존 규칙 유지

일반 User와 Production 경제 시스템은
절대 변경하지 마.
