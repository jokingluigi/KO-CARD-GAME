==================================================
이번 작업에서 반드시 수정할 버그
==================================================

우선순위 P0:

1. 판도라 Champion Ability가 아군 WRESTLER도 대상으로 선택 가능해야 함.
2. 판도라 Ability로 아군에게 실제 DAMAGE 가능해야 함.
3. 그 피해로 HP <= 0이면 정상 RETIRE.
4. 판도라 Quest 조건에 해당하면 0/5 → 1/5 증가해야 함.
5. 판도라 Quest 완료 시 reward까지 정상 작동.
6. 예거 능력 사용 후 END_TURN 불가능 문제.
7. Online에서 상대 턴 종료 후 내 턴으로 넘어오지 않는 문제.
8. timeout 시 필드 카드가 손으로 튕기는 문제.
9. AI Match 패배 시 Champion HP 1로 되살아나는 문제.
10. Online Quick/Friendly 선택 화면에서 Main으로 돌아갈 수 없는 문제.

실제 게임 테스트가 완료 조건
==================================================

실제 Match 시작
→ 판도라 능력 사용
→ 내 용병 선택
→ DAMAGE
→ RETIRE
→ Quest UI 확인

반드시:

0/5
→ 1/5

을 직접 확인.

예거:

능력 사용
→ END_TURN 클릭
→ 실제 다음 턴 진행

Online:

상대 END_TURN
→ 내 클라이언트가 내 턴으로 전환

Timeout:

필드 카드 before/after 확인
→ 손으로 이동하지 않음

AI 패배:

HP <= 0
→ match FINISHED
→ HP 1로 복원되지 않음

Main navigation:

Main
→ Online
→ Quick/Friendly 선택
→ Back/Main
→ Main 화면 실제 도착

==================================================
테스트 게임 방식
==================================================

한 판을 처음부터 끝까지 길게 플레이할 필요는 없다.

가능하면 fixture/test scenario를 이용해서
버그 발생 직전 상태를 빠르게 만들어라.

하지만 최종 확인은 실제 game runtime/browser에서 한다.

각 항목은:

REPRODUCED
→ FIXED
→ GAMEPLAY VERIFIED

순서로 확인.

==================================================
PASS 판정
==================================================

PASS:
실제 browser/gameplay에서 고친 결과 확인.

FAIL:
재현되지만 아직 고치지 못함.

UNVERIFIED:
실제 게임에서 확인하지 못함.

코드상 정상/테스트 통과만으로 PASS 금지.
