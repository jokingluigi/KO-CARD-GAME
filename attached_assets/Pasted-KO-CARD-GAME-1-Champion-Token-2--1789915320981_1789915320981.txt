KO CARD GAME 중요 규칙 변경 패치를 적용해줘.

이번 작업의 핵심은 두 가지다.

1. Champion Token 규칙 일부 약화
2. 기존 게임 키워드 "태그" 제거

주의:
이번에 새로 추가한 cards.tags 메타데이터 시스템은 유지한다.
Production DB / Supabase / 실제 사용자 데이터는 수정하지 말고
개발 코드, 개발 DB, 테스트만 수정한다.

==================================================
1. Champion Token 규칙 변경
==================================================

기존 Champion Token 시스템에서 다음 두 규칙을 제거한다.

----------------------------------------
A. 원본 Champion HP 합산 제거
----------------------------------------

기존에는 Champion Token을 deploy할 때
원본 Champion의 현재/최대 HP를 Token HP에 더하는 처리가 있었다.

이 규칙을 완전히 제거한다.

Champion Token은 자신의 CardDefinition에 적힌
기본 공격력/체력만 사용한다.

예:

챔피언 판도라(폭주)
Attack 6
Health 10

원본 Champion HP가 13이어도 deploy 결과:

6 / 10

이어야 한다.

절대로:

6 / 23

같은 식으로 HP를 합산하면 안 된다.

원본 Champion HP는 Token deploy 전 값 그대로 보존한다.

----------------------------------------
B. Champion Token RETIRE → 즉시 패배 제거
----------------------------------------

기존에는 활성 Champion Token이 RETIRE되면
소유자가 즉시 게임에서 패배했다.

이 규칙을 제거한다.

Champion Token이 일반 피해/전투로 HP 0 이하가 되어
RETIRE되어도 게임 패배가 발생하면 안 된다.

정상적인 RETIRE로 처리한다.

- graveyard 이동
- 관련 RETIRE Event
- active Champion Token 상태 해제

를 정상 처리한다.

==================================================
2. Champion Token 보호 규칙은 유지
==================================================

Champion Token이 정상적인 Champion deploy 경로로
활성화되어 필드에 존재하는 동안:

- 원본 Champion은 보호 상태 유지
- 원본 Champion은 일반 target 후보에서 제외
- 원본 Champion은 damage/effect target 불가
- 원본 Champion ability는 계속 사용 가능

이 기존 규칙은 유지한다.

단 Champion Token이 필드에서 사라지면:

- active Champion Token 상태 종료
- 원본 Champion 보호 해제
- 원본 Champion 다시 target 가능
- 원본 Champion 다시 damage/effect 대상 가능

원본 Champion HP는 Token deploy 전의 값 그대로 유지한다.

Champion Token이:

- RETIRE
- DESTROY가 실제로 허용되는 경우
- REMOVE_FROM_GAME이 실제로 허용되는 경우
- 기타 정상적인 field leave

등으로 필드를 떠났을 때도
active 상태가 stale하게 남으면 안 된다.

단 아래 즉사 면역 규칙과 충돌하지 않게 처리한다.

==================================================
3. Champion Token 침묵 면역 유지
==================================================

Champion Token의 기존 SILENCE 면역은 반드시 유지한다.

Champion Token은 침묵될 수 없다.

확인할 것:

- SILENCE target 후보에서 제외되는지
또는
- SILENCE 적용 시 안전하게 무효 처리되는지

현재 엔진 방식에 맞게 기존 동작을 보존한다.

침묵 면역 때문에:

- 일반 공격
- 일반 damage
- stat modification

까지 막히면 안 된다.

즉:

SILENCE만 면역.

==================================================
4. Champion Token 즉사 면역 유지
==================================================

Champion Token의 기존 "즉사 효과 면역"도 반드시 유지한다.

먼저 현재 코드에서
Champion Token instant-kill immunity가 정확히 어떤 effect를 막는지 조사한다.

기존 구현 범위를 임의로 넓히거나 줄이지 말 것.

예를 들어 현재:

DESTROY

가 즉사 계열로 분류되어 Champion Token에게 무효라면
그 규칙을 그대로 유지한다.

중요:

즉사 면역 ≠ damage 면역.

Champion Token 6/10이라면:

피해 3
→ 6/7

피해 7
→ HP 0
→ 정상 RETIRE

는 가능하다.

반면 기존 즉사 효과:

DESTROY 등

→ 기존 Champion Token 즉사 면역에 따라 무효.

REMOVE_FROM_GAME이
기존 instant-kill immunity 대상인지 아닌지는
현재 구현을 조사해서 기존 규칙을 유지하고
최종 보고에 정확히 명시한다.

==================================================
5. 일반 SUMMON된 같은 Definition과 구분
==================================================

Champion Token 특수 규칙은
정상적인 Champion Token deploy 경로로 활성화된 instance에만 적용한다.

같은 CardDefinition을 일반:

SUMMON
FULL_RANDOM
기타 effect

등으로 필드에 만든 경우에는:

- 원본 Champion 보호 활성화 금지
- Champion active state 연결 금지
- Champion Token deploy 특수 처리 금지

기존 규칙을 유지한다.

카드 이름으로 판정하지 말 것.

Champion Token deploy 상태 / entryCause / instance metadata 등
현재 canonical mechanism으로 판정한다.

==================================================
6. Champion Token 최종 규칙
==================================================

최종적으로 Champion Token은 다음 규칙을 가진다.

Deploy:
- 자신의 base Attack/Health 그대로 사용
- 원본 Champion HP 합산 없음

Active 동안:
- 원본 Champion 보호
- 원본 Champion target 불가
- 원본 Champion ability 사용 가능
- Champion Token SILENCE 면역
- Champion Token 기존 즉사 효과 면역
- 일반 damage/combat은 정상 적용

Champion Token 일반 damage로 RETIRE:
- 즉시 패배 없음
- 정상 graveyard
- active state 종료
- 원본 Champion 보호 해제
- 원본 Champion 다시 targetable
- 원본 Champion HP 그대로 유지

==================================================
7. 기존 게임 키워드 "태그" 제거
==================================================

주의:

이번에 새로 만든:

cards.tags

메타데이터는 절대 제거하지 않는다.

유지할 것:

- cards.tags
- 최대 3개 tag
- Admin tag 입력
- ALT Inspector tag 표시
- Card Detail tag 표시
- hasCardTag(...)
- sharesCardTag(...)
- matchesCardTagFilter(...)
- tagsAny
- tagsAll
- tagsNone
- tag 기반 effect targeting/filtering

전부 유지.

제거할 것은 예전 게임 mechanic/keyword인:

"태그"

이다.

이 구 키워드는:

"이번 턴 먼저 손에서 플레이된 다른 아군 WRESTLER와
공통 태그가 있으면 효과 발동"

같은 combo-like mechanic이다.

이 기존 keyword mechanic을 제거한다.

==================================================
8. 기존 "태그" 키워드 관련 코드 제거
==================================================

전체 repository를 조사해서
구 keyword "태그"와 관련된 코드를 찾는다.

예:

- keyword enum/type
- keyword definition
- structured effect condition
- parser
- event listener
- turn provenance
- previous-played tracking
- SHARES_TAG_WITH_PREVIOUSLY_PLAYED_ALLY_THIS_TURN
- UI keyword badge
- ALT keyword 설명
- tooltip
- 테스트
- 문서
- seed/default effect data

다른 mechanic에서 사용하지 않는다면 제거한다.

하지만 주의:

새 cards.tags 시스템에서 사용하는:

sharesCardTag

같은 generic helper는 제거하면 안 된다.

즉:

구 keyword mechanic 제거

와

새 tag metadata/filter 시스템 유지

를 정확히 구분한다.

==================================================
9. 사용자 노출 용어 정리
==================================================

앞으로 사용자에게 보이는 "태그"라는 단어는
cards.tags 메타데이터만 의미한다.

예:

키워드
[도발] [러쉬] [회피]

태그
[용병] [인간]

이렇게 표시한다.

더 이상:

키워드
[태그]

가 나타나면 안 된다.

기존 카드 설명이나 keyword 설명 중
구 태그 mechanic을 언급하는 데이터가 있다면 조사해서 보고한다.

임의로 다른 mechanic으로 변환하지 말 것.

10. Champion Token 테스트
==================================================

기존 테스트 중:

- Champion HP를 Token HP에 더하는 테스트
- Champion Token RETIRE → 즉시 패배 테스트

는 새 규칙에 맞게 수정한다.

반드시 다음 테스트 추가/수정:

TEST A

원본 Champion HP = 13
Champion Token base HP = 10

DEPLOY_CHAMPION_TOKEN

기대:

Token currentHP = 10
Token maxHP = 10

23이 되면 FAIL.

----------------------------------------

TEST B

Champion Token active

기대:

원본 Champion target 불가
원본 Champion damage 불가
Champion ability 사용 가능

----------------------------------------

TEST C

Champion Token에 SILENCE 시도

기대:

Champion Token 침묵되지 않음.

----------------------------------------

TEST D

Champion Token에 기존 즉사/DESTROY 효과 사용

기대:

기존 instant-kill immunity 규칙대로 무효.

Champion Token 유지.
RETIRE 발생하지 않음.

----------------------------------------

TEST E

Champion Token에게 일반 damage 누적.

HP가 0 이하가 됨.

기대:

정상 RETIRE.
graveyard 이동.
게임 패배하지 않음.

----------------------------------------

TEST F

Champion Token RETIRE 후

기대:

원본 Champion 보호 해제.
원본 Champion 다시 target 가능.
원본 Champion HP는 deploy 전 값 그대로.

----------------------------------------

TEST G

같은 Champion Token definition을
일반 SUMMON.

기대:

원본 Champion 보호 활성화 안 됨.
Champion active state 생성 안 됨.
