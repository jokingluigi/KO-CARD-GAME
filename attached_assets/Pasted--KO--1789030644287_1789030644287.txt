현재 KO 카드게임에 카드 플레이 연출만 추가해줘.

목표:
카드를 손패에서 플레이할 때 하스스톤처럼
"손에서 꺼내서 내는 느낌"과 카드의 무게감이 느껴지게 해줘.

중요:
- 게임 규칙/엔진은 바꾸지 말고 시각 연출만 추가
- 과한 파티클/폭발 금지
- 바닥 링 스포트라이트는 넣지 마
- 기존 카드 프레임/희귀도 시스템은 유지
- 관련 프론트엔드 UI만 최소 수정

1. 선수 카드 플레이 연출

손패에서 선수를 플레이하면:

- 카드가 먼저 짧게 살짝 확대된다 (약 1.08~1.15배)
- 손패 위치에서 목표 보드 슬롯까지 빠르게 이동
- 슬롯 도착 시 짧은 착지 임팩트
- 착지 직후 scale bounce
  예: 1.12 → 0.96 → 1.00
- 카드 프레임을 따라 짧은 빛 번짐/플래시 1회
- 보드 전체를 과하게 흔들지 말고 카드 주변 위주로 강조

전체 연출 길이:
약 0.35~0.6초

2. BASE COST에 따른 착지 무게감

선수 카드의 착지 임팩트 강도는 CURRENT COST가 아니라 BASE COST 기준으로 결정해.

0~1G:
- LIGHT
- 매우 가벼운 착지
- 작은 bounce
- 화면 흔들림 없음

2~3G:
- NORMAL
- 기본 착지
- 적당한 bounce
- 아주 약한 impact

4~5G:
- HEAVY
- 더 묵직한 착지
- bounce 조금 강하게
- 카드 주변 짧은 충격감
- 아주 미세한 화면 진동 가능

6G 이상:
- VERY_HEAVY
- 확실한 scale impact
- 짧고 강한 화면 진동
- 카드 주변 작은 충격파/먼지 느낌 정도 허용

8G, 10G 등 초고코스트도 지원하되
효과 강도가 무한히 커지지 않도록 최대치를 제한해.

예:
10G 씨 몬스터도 강하게 느껴지되
과도한 폭발/긴 화면 흔들림은 금지.

할인/증가로 CURRENT COST가 변해도
착지 등급은 원래 BASE COST 기준으로 유지.

3. 희귀도 차이

코스트는 "착지 무게감"만 담당하고,
rarity는 프레임 빛/색상 강조를 담당하게 분리해.

NORMAL:
- 기본 프레임 플래시

LEGENDARY:
- 금빛 프레임 플래시를 조금 더 강하게

CHAMPION:
- 가장 강한 프레임 강조
- 카드 주변 강조 조금 더 강하게

희귀도와 코스트 효과가 겹쳐도 과해지지 않게 조절해.

4. 기술 카드 플레이 연출

기술 카드를 사용하면:

- 손패 카드가 화면 중앙 쪽으로 빠르게 튀어나옴
- 잠깐 크게 보여줌
- 기술 효과 실행
- 빠르게 사라짐

기술 카드는 선수 카드처럼 보드 슬롯 착지 연출을 쓰지 않는다.

5. 등장 효과 타이밍

선수 카드:

플레이 시작
→ 손패에서 이동
→ 슬롯 착지
→ bounce / frame flash
→ ENTER_FIELD 효과 처리

연출 때문에 ENTER_FIELD가 두 번 실행되면 안 된다.

6. 오디오 연동

기존 카드 등장 음악이 있다면
카드가 보드 슬롯에 착지하는 시점에 재생해.

오디오가 없어도 정상 동작해야 한다.

7. 구현 방식

가능하면 공통 카드 플레이 애니메이션 함수/컴포넌트로 구현해.

별도의 카드별 애니메이션을 만들지 말고:

landingImpactLevel =
LIGHT / NORMAL / HEAVY / VERY_HEAVY

를 BASE COST로 계산한 뒤
duration / scale / shake intensity만 조절해.

현재 카드 위치와 목표 위치의 bounding box를 이용한
FLIP 또는 유사 transform 애니메이션을 사용해도 된다.

8. 안전성

- 잘못된 플레이 시도 때문에 애니메이션이 시작되거나 GameState가 바뀌면 안 됨
- animation 실패해도 게임 진행 정상 유지
- 페이지 reload/reset 금지
- Effect Library / 전투 / Gold / 턴 규칙 수정 금지
- prefers-reduced-motion 환경에서는 shake를 줄이거나 제거

9. 완료 확인

실제로 다음을 확인해:

- 1G 선수 → 가벼운 착지
- 3G 선수 → 기본 착지
- 5G 선수 → 묵직한 착지
- 6G 이상 선수 → 강한 착지
- LEGENDARY 카드 → rarity 프레임 강조 정상
- CHAMPION 카드/토큰 → 가장 강한 프레임 강조
- 기술 카드 → 중앙 표시 후 사라짐
- ENTER_FIELD 효과가 정확히 1회만 실행

기능이 정상 작동하면 추가 작업하지 말고 종료해줘.
