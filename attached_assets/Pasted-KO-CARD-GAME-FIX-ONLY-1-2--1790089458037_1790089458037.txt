0. FIX-FIRST
==================================================

이번 작업은 QA/조사 보고서가 아니다.

반드시 각 카드마다:

authoritative effect 확인
→ 실패 경로 재현
→ root cause 확인
→ 실제 source/config 수정
→ 카드 전용 regression test
→ 관련 공통 regression
→ 다음 카드

순서로 진행한다.

네 카드를 전부 조사만 하고
마지막에 일부만 수정하는 방식 금지.

→ 조크루이지

각 항목을 실제로 끝낸 뒤 다음으로 이동.

==================================================
PART A — 흑구슬마스터
==================================================

현재 신고:

흑구슬마스터를 손에서 플레이하면
대상을 지정해야 하는 등장 효과가
정상적으로 이어지지 않거나 씹힌다.

특히:

PLAY_FROM_HAND
→ ON_ENTER
→ PLAYER_CHOICE

까지 연결되어야 하는 효과가
중간에서 resolution되지 않는 문제가 있었다.

==================================================
1. 흑구슬마스터 공식 효과 확인
==================================================

먼저 authoritative definition을 확인.

우선순위:

1. CardDefinition
2. effectConfig
3. SCRIPT_V1 / Structured Effect
4. Admin saved effect
5. seed/catalog
6. git history

정확한:

- trigger
- 대상
- 효과
- 수치
- 조건

을 확인.

효과를 추측해서 새로 만들지 마.

==================================================
2. 흑구슬마스터 핵심 경로
==================================================

정상 흐름이 target-selection ON_ENTER라면:

PLAY_FROM_HAND
→ ON_ENTER
→ effect frame 생성
→ PLAYER_CHOICE targetingState
→ 유효 target 표시
→ SELECT_EFFECT_TARGET
→ continuation resume
→ 실제 effect
→ effect frame 완료

까지 이어져야 한다.

==================================================
3. 특히 확인할 것
==================================================

A.
ON_ENTER가 PLAY_FROM_HAND에서 실제 발생하는가?

B.
PLAYER_CHOICE에서 targetingState가 생성되는가?

C.
선택 후 continuation ID/frame이 유지되는가?

D.
target 선택 순간 effect frame이 삭제되는가?

F.

validator가 effect를 취소하는가?

G.
UI만 targeting 상태인데
canonical engine은 이미 effect를 종료했는가?

==================================================
4. ON_ENTER 규칙 유지
==================================================

기존 공식 규칙:

ON_ENTER / 등장 효과는
WRESTLER의 PLAY_FROM_HAND에서만 발생.

다음에서는 일반 등장 효과 자동 발동 금지:

- SUMMON
- REVIVE
- Champion Token deployment

흑구슬마스터를 고치면서
이 규칙을 깨뜨리지 마.

12. HAND 효과는 server-side에서 처리
==================================================

데헌이 상대에게 공개되지 않아야 하는
HAND 카드라면:

효과가 발동하기 전까지
상대 client에 identity를 노출하면 안 된다.

하지만 hidden information 보호 때문에
server-side trigger까지 막으면 안 된다.

즉:

server knows HAND card
→ trigger 판정
→ effect resolution
→ 공개가 필요한 시점에 presentation

구조 유지.

15. Temporary modifier lifecycle 조사
==================================================

공식적으로 이번 턴 동안만 유지되는 효과라면:

effect activation
→ temporary attack modifier 등록

→ TURN_END
→ 해당 temporary modifier 제거

되어야 한다.

완료 조건
==================================================

이번 작업은 정확히 네 카드만 끝낸다.

1. 흑구슬마스터
   PLAY_FROM_HAND → target selection → effect 정상 실행

2. 조크루이지
   authoritative effect가 실제 GameState에 적용

3. 데헌
   HAND 상태에서 공식 effect 정상 발동

4. 나토마토
   공식 temporary buff라면 정확한 시점에 원상복구

이 네 가지가 자동 regression으로 증명되어야 한다.

다른 문제는 수정하지 말고 멈춰라.
