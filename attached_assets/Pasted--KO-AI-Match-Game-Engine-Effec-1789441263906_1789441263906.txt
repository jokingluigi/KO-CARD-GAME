현재 KO 카드게임에 AI Match를 구현하기 전에
"게임 엔진 핵심 통합 점검"을 실행해줘.

목표:
새 기능을 추가하는 것이 아니라,
현재 Game Engine / Effect Engine / Match Flow가
실제 플레이 가능한 상태인지 브라우저에서 검증하고
발견된 버그만 최소 수정한다.

TEST USER / TEST ADMIN Auth Helper가 있으면 반드시 사용해.

==================================================
1. PLAYER_CHOICE
==================================================

가장 먼저 실제로 테스트해.

챔피언 판도라 기본 능력:
2G
"선택한 선수에게 피해 1"

반드시:

능력 클릭
→ Targeting Mode
→ 선수 Highlight
→ 실제 카드 클릭
→ 선택한 선수에게 정확히 피해 1
→ pendingSelection 제거
→ 게임 계속 진행

강화 능력:
1G
"선택한 대상에게 피해 1"

여기서:

대상 = WRESTLER + CHAMPION

둘 다 실제 클릭 가능해야 한다.

Champion 보호 상태라면
Champion은 선택 후보에서 제외.

Analyzer만 정상인 것으로 PASS 처리하지 말고
실제 브라우저 클릭까지 확인해.

==================================================
2. PLAYER_CHOICE 다른 Zone
==================================================

다음 효과도 테스트:

"손에 있는 선수 카드 하나를 선택하여 공격력을 2 올립니다."

→ HAND의 WRESTLER만 선택 가능
→ Technique 선택 불가
→ 선택한 Card Instance만 +2 Attack

PLAYER_CHOICE는:

- Board
- Hand
- Champion

에서 공통 시스템을 사용해야 한다.

==================================================
3. RETIRE / DESTROY / REMOVE
==================================================

공식 규칙 확인:

RETIRE:
- 퇴장 효과 O
- RETIRE Event O
- Graveyard 이동 O

DESTROY:
- 퇴장 효과 X
- RETIRE Event X
- Graveyard 이동 X
- DESTROY Event O
- 그냥 파괴되어 사라짐

REMOVE_FROM_GAME:
- 퇴장 X
- RETIRE X
- DESTROY X
- Graveyard X
- removedFromGame 이동 O

실제로 테스트해.

==================================================
4. 위리놈으로 RETIRE 테스트
==================================================

위리놈:

"퇴장: 손에 있는 위리녀 하나를 소환합니다."

A.
전투/피해로 HP 0 이하

→ RETIRE
→ 위리녀 소환
→ 위리놈 묘지 이동

B.
DESTROY

→ 위리녀 소환 X
→ 묘지 이동 X

확인.

==================================================
5. 디 오리진 묘지 계산
==================================================

디 오리진:

7G / 4/4

"내 묘지의 선수 카드 수만큼
공격력과 체력을 얻습니다."

내 묘지만 계산.

예:

내 선수:
3 RETIRE
2 DESTROY

이면

묘지 선수 수 = 3

디 오리진 = 7/7

이어야 한다.

상대 묘지는 계산하지 않는다.

==================================================
6. 전투
==================================================

기본 선수 전투 확인:

- CURRENT Attack 사용
- CURRENT Health 사용
- 선수 vs 선수 동시 피해
- HP <= 0 → RETIRE
- 한 선수 기본 1회 공격
- 새로 소환된 선수 공격 불가
- 러쉬/기습은 기존 규칙 유지
- 도발이 있으면 일반 공격 대상 제한

UI Animation이 Engine 결과를 결정하면 안 된다.

==================================================
7. Champion 공격
==================================================

선수 → 적 Champion 직접 공격 정상 동작 확인.

단:

도발 존재
→ 일반 공격으로 Champion 선택 불가

Active Champion Token 보호 중
→ Champion 직접 공격/효과 Target 불가

확인.

==================================================
8. Board 4칸
==================================================

각 Player Board는 정확히:

slot 0
slot 1
slot 2
slot 3

4칸.

확인:

- 빈 slot summon
- 꽉 찬 Board에 추가 summon 안전 실패
- 효과 소환도 4칸 제한
- Board overflow 없음

==================================================
9. ENTER_FIELD
==================================================

모든 정상 Field 진입에서
ENTER_FIELD가 정확히 1회 발생해야 한다.

확인:

- Hand에서 플레이
- Effect SUMMON
- Generated/Token SUMMON
- Captured release
- Champion Token 특수 배치

효과 소환된 선수의 등장 효과도 발동.

중복 ENTER_FIELD 금지.

==================================================
10. Generated
==================================================

Effect로 새로 만들어진 카드는:

isGenerated = true

상태가:

HAND
DECK
BOARD

이동 후에도 유지되어야 한다.

기존 카드를 단순 이동했다고 Generated가 되면 안 된다.

Generated Targeting도 정상 작동 확인.

==================================================
11. Draw / Hand
==================================================

확인:

- 시작 손패 정상
- 개인 턴 시작 Draw 1
- Hand 최대 7
- Hand가 가득 찬 상태에서 Draw
  → Graveyard가 아니라 removedFromGame
- Draw Event/준비 Trigger가 있다면 기존 순서 유지

Fatigue 규칙은 이번 점검에서 새로 만들거나 변경하지 마.

==================================================
12. Gold
==================================================

개인 턴 기본 Gold:

1 → 2 → 3 → 4 → 5 → 6
이후 기본 6 유지.

확인:

- 턴 종료 후 carryover 없음
- Bonus Gold로 6 초과 가능
- 7G 이상 카드도 조건 충족 시 플레이 가능
- Cost 지불 검증 정상

==================================================
13. Card Play
==================================================

선수 카드:

Cost 지불
→ Slot 결정
→ Field 진입
→ ENTER_FIELD
→ Effect

정상 순서 확인.

Technique:

Cost 지불
→ Effect
→ Field에 남지 않음

Invalid play:

- GameState 변경 없음
- Crash 없음
- Toast/오류
- 비용도 소모되지 않음

==================================================
14. Effect Sequence
==================================================

Sequence Effect가 순서대로 작동하는지 확인.

예:

선택한 선수
→ SILENCE
→ DESTROY

선택은 한 번만 하고
같은 Target을 후속 Step에서도 사용해야 한다.

Effect 중간에 context가 사라지면 안 된다.

==================================================
15. Champion Ability
==================================================

Champion Ability 확인:

- Cost 지불
- Target 필요 시 PLAYER_CHOICE
- Effect 정상 실행
- Invalid target이면 State 변경 없음

판도라 능력을 반드시 실제 통합 테스트로 사용.

특정 Champion 이름으로 Engine 하드코딩 금지.

==================================================
16. Champion Token
==================================================

특수 DEPLOY_CHAMPION_TOKEN 확인:

- championTokenDefinitionId 사용
- ENTER_FIELD 발생
- Champion 현재 HP가 Token Max HP에 1회 추가
- Token 활성 중 Champion target 불가
- Champion Ability는 사용 가능
- 해당 특수 Token이 RETIRE하면 Owner 즉시 패배

일반 SUMMON된 같은 CardDefinition에는
이 보호/패배 규칙이 붙으면 안 된다.

==================================================
17. Match Result
==================================================

확인:

- Champion HP <= 0 → 승패 확정
- Active Champion Token RETIRE → 패배
- Surrender → 패배

Match Result 확정 후:

- 새 카드 플레이 금지
- 공격 금지
- 능력 사용 금지
- End Turn 금지

마지막 Animation 완료 후:

VICTORY / DEFEAT 화면
→ [메인 화면으로]

정상 작동.

==================================================
18. Deck → Match 시작
==================================================

TEST USER의 VALID 저장 Deck으로
실제 Match를 시작해.

확인:

- ChampionDefinition 정상 로드
- Deck CardDefinition 정상 로드
- Token / Champion Token이 시작 Deck에 없음
- CardDefinition ID reference 정상
- Match 시작 Snapshot 정상 생성

AI 구현 전에 이 흐름이 반드시 안정적이어야 한다.

==================================================
19. RNG
==================================================

Game Engine에서 Math.random 사용 여부 확인.

게임 효과 RANDOM은
현재 deterministic RNG 시스템을 사용해야 한다.

UI가 Random 결과를 새로 결정하면 안 된다.

Pack Opening RNG는 별도 시스템이므로
이번 작업에서 건드리지 마.

==================================================
20. Event / Effect 연결
==================================================

최소 다음 Event가 실제 Executor와 연결되어 있는지 확인:

- CARD_PLAYED
- ENTER_FIELD
- ATTACK
- DAMAGE
- RETIRE
- DESTROY
- TURN_START
- TURN_END
- CARD_DRAWN
- CARD_GENERATED
- CHAMPION_ABILITY_USED

Event Log에 기록되는 것만으로 PASS 처리하지 마.

실제 Effect Trigger가 실행되는지 확인.
