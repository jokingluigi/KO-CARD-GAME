KO CARD GAME — P0 PRODUCTION BACKEND INCIDENT
RENDER NODE FAILED + QUEST DB QUERY FAILURE + IMAGE/API FAILURE + ONLINE MATCH CONNECTION FAILURE

현재 KO CARD GAME에 여러 증상이 동시에 발생하고 있다.

이것들을 개별 UI 버그로 따로 패치하지 말고,
공통 backend/API/database infrastructure 장애 가능성을 최우선으로 조사하고
ROOT CAUSE부터 해결하라.

현재 실제 증상:

7. MIGRATION 누락이면 안전하게 해결
==================================================

조건:

- additive
- idempotent where possible
- 기존 row 보존

- truncate 금지
- reset 금지

schema_version
condition
progress

라면
실제 application schema에 맞는 type/default를 확인한 후
정식 migration.

타입을 추측해서 넣지 말 것.

45. 가장 중요한 마지막 지시
==================================================

지금 발생한 증상들을 서로 독립된 버그라고 가정하지 마라.

현재 동시에:

QUEST DB QUERY FAILURE
IMAGE LOAD FAILURE
AUTH FAILURE
WEBSOCKET FAILURE
TURN END FAILURE
FORFEIT FAILURE
RENDER NODE SERVICE FAILED

가 발생하고 있다.

이 상황에서는
NODE BACKEND / DATABASE SCHEMA / DEPLOYMENT
공통 장애를 최우선으로 의심해야 한다.

따라서:

RENDER PROCESS
→ DATABASE
→ API
→ AUTH
→ MEDIA
→ WS
→ ONLINE GAME

순서대로 복구하라.

특히 daily_quest_assignments query에서
코드가 요구하는 schema와
실제 DB schema가 다르면
그 mismatch를 정확히 찾아
데이터를 보존하는 정식 migration으로 해결하라.

Node server를 HEALTHY 상태로 만들지 못했다면
온라인 매치나 Quest를 해결했다고 선언하지 마라.
