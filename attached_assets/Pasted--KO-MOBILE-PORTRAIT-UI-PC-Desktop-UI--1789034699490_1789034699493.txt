현재 KO 카드게임의 MOBILE PORTRAIT 전용 UI를 다시 크게 수정해줘.

가장 중요:
이 작업은 모바일 세로 화면 전용이다.
PC/Desktop/가로 화면 UI는 절대로 변경하지 마.

현재 모바일 문제:
- 필드 카드가 너무 작음
- 손패 카드가 너무 작음
- 보조 UI가 공간을 너무 많이 차지함

이번 목표:
모바일에서는 "카드와 전투 보드"를 최우선으로 두고
현재보다 카드가 체감상 최소 2배 이상 크게 보이도록 재배치해줘.

1. 중앙 보드 최우선

상대 4슬롯 + 내 4슬롯 보드를
모바일 화면 중앙의 가장 큰 영역으로 사용해.

필드 카드 크기를 현재보다 매우 크게 키워.
약간 키우는 수준이 아니라
현재 대비 체감상 2배 이상 커야 한다.

- 슬롯 gap 최소화
- 불필요한 margin/padding 제거
- 상대/내 필드 사이 간격 축소
- 카드가 화면 밖으로 나가지만 않으면 최대한 크게

4슬롯 구조는 유지.

2. 손패도 크게

손패 카드는 한 화면에 다 넣기 위해 작게 축소하지 마.

하스스톤처럼 카드끼리 크게 겹쳐서 배치해.

- 카드 한 장 자체는 크게 유지
- 카드 폭의 약 50~65%까지 overlap 허용
- 카드 수가 많을수록 overlap 증가
- 선택한 카드는 위로 올라오고 확대
- 선택 카드가 가장 높은 z-index
- 겹친 카드도 터치 가능하게 할 것

손패는 화면 하단에 배치.

3. 보조 UI는 거의 전부 접기

모바일에서 아래 UI는 평소 화면을 차지하지 않게 해:

- 로그
- 무덤
- 제거된 카드
- 설정
- 상세 턴 정보
- 세부 덱 정보

각각 작은 아이콘/버튼만 남기고
눌렀을 때 모달이나 접이식 패널로 열어.

로그 박스 같은 큰 고정 UI는 모바일에서 제거해.

4. 챔피언 UI도 압축

상대/내 챔피언 UI는 필요한 정보만 작게 유지:

- 챔피언 초상
- HP
- Gold
- 퀘스트 진행도
- 능력 버튼

현재처럼 큰 사각형 패널이 카드 공간을 많이 먹지 않게
모바일 전용 compact 형태로 만들어.

5. 턴 종료

턴 종료 버튼은 항상 보이게 유지하되
필드 카드 공간을 침범하지 않는 우측 또는 적절한 고정 위치에 배치.

버튼은 손가락으로 누르기 쉬운 크기 유지.

6. 카드 상세 보기

손패/필드 카드를 탭하면
큰 카드 상세보기로 내용을 읽을 수 있게 해.

모바일에서는 Alt/Hover를 요구하지 마.

Desktop Alt+Hover는 그대로 유지.

7. 모바일 전용 CSS

반드시 mobile portrait breakpoint 안에서만 적용:

예:
@media (max-width: 768px) and (orientation: portrait)

공통 Card Renderer는 재사용하되
모바일 전용 size/layout만 별도로 적용해.

Desktop CSS를 바꿔서 해결하지 마.

8. 기존 프레임 유지

NORMAL / LEGENDARY / CHAMPION 카드 프레임 유지.

카드를 크게 키운 뒤에도:

- Cost
- Name
- Attack
- Health
- Effect text
- Artwork

가 프레임에 정확히 맞아야 한다.

9. 애니메이션 유지

기존:
- 카드 플레이 이동
- 공격 이동
- 충돌
- screen shake

는 모바일의 새로운 카드 위치를 기준으로 정상 작동하게 해.

Desktop 좌표 하드코딩 금지.

10. 실제 목표 화면 비율

390x844
430x932

에서 직접 확인해.

최종적으로:

- 중앙 보드가 화면에서 가장 큰 요소
- 필드 카드가 현재보다 최소 체감 2배 이상 큼
- 손패 카드도 현재보다 최소 체감 2배 이상 큼
- 손패는 겹쳐서 공간 절약
- 로그/무덤/설정 등은 아이콘/모달로 숨김
- 챔피언 UI는 compact
- 카드가 읽기 쉬움
- UI끼리 겹치지 않음

이어야 한다.

반드시 Desktop 1920x927도 확인해서
Desktop UI는 작업 전과 시각적으로 동일하게 유지해.

게임 엔진 / Effect / Combat / Gold / Turn은 수정하지 말고
모바일 portrait UI 배치/CSS만 수정해.

이번에는 카드가 여전히 작게 보이면 실패로 판단하고
추가 기능 없이 종료해줘.
