현재 KO 카드게임에서 불가능한 행동을 시도할 경우 사이트 전체 오류가 발생하거나 게임 상태가 초기화되는 문제가 있다.

이 동작을 수정해줘.

매우 중요:
게임 규칙상 불가능한 행동은 프로그램 오류(Exception)가 아니다.
정상적인 사용자 입력 실패로 처리해야 한다.

게임이 절대로 초기화되거나 새 게임으로 돌아가면 안 된다.

================================
목표
==

사용자가 불가능한 행동을 시도하면:

1. 행동을 실행하지 않는다.
2. 현재 GameState를 변경하지 않는다.
3. 게임을 초기화하지 않는다.
4. 페이지를 새로고침하지 않는다.
5. 예외 화면을 띄우지 않는다.
6. 대신 사용자에게 간단한 경고 메시지를 표시한다.

================================
예시
==

골드가 부족한 카드를 사용하려고 할 경우:

"골드가 부족합니다."

보드가 4칸 모두 차 있는데 선수를 소환하려는 경우:

"필드에 빈 자리가 없습니다."

이번 턴에 일반적으로 소환된 선수가 공격하려는 경우:

"이 선수는 이번 턴에 공격할 수 없습니다."

이미 기본 공격 횟수를 모두 사용한 선수가 다시 공격하려는 경우:

"이 선수는 이번 턴에 더 이상 공격할 수 없습니다."

상대 턴에 행동하려는 경우:

"상대의 턴입니다."

도발 등으로 인해 선택할 수 없는 공격 대상을 선택한 경우:

"해당 대상을 공격할 수 없습니다."

유효하지 않은 보드 슬롯:

"해당 위치에는 소환할 수 없습니다."

================================
게임 엔진 구조
========

현재 validation 과정에서 불가능한 행동에 대해 throw Error() 또는 게임 전체를 중단시키는 방식이 있다면 수정해줘.

예외를 던지는 대신 validation 결과를 반환하는 방식으로 만들어줘.

예를 들면 개념적으로:

{
success: false,
errorCode: "NOT_ENOUGH_GOLD",
message: "골드가 부족합니다."
}

또는

{
success: true,
state: updatedGameState
}

같은 구조를 사용해도 된다.

정확한 타입 이름은 기존 코드 구조에 맞게 정해줘.

중요:

validation 실패 시 원래 GameState를 그대로 유지해야 한다.

게임 규칙 위반 때문에 GameState를 초기 상태로 되돌리는 코드는 제거해줘.

================================
Action 처리
=========

PLAY_CARD
ATTACK
USE_ACTIVE
USE_CHAMPION_ABILITY
END_TURN

등 모든 사용자 Action은 실행 전에 validation을 거치게 해줘.

Action 처리 결과는 성공/실패를 명확히 구분한다.

실패했다고 해서 React App 전체에서 exception이 발생하면 안 된다.

예:

PLAY_CARD 실패
→ 카드가 손패에 그대로 존재
→ 골드 그대로
→ 보드 그대로
→ 현재 턴 그대로
→ 경고 메시지만 표시

ATTACK 실패
→ 선수 위치 그대로
→ attacksUsedThisTurn 그대로
→ 체력 그대로
→ 경고 메시지만 표시

================================
경고 UI
=====

화면 중앙 또는 하단에 작은 Toast/Alert 형태의 메시지를 보여줘.

예:

[ 골드가 부족합니다. ]

경고창 때문에 게임 플레이가 중단되지는 않게 한다.

확인 버튼을 반드시 눌러야 하는 브라우저 alert()는 사용하지 않는 것을 권장한다.

간단한 Toast UI를 사용해줘.

약 2~3초 후 자동으로 사라지게 한다.

동시에 여러 오류가 발생해도 UI가 망가지지 않도록 해줘.

================================
카드 선택 UX
========

가능하면 불가능한 행동을 애초에 시각적으로도 알 수 있게 해줘.

예:

골드가 부족한 손패 카드
→ 약간 어둡게 표시

공격할 수 없는 선수
→ 공격 가능 강조 효과 없음

이미 공격한 선수
→ 비활성 상태 표시

이번 턴에 나온 일반 선수
→ 공격 불가 표시

하지만 매우 중요:

UI에서 막는 것만으로 끝내지 말고
게임 엔진에서도 반드시 validation을 수행해야 한다.

UI는 편의를 위한 것이고,
실제 게임 규칙 판정은 게임 엔진이 담당한다.

================================
예외와 정상적인 규칙 실패 구분
=================

다음은 정상적인 게임 규칙 실패다.

* 골드 부족
* 잘못된 공격 대상
* 소환 턴 공격
* 보드 가득 참
* 공격 횟수 부족
* 상대 턴 행동
* 사용할 수 없는 카드
* 잘못된 슬롯 선택

이 경우 exception을 발생시키지 않는다.

반대로 실제 프로그래밍 버그:

* GameState 자체가 undefined
* 존재해야 하는 객체가 손상됨
* 예상하지 못한 내부 데이터 오류

등은 개발자가 확인할 수 있도록 console error 또는 Error Boundary를 사용할 수 있다.

하지만 실제 프로그래밍 오류가 발생하더라도 가능하면 현재 게임 상태를 자동으로 새 게임 상태로 덮어쓰지 마.

================================
절대 하지 말 것
=========

불가능한 행동을 했다고:

* window.location.reload()
* 게임 자동 재시작
* createInitialGameState() 재호출
* 전체 GameState 초기화
* 페이지 강제 리로드

하지 마.

기존 정상 게임 규칙도 변경하지 마.

이번 작업은 "행동 validation 실패 처리와 오류 UI"를 고치는 작업이다.

================================
테스트
===

다음을 직접 테스트해줘.

1. 1G인데 5G 카드 사용 시도
   → 카드 사용 안 됨
   → 골드 변화 없음
   → 경고 표시
   → 게임 계속 진행

2. 보드 4칸 가득 찬 상태에서 선수 사용
   → 사용 안 됨
   → 카드 손패에 유지
   → 경고 표시

3. 이번 턴에 소환된 일반 선수로 공격
   → 공격 안 됨
   → 경고 표시
   → 게임 계속 진행

4. 이미 공격한 선수로 다시 공격
   → 공격 안 됨
   → 경고 표시

5. 상대 턴에 행동
   → 행동 안 됨
   → 경고 표시

6. 잘못된 공격 대상
   → 공격 안 됨
   → 경고 표시

위 모든 경우에서 게임 상태가 초기화되지 않는지 반드시 확인해줘.

기존 정상적인 카드 사용, 공격, 턴 종료 기능은 그대로 유지해줘.

요청 범위 밖의 대규모 리팩터링은 하지 마.
