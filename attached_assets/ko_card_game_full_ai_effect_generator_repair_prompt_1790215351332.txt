5. SCRIPT_V1 완전 정렬
==================================================

SCRIPT_V1은 shared Script AST contract를 그대로 따른다.

대표 canonical shape:

{
  "scripts": [
    {
      "version": "SCRIPT_V1",
      "trigger": "SELF_ATTACK",
      "steps": [
        {
          "id": "selectedCard",
          "type": "SELECT",
          "target": {
            ...
          }
        },
        {
          "type": "EFFECT",
          "effect": {
            "action": "STEAL",
            "target": {
              "resultId": "selectedCard"
            }
          }
        }
      ]
    }
  ]
}

반드시 reject:

- version 없음
- SCRIPT_V2
- steps object
- unknown step type
- duplicate step id
- nonexistent resultId
- forward reference
- unknown action
- invalid target enum
- arbitrary code
- spoofed sourceId
- malformed nested script

Validator를 느슨하게 하지 마.

==================================================
6. Simple Effect vs SCRIPT_V1 선택 정책
==================================================

simple `effects[]`로 가능한 것은 script로 만들지 마.

Simple Effect:
- 독립 action
- target/value dependency 없음
- single effect로 표현 가능

SCRIPT_V1:
- SELECT 결과를 후속 EFFECT가 참조
- sequential dependency
- same target binding
- resultId 필요

Provider가 복잡해 보인다는 이유만으로
무조건 SCRIPT_V1을 선택하면 FAIL.
