KO CARD GAME — AI MATCH OPENING SEQUENCE FIX

현재 문제:

Online Match에서는 게임 시작 시 기존 오프닝 연출이 정상적으로 재생된다.

하지만 AI Match에서는 게임 화면에 들어가자마자 바로 플레이 상태가 시작되고,
동일한 오프닝 연출이 나오지 않는다.

목표:

AI Match에서도 Online Match와 동일한 게임 시작 오프닝을 재생한다.

==================================================
1. 기존 오프닝 구현부터 추적
==================================================

Online Match에서 현재 정상 작동하는 오프닝의 실제 구현을 찾아라.

확인:

- 어떤 component가 오프닝을 렌더링하는가
- 어떤 state/phase가 오프닝 시작을 결정하는가
- 어떤 조건에서 오프닝이 끝나는가
- 오프닝 종료 후 실제 gameplay가 READY 되는 흐름
- Champion / player / opponent 정보가 어떻게 전달되는가
- 애니메이션 duration / transition / sound가 어디에서 관리되는가

AI Match용으로 비슷한 코드를 새로 복사하지 말고,
가능하면 기존 공통 오프닝 component/flow를 재사용하라.

==================================================
2. AI MATCH에서도 동일하게 실행
==================================================

AI Match 진입 흐름:

AI Match 생성
→ initial GameState 준비
→ 오프닝 시작
→ 기존 오프닝 연출 재생
→ 오프닝 종료
→ gameplay 활성화

가 되도록 한다.

AI Match라고 해서 오프닝을 skip하지 말 것.

==================================================
3. ONLINE MATCH와 시각적으로 동일
==================================================

AI Match 오프닝은 Online Match의 현재 Production 오프닝과 동일해야 한다.

가능한 한 동일한:

- 레이아웃
- Champion 표시
- 플레이어 이름
- 상대 이름
- VS 연출
- 애니메이션
- 전환 속도
- 배경
- 사운드/BGM 전환
- 시작 타이밍

을 사용.

AI 상대의 이름/Champion 정보만 AI 데이터에서 가져온다.

==================================================
4. AI 상대 표시
==================================================

Online opponent 대신 AI opponent 정보를 사용.

예:

PLAYER:
실제 사용자 nickname
실제 Champion

OPPONENT:
AI 이름
AI가 사용하는 Champion

현재 AI Match에 이미 authoritative하게 존재하는 데이터를 사용.

하드코딩 금지.

==================================================
5. 오프닝 중 게임 진행 금지
==================================================

오프닝이 재생되는 동안:

- 카드 플레이
- 공격
- Champion Ability
- Technique
- END TURN
- AI 행동

이 시작되면 안 된다.

특히 AI가 오프닝 뒤에서 먼저 행동하는 문제를 만들지 말 것.

AI turn timer / AI action scheduler가 있다면
오프닝 완료 전까지 시작되지 않도록 한다.

==================================================
6. 오프닝 종료 후 정상 시작
==================================================

오프닝이 끝난 직후:

- board 정상 표시
- hand 정상 표시
- 현재 turn 정상
- Gold 정상
- Champion 정상
- action buttons 정상
- AI scheduler 정상 시작

기존 AI Match의 GameState를 새로 만들거나 reset하지 말 것.

오프닝은 presentation layer여야 한다.

==================================================
7. GAME STATE 변경 금지
==================================================

오프닝 추가 때문에:

- shuffle 다시 실행
- starting hand 다시 draw
- Gold reset
- turn reset
- Champion HP reset
- random seed 변경
- AI state 재생성

금지.

이미 생성된 AI Match GameState 위에
오프닝 UI만 선행하도록 한다.

==================================================
8. 공통 오프닝 구조 우선
==================================================

현재 Online Match 전용으로 오프닝이 박혀 있다면
가능하면 다음처럼 공통화:

MatchOpening

props 예시:

player
opponent
playerChampion
opponentChampion
onComplete

그리고:

Online Match
AI Match

둘 다 같은 component를 사용.

단, 불필요한 대규모 refactor는 하지 말 것.

==================================================
9. SKIP 기능이 기존에 있다면 유지
==================================================

Online Match 오프닝에:

Skip
click to continue
animation skip

같은 기존 기능이 있다면
AI Match에서도 동일하게 작동.

새 동작을 임의로 추가하지 말 것.

==================================================
10. AI MATCH 재시작/재진입
==================================================

검사:

새 AI Match 시작
→ 오프닝 1회

게임 도중 설정 열기/닫기
→ 오프닝 다시 나오면 안 됨

같은 Match 화면 rerender
→ 다시 나오면 안 됨

새로운 AI Match 시작
→ 다시 오프닝 나와야 함

즉 Match 단위로 정확히 1회.

==================================================
11. ONLINE MATCH REGRESSION 금지
==================================================

Online Match의 현재 정상 오프닝은 그대로 유지.

검사:

Online Match
→ 기존 오프닝 정상

AI Match
→ 동일 오프닝 정상

둘 중 하나를 고치면서 다른 쪽을 깨지 말 것.

==================================================
12. 테스트
==================================================

AI MATCH #1

게임 시작
→ 오프닝 표시

→ 정상 gameplay

AI MATCH #2

→ 오프닝 다시 표시

→ AI 행동 정상 시작

PLAYER TURN START MATCH

플레이어 선공:
오프닝 종료
→ 플레이어 action 정상

최종 목표
==================================================

Online Match에서 이미 정상적으로 사용하는 게임 시작 오프닝을
AI Match에서도 동일하게 보여준다.

새로운 별도 오프닝을 만들지 말고
가능하면 기존 오프닝 구현을 공통 재사용한다.

오프닝은 UI/Presentation만 담당하고
AI Match의 canonical GameState에는 영향을 주지 않는다.
