KO CARD GAME — SEV-1 DECK VALIDATION BUG
“OWNED LIMIT REACHED” MUST NOT INVALIDATE AN ALREADY VALID DECK

현재 Production에서 반복적으로 발생하는 버그다.

실제 UI:

"이 덱은 현재 사용할 수 없습니다."
"카드 문제 · 보유 수량 1장에 도달했습니다."

그리고 덱 목록에서
카드 ×1이 빨간색 오류로 표시된다.

이 판정은 잘못됐다.

==================================================
CORE RULE
==================================================

반드시 다음 세 개념을 분리하라.

ownedCount
= 사용자가 실제로 보유한 해당 카드 총 수량

deckCount
= 현재 덱에 들어 있는 해당 카드 수량

availableToAdd
= 현재 덱에 추가로 더 넣을 수 있는 수량

IMPORTANT:

availableToAdd === 0

은

"현재 덱이 INVALID"

라는 뜻이 아니다.

단지:

"더 이상 이 카드를 추가할 수 없다"

는 뜻이다.

==================================================
LIKELY BUG
==================================================

Inspect whether deck validation currently uses logic similar to:

deckCount >= ownedCount

or

availableToAdd <= 0

or

!canAddCardToDeck(card)

to decide whether the EXISTING deck is valid.

That is incorrect.

For validation:

INVALID ownership condition must be:

deckCount > ownedCount

NOT:

deckCount >= ownedCount

For duplicate rules:

INVALID condition must be:

deckCount > duplicateLimit

NOT:

deckCount >= duplicateLimit

==================================================
VERY IMPORTANT ARCHITECTURE
==================================================

Separate:

canAddCardToDeck()

from:

validateDeck()

These are different questions.

canAddCardToDeck:

"Can the user add ONE MORE copy?"

validateDeck:

"Is the CURRENT number of copies legal?"

Never use `canAddCardToDeck()` as the validator for cards already present in the deck.

Example:

owned = 1
deck = 1

canAddCardToDeck:
false

validateDeck:
true

This distinction is mandatory.

LEGENDARY RULES
==================================================

Current deck rules:

- Champion is separate from the 25 cards.
- Legendary total maximum = 5.
- Same Legendary CardDefinition cannot be duplicated.
- Normal duplicate rules remain unchanged.

Legendary total max 5

is different from:

same Legendary definition max 1.
