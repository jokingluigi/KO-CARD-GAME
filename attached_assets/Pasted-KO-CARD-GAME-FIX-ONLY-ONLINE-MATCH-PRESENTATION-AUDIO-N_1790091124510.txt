KO CARD GAME — FIX ONLY:
ONLINE MATCH PRESENTATION + AUDIO + NAVIGATION

이번 작업에서는 이미 정상 연결되는 Online Match의
UI / Presentation / Audio / Navigation 문제만 수정한다.

현재 Online 연결 오류는 해결된 문제다.

따라서:

WebSocket architecture
WS ticket
API routing
CORS
Render connection
authentication architecture

를 새로 뜯어고치지 마.

==================================================
이번 작업 대상
==================================================

오직 아래 문제만 수정한다.

1. Online Match 화면에서 뒤로가기 시 메인 화면으로 복귀하지 않음

2. Online Match에서 경기 음악/BGM이 나오지 않음

3. Online Match에서 카드 PLAY 애니메이션이 나오지 않음

4. Online Match에서 공격/피해/회복/버프 등
   기존 게임 연출이 일부 나오지 않음

5. 상대가 Technique을 사용했을 때
   Technique 사용 연출/표시가 제대로 나오지 않음

6. 상대 nickname 표시 문제

7. "상대가 다시 연결되었습니다" 알림이
   계속 화면에 남는 문제

8. 내 턴이 시작됐을 때
   YOUR TURN 계열 알림이 나오지 않는 문제

9. Online Quest 완료 알림이 안 뜨는 문제

10. 반대로 같은 Quest 완료 화면이
    여러 번 반복해서 나타나는 문제

11. 실제 턴은 넘어갔는데 UI가 계속
    "상대의 턴입니다" 같은 이전 턴 표시를 유지하는 문제

이번 작업은 Online Presentation 전용이다.

==================================================
0. FIX-FIRST
==================================================

이번 작업은 조사 보고서가 아니다.

각 문제마다:

재현
→ canonical state/event 확인
→ presentation 연결 확인
→ root cause
→ 실제 수정
→ regression test

순서로 진행한다.

Online connection 자체가 정상이라면
connection 코드를 불필요하게 수정하지 마.

==================================================
중요 원칙
==================================================

Online Match에서도
게임 연출의 source of truth는
server-authoritative canonical Event / GameState여야 한다.

즉 클라이언트가 임의로:

"아마 카드가 사용됐겠지"
"HP가 줄었으니 공격했겠지"

라고 추측해서 animation을 만들지 마.

Server Event
→ Online client receive
→ Presentation Event
→ Animation / Audio / Notification

구조를 사용한다.

가능하면 AI Match와 동일한
presentation system을 재사용한다.

Online 전용으로 게임 로직을 복제하지 마.
