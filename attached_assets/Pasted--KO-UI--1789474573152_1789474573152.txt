현재 KO 카드게임 관리자 페이지에
"카드 프레임 / 테두리 UI 관리"
기능을 추가해줘.

목표:
코드 수정 없이 관리자 화면에서
카드 등급/종류별 테두리 프레임 이미지를 변경할 수 있게 한다.

기존 공통 Card Renderer를 반드시 재사용하고
각 화면별로 프레임 UI를 따로 구현하지 마.

==================================================
1. 관리자 메뉴
==================================================

/admin에:

[카드 프레임 관리]

메뉴 추가.

예:
/admin/card-frames

ADMIN만 접근 가능.

==================================================
2. 관리할 프레임 종류
==================================================

최소 다음 프레임을 개별 관리 가능하게 해.

WRESTLER:
- NORMAL
- LEGENDARY
- CHAMPION

TECHNIQUE:
- NORMAL
- LEGENDARY

현재 실제 프로젝트에 존재하는 rarity/cardType을 기준으로
확장 가능하게 구성해.

Token / Champion Token은 필요하면
기존 WRESTLER 프레임을 재사용하고
이번 단계에서 별도 프레임을 강제로 만들지 마.

==================================================
3. 프레임 이미지 업로드
==================================================

각 프레임에 PNG/WEBP 등
투명 배경 이미지를 업로드할 수 있게 해.

기존 Asset uploader를 재사용.

DB에 Base64 저장 금지.

예:

NORMAL WRESTLER FRAME
[현재 이미지]
[업로드/교체]
[삭제]
[기본값 복원]

==================================================
4. 공통 FrameDefinition
==================================================

데이터 기반으로 관리해.

예:

CardFrameDefinition {
  id
  cardType
  rarity
  frameAssetId
  enabled
  updatedAt
}

기존 frame 설정 구조가 있다면
새 시스템을 중복 생성하지 말고 확장해.

==================================================
5. 실제 카드 전체에 적용
==================================================

Card Renderer는:

cardType
+
rarity

를 기준으로 현재 활성 FrameDefinition을 읽어
프레임을 렌더링해.

관리자가 프레임을 변경하면 다음에서 동일하게 반영:

- 실제 게임
- Deck Editor
- Collection
- Pack Opening
- Shop Preview
- Card Admin Preview

각 화면마다 별도의 프레임 경로를 하드코딩하지 마.

==================================================
6. 프레임 레이아웃 조정
==================================================

프레임 이미지마다 실제 투명 영역/장식 위치가 다를 수 있으므로
관리자에서 최소 다음 값을 조정 가능하게 해.

- frameScale
- frameOffsetX
- frameOffsetY

가능하면 기존 rarity별 frameLayout 구조가 있다면 재사용.

필요하다면 추가로:

- artwork inset top/right/bottom/left
- name panel 위치
- cost 위치
- attack 위치
- health 위치

를 조정 가능하게 해.

하지만 처음부터 지나치게 복잡한 디자인 툴은 만들지 마.

==================================================
7. 실시간 미리보기
==================================================

관리자 화면 오른쪽 또는 하단에
실제 Card Renderer Preview를 제공해.

테스트 카드 하나를 선택해서:

NORMAL
LEGENDARY
CHAMPION
TECHNIQUE

프레임이 실제 카드에서 어떻게 보이는지 즉시 확인.

프레임만 따로 보여주는 Preview가 아니라
실제 카드 UI 전체를 렌더링해.

==================================================
8. 카드 정보 위치
==================================================

프레임 변경 때문에:

- 카드명
- Cost
- Attack
- Health
- 카드 이미지
- 효과 텍스트

가 프레임 밖으로 나가지 않게 해.

WRESTLER:
Attack / Health 표시 유지.

TECHNIQUE:
Attack / Health 영역 없음.

기존 Technique 전용 프레임 구조를 유지해.

==================================================
9. 기존 Artwork 조절 기능 유지
==================================================

기존 카드 이미지:

- imageScale
- imagePositionX
- imagePositionY
- COVER / CONTAIN / CUSTOM

기능은 그대로 유지.

카드 프레임을 변경했다고
기존 카드별 Artwork 위치값을 초기화하지 마.

==================================================
10. 프레임 투명 영역
==================================================

프레임 PNG 자체가 카드 외곽 형태를 정의하도록 해.

Card container에 불필요한 기본 테두리/배경이
프레임 밖으로 보이지 않게 해.

기존 원칙:

- 프레임 이미지가 실제 외곽선을 담당
- artwork만 필요한 영역에서 crop
- frame 자체는 잘리지 않음

유지.

==================================================
11. 선택 Highlight
==================================================

게임에서 카드가 선택될 때
사각형 CSS border로 강조하지 마.

기존처럼 프레임 실루엣을 따라가는:

drop-shadow
또는 mask 기반 highlight

를 유지.

새 프레임으로 바뀌어도
Highlight가 정상 작동해야 한다.

==================================================
12. 기본값 복원
==================================================

각 프레임에:

[기본값 복원]

기능 제공.

잘못된 프레임을 업로드해도
기존 기본 Card Frame으로 되돌릴 수 있어야 한다.

==================================================
13. 비활성 / Asset 오류
==================================================

FrameDefinition이 없거나
asset이 깨졌거나 disabled이면:

기존 기본 프레임으로 안전하게 fallback.

카드 UI가 사라지거나 crash하면 안 된다.

==================================================
14. 모바일
==================================================

관리자 모바일에서도:

- 프레임 선택
- 업로드
- 위치/크기 조정
- Preview

가능하게 해.

390x844 / 430x932 확인.

실제 모바일 게임 카드 크기에도
프레임이 정상 적용되어야 한다.

==================================================
15. 테스트
==================================================

반드시 확인:

- NORMAL WRESTLER 프레임 교체
- LEGENDARY 프레임 교체
- CHAMPION 프레임 교체
- TECHNIQUE 프레임 교체
- 저장 후 새로고침 유지
- 게임/덱/컬렉션/팩깡에서 동일 프레임 사용
- Artwork 위치값 유지
- Attack/Health 위치 정상
- Technique에 Attack/Health 표시 없음
- 프레임 asset 오류 시 fallback
- 기본값 복원
- 모바일 정상

==================================================
16. 수정 금지
==================================================

이번 작업에서 변경하지 마:

- 카드 게임 효과
- CardDefinition 스탯
- rarity 규칙
- Pack 확률
- Collection
- Deck
- Game Engine

카드의 시각적 Frame/UI 설정만 관리한다.

특정 카드 이름으로 프레임을 하드코딩하지 마.

최종 구조:

ADMIN
→ 카드 프레임 관리
→ CardType / Rarity 선택
→ 프레임 업로드
→ 크기/위치 조정
→ 실제 Card Preview
→ 저장

↓

공통 Card Renderer

↓

게임 / 덱 / 컬렉션 / 팩깡 등
모든 화면에 동일하게 적용

여기까지만 구현해.
