현재 KO 카드게임의 선수 카드 목록에 아래 카드들의 최신 수치/효과를 반영하고,
실제 Match Engine에서 모든 효과가 작동하도록 구현해줘.

중요:
- 기존 CardDefinition이 이미 존재하면 새 카드를 중복 생성하지 말고 기존 Definition을 업데이트.
- 존재하지 않는 경우에만 새 Definition 생성.
- 카드 이름 하드코딩으로 Match Engine을 구현하지 말 것.
- 기존 Effect DSL / Structured Effect / Event / Action 시스템을 최대한 재사용.
- 단순히 카드 설명 텍스트만 저장하고 끝내지 말고 실제 Executor까지 구현.
- 기존 이미지, 태그, Rarity, 음악 등 이미 설정된 메타데이터는 유지.
- 카드 밸런스를 임의로 변경하지 말 것.

==================================================
0. 이번 작업에서 먼저 변경할 공통 규칙
==================================================

--------------------------------------------------
A. SUMMON은 등장 효과를 발동하지 않는다
--------------------------------------------------

기존 규칙을 변경한다.

앞으로:

1. 손에서 WRESTLER 카드를 정상 PLAY
→ 등장 효과 발동 O

2. 다른 카드 효과로 WRESTLER를 SUMMON
→ 등장 효과 발동 X

3. Token을 효과로 SUMMON
→ 등장 효과 발동 X

4. 묘지에서 REVIVE / RESURRECT
→ 등장 효과 발동 X

즉:

PLAY_FROM_HAND
와
SUMMON / REVIVE

를 반드시 구분한다.

가능하면 field entry event에:

entryCause:
- PLAY_FROM_HAND
- SUMMON
- REVIVE
- CHAMPION_DEPLOY
- 기타 필요한 기존 원인

형태의 정보를 넣어라.

ON_ENTER / 등장 효과는 기본적으로:

entryCause === PLAY_FROM_HAND

일 때만 발동.

단순히 BOARD에 들어왔다는 이유만으로 등장 효과를 실행하면 안 된다.

--------------------------------------------------
중요: Champion Token
--------------------------------------------------

기존의:

DEPLOY_CHAMPION_TOKEN

은 일반 SUMMON과 별도 Action이다.

챔피언 토큰 시스템은 이번 변경으로 망가뜨리지 마.

특히 기존 판도라 Champion Token의
특수 Deploy 효과/처리는 그대로 유지해야 한다.

현재 DEPLOY_CHAMPION_TOKEN이 내부적으로 SUMMON과
섞여 있다면 이번에 둘을 명확하게 분리해라.

--------------------------------------------------
Generated와 Summon은 별개
--------------------------------------------------

새 CardInstance를 효과로 생성해서 필드에 SUMMON했다면:

isGenerated = true
CARD_GENERATED 발생
SUMMON 발생

하지만:

등장 효과는 발동하지 않는다.

따라서 예거 Quest의
"선수 카드 생성" 카운트에는 포함될 수 있지만
그 Token/Wrestler 자신의 등장 효과는 발동하지 않는다.

==================================================
B. 묘지 부활 시 0 HP 금지
==================================================

묘지에 있는 선수는 RETIRE 당시 currentHealth가
0 이하일 수 있다.

REVIVE 시 그 값을 그대로 가져오면 안 된다.

부활 성공 시:

currentHealth = 현재 유효한 maximumHealth

로 복구해서 BOARD에 배치.

최소한:

currentHealth > 0

인 상태로 부활해야 한다.

0 HP / 음수 HP 상태로 부활해서
즉시 이상한 Board Instance가 생기는 것을 금지.

부활은 기존 CardInstance 이동으로 처리하며:

isGenerated를 새로 붙이지 않는다.
CARD_GENERATED도 발생하지 않는다.
등장 효과도 발동하지 않는다.

"효과 중에 공격력이 증가하면,

중요:
기존의 "필드에 있는 동안" 장소 제한을 제거한다.

도쿵이:

HAND
DECK
BOARD

어디에 있든
Effect에 의해 Attack이 증가하면 발동 가능.

예:

Attack +1
→ Health +1

Attack +2
→ Health +2

Attack +3
→ Health +3

Attack 증가가 실제로 발생한 수치(delta)를 사용.

예:
Attack 3 → 5
delta = +2
→ Health +2

Health 증가 시 카드의 스탯 자체가 증가하도록:

maximumHealth += delta

BOARD에 존재한다면:
currentHealth도 동일하게 += delta.

HAND / DECK에서는 저장된 Health Stat 증가.

중요:
기본 카드 생성/초기 스탯 세팅은 발동하지 않는다.

"Effect 때문에 Attack이 증가"했을 때만 발동.

같은 Effect에서 Attack 증가가 임시 Modifier라면
기존 Modifier duration 시스템을 재사용해서
연결된 Health Modifier도 동일한 duration을 사용.

카드 표시 텍스트에는 duration 설명을 추가하지 말고
위의 카드 텍스트 그대로 사용.
