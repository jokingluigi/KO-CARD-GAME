현재 KO 카드게임의 기존 공격 애니메이션을 유지하면서
다음 2가지만 수정/추가해줘.

1. 공격 충돌 시 화면 흔들림 추가

공격 카드가 타겟과 실제 충돌하고 DAMAGE가 적용되는 순간
짧은 screen shake를 발생시켜줘.

중요:
흔들림 강도는 카드의 공격력 자체가 아니라
이번 공격으로 실제 적용된 DAMAGE 수치를 기준으로 한다.

예:
실제 피해 0
→ 흔들림 없음

1 DAMAGE
→ 아주 약한 흔들림

2~3 DAMAGE
→ 약한 흔들림

4~5 DAMAGE
→ 확실한 흔들림

6~7 DAMAGE
→ 강한 흔들림

8 이상 DAMAGE
→ 매우 강하고 묵직한 흔들림

피해가 높을수록 차이가 확실히 느껴져야 한다.
1 피해와 8 피해가 비슷하게 보이면 안 된다.

단 흔들림 시간은 짧게 유지하고
고피해에서도 플레이가 불편할 정도로 과하게 만들지 마.

추천:
0 DAMAGE = NONE
1 = VERY_LIGHT
2~3 = LIGHT
4~5 = MEDIUM
6~7 = HEAVY
8+ = VERY_HEAVY

실제 최종 damage result를 사용해서 계산해.

예:
공격력 8이지만 회피로 피해 0
→ screen shake 없음

공격력 8인데 피해 감소로 실제 3 피해
→ 3 피해 강도의 shake

카드 → 카드,
카드 → Champion
둘 다 적용.

shake는 게임 전체 레이아웃을 영구 이동시키지 말고
게임 화면의 visual wrapper에 짧은 transform animation으로 적용해.

애니메이션 종료 후 transform이 반드시 정상 위치로 복구되어야 한다.

prefers-reduced-motion에서는 shake를 크게 줄이거나 제거해.

2. 공격 카드가 2장으로 보이는 버그 수정

현재 공격 애니메이션 중:

원래 필드 슬롯의 카드가 그대로 남아 있고
별도의 움직이는 공격 카드가 생성되어

같은 카드가 동시에 2장 보이는 문제가 있다.

이 버그를 수정해.

공격 애니메이션 동안에는 시각적으로 공격 카드가 정확히 1장만 보여야 한다.

현재 구조가 animation clone/overlay를 사용하는 경우:

공격 시작
→ 원래 슬롯 카드의 공간(layout)은 유지
→ 원본 카드 visual만 임시로 숨김
→ animation clone 1장만 이동
→ 공격/복귀 애니메이션 완료
→ clone 제거
→ 원본 카드 다시 표시

방식으로 처리해.

중요:
원본을 display:none으로 해서 슬롯 layout이 무너지거나
주변 카드가 움직이면 안 된다.

가능하면:
visibility:hidden
또는
opacity:0

등으로 원래 자리의 공간은 유지해.

애니메이션 clone은:
- 실제 GameState 카드가 아님
- 클릭/공격/Target 대상이 되면 안 됨
- pointer-events:none
- 애니메이션 종료 후 반드시 제거

공격 도중 React re-render가 발생해도
원본 + clone이 동시에 보이지 않도록 해.

공격자가 원래 위치로 돌아오는 순간
clone과 원본이 겹쳐 두 장처럼 보이는 프레임도 없게
애니메이션 완료 시점에 정확히 교체해.

3. 기존 공격 흐름 유지

기존:

wind-up
→ 카드 돌진
→ 충돌
→ 공격/피격 SFX
→ damage
→ screen shake
→ hit reaction
→ 공격자 복귀

흐름을 유지해.

RETIRE가 발생하면 기존 RETIRE 연출로 이어지게 해.

4. 기존 시스템 보호

다음은 변경하지 마:
- 전투 계산
- Damage 규칙
- Effect Library
- 공격 가능 여부
- 도발/러쉬/기습
- 카드 데이터

공격 애니메이션 UI와 screen shake 관련 코드만 최소 수정해.

실제로:
- 1 피해
- 3 피해
- 5 피해
- 8+ 피해
- 회피로 0 피해
- 카드→카드
- 카드→Champion

공격을 테스트하고,

✓ 피해량에 따라 shake 차이가 확실함
✓ 공격 중 카드가 절대 2장으로 보이지 않음
✓ 공격 후 원본 카드가 정확히 원래 슬롯에 표시됨

을 확인한 뒤 종료해줘.
