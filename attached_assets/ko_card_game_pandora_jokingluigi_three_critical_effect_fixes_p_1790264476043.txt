KO CARD GAME — CRITICAL GAMEPLAY EFFECT FIX BUNDLE
PANDORA ALLY TARGETING + JOKING LUIGI ADJACENT SUMMON/TAUNT + PANDORA ATTACK ABSORPTION

현재 실제 플레이에서 아래 3개 버그가 발생한다.

BUG 1 — Champion Pandora Ability
판도라의 고유 능력을 아군 선수 카드에게 사용할 수 없다.
사용자가 "선택한 대상"에게 데미지를 주는 능력이라면 아군 선수도 합법적인 선택 대상이어야 한다.

BUG 2 — 조킹루이지
조킹루이지가 등장했을 때 무작위 선수 카드를 자신의 양옆에 소환해야 하는데 소환하지 않는다.
그리고 도발도 자기 자신에게만 붙는 잘못된 동작이 발생한다.
의도는 조킹루이지 자신이 아니라 "바로 양옆의 아군 선수"에게 도발을 주는 것이다.

BUG 3 — 판도라(필드 카드)의 공격력 흡수
판도라가 FIELD에 있고 그 판도라가 상대 선수 카드를 RETIRE 또는 DESTROY시켜도
피해자의 공격력을 자신의 공격력에 더하지 않는다.

이 3개를 단순 UI 수정이나 카드 이름 hardcode로 때우지 말고,
Target Resolver / ADJACENT slot logic / SUMMON placement / persistent causal-removal listener를
실제 Action → Event → GameState 경로에서 고친다.

8. 조킹루이지 무작위 선수 소환
==================================================

각 직접 인접 슬롯이 비어 있으면
그 슬롯에 무작위 WRESTLER 카드 1장을 소환한다.

최대:
왼쪽 1장 + 오른쪽 1장 = 2장

이미 점유된 인접 슬롯:
- 기존 카드 overwrite 금지
- 그 슬롯에는 summon 하지 않음
- 기존 adjacent ally는 TAUNT 대상이 될 수 있음(최신 Source Text 의미에 따라)

중요:
소환은 source 자신이 들어간 뒤의 실제 FIELD slot 위치를 기준으로 계산.

random pool:
현재 프로젝트의 canonical random WRESTLER pool 사용.
PUBLISHED/allowed definition 규칙 유지.
Token/Champion/Technique가 무작위 WRESTLER pool에 잘못 섞이지 않게 한다.
deterministic RNG 사용.
Math.random 금지.

동일 roll이 양쪽에서 같은 definition을 뽑을 수 있는지 여부는
현재 random-generation 공식 규칙을 따른다.
임의 unique restriction 추가 금지.

==================================================
9. 조킹루이지 TAUNT 순서
==================================================

필요하면 effect sequence를 명확히 보장:

1. 조킹루이지 FIELD에 들어감
2. 왼쪽/오른쪽 직접 인접 empty slot에 random WRESTLER summon
3. 현재 직접 인접한 OWN WRESTLER들을 resolve
4. 그 adjacent allies에 TAUNT 부여
5. SELF는 절대 TAUNT 대상 아님

즉:

[empty] [조킹루이지] [empty]

효과 후 예:
[random A] [조킹루이지] [random B]

TAUNT:
random A = true
조킹루이지 = false
random B = true

==================================================

- Structured Effect에 SUMMON clause 자체가 누락됐는지

13. 공격력 흡수는 ENTER_FIELD destroy에만 한정하면 안 됨
==================================================

반드시 다음을 포함:

A. 이 카드의 등장 DESTROY 효과로 제거
B. 이 카드의 공격/combat damage로 상대 WRESTLER RETIRE
C. 이 카드 자신의 effect damage로 상대 WRESTLER RETIRE
D. 이 카드가 가진 다른 causal effect로 RETIRE/DESTROY

Source가 "자신이 리타이어 혹은 파괴 시킨"이라고 하면
단순 LAST_DESTROYED_TARGETS ENTER_FIELD snapshot만으로는 부족하다.

Persistent causal listener가 필요.
