2. Replit KO가 어떤 Database를 사용하는지 확인해주세요.

3. 현재 실제 Production KO CARD GAME이 어떤 Backend/API와 Database를 사용하는지 코드와 환경설정 기준으로 확인해주세요.

4. KO 관리자 사이트가 카드와 Champion을 수정할 때 실제로 어느 Backend/API와 Database에 요청을 보내는지 확인해주세요.

5. 아래 3개가 같은 데이터 원본을 바라보는지 비교해주세요.

* Production KO CARD GAME
* Replit에서 실행되는 KO

6. 서로 다르다면 정확히 무엇이 다른지 알려주세요.

예:

* API URL이 다름
* Database URL이 다름
* Supabase 프로젝트가 다름
* Replit이 로컬 DB를 사용 중
* Production만 별도 환경변수를 사용 중
* 관리자 사이트가 다른 Backend를 사용 중
* Seed 또는 로컬 데이터가 Production DB보다 우선해서 사용되고 있음

7. 관련된 환경변수 이름도 알려주세요.

예:

* DATABASE_URL
* SUPABASE_URL
* API_URL
* VITE_API_URL
* BACKEND_URL

단, **Secret 값이나 API Key 실제 값은 절대 출력하지 마세요.**
주소를 비교할 필요가 있다면 민감정보가 아닌 endpoint/domain 수준만 알려주세요.

8. 카드와 Champion 데이터의 최종 Source of Truth가 현재 어디인지 확인해주세요.

즉,
“관리자 사이트에서 수정한 데이터가 최종 기준인지”
“코드 내부의 seed/static data가 기준인지”
“별도 DB가 기준인지”
를 명확히 알려주세요.
