KO CARD GAME — DECK EDITOR COMPACT DECK LIST REDESIGN
한 화면에 덱 전체가 보이도록, 스크롤 없는 Hearthstone-style 텍스트 덱 목록으로 변경

현재 문제:
Deck Editor에서 현재 덱에 들어간 카드 목록을 보려면 아래로 스크롤해야 해서
덱 전체 구성이 한눈에 안 들어온다.

목표:
덱 편집 화면의 "현재 덱" 영역은
가능하면 한 화면 안에서 25장 전체 구성이 보이도록
이미지 중심 카드 목록이 아니라
텍스트 중심의 compact deck list로 변경한다.

참고 UX:
Hearthstone 덱 구성 목록처럼
카드 이름 + 비용 + 수량 중심으로 촘촘하게 보여주는 방식.

중요:
카드 탐색/보유 카드 브라우저는 기존 비주얼을 유지해도 되지만,
"현재 덱에 들어간 카드 목록"은 한눈에 읽히는 compact text list가 우선.

==================================================
1. 기본 구조
==================================================

Deck Editor를 두 영역으로 분리:

LEFT / MAIN:
카드 탐색/검색/필터/보유·미보유 카드

RIGHT / DECK PANEL:
현재 덱 25장 compact text list

Desktop에서는:
덱 패널이 화면 안에 고정된 높이 안에서
25장 전체 구성을 스크롤 없이 보여주는 것을 목표로 한다.

==================================================
2. 덱 목록 표시 형식
==================================================

각 row는 최대한 얇고 정보 밀도 높게:

[비용] 카드 이름                         x2

예:

1  좀비                                  x2
2  작은 하마                             x1
2  판도라                                x2
3  예거                                  x1
4  블랙마카롱                            x2
...

최소 표시 정보:

- Cost
- Card Name
- Quantity

선택적으로:
- rarity 작은 아이콘/점
- tag 표시
- card type 아이콘

하지만 한 화면 가독성을 해치면 넣지 말 것.

==================================================
3. 스크롤 없는 25장 전체 표시
==================================================

중요:
"한 화면에 25장의 모든 카드 구성이 보인다"가 목표.

가능하면:
- row height를 compact하게
- font size는 읽을 수 있는 최소 수준
- gap 최소화
- card image 미표시
- unnecessary padding 제거

하지만 너무 작아서 읽기 어려우면 실패.

Desktop 기준에서 25 rows가 너무 길면:
"카드 인스턴스 25줄"이 아니라
동일 카드 이름은 한 row로 합치고 quantity 표시.

예:
Zombie x2
Pandora x2

이렇게 unique card row로 압축.

즉:
25장 deck = 최대 25 rows가 아니라
실제 unique definitions 수만큼 rows.

==================================================
4. 정렬
==================================================

기본 정렬:
1. Cost ASC
2. Name ASC

동일 cost는 name 정렬.

Champion은 deck 25장과 별도이므로
Champion row는 deck list 상단 또는 별도 small section.

예:

CHAMPION
Pandora

DECK 25/25
1 Zombie x2
2 ...
...

==================================================
5. 카드 클릭 interaction
==================================================

Deck list row 클릭:

- 해당 카드 상세 정보 표시
또는
- 기존 카드 inspector/highlight 기능과 연동

더블클릭/우클릭은 필수 아님.

삭제:
row 오른쪽에 작은 `-` 버튼 또는 클릭 시 remove action.

예:

[2] Small Hippo                         x2   [-]

수량 2에서 한 번 제거:
x2 → x1

수량 1에서 제거:
row 제거

==================================================
6. Hover / ALT 정보
==================================================

기존 ALT 카드 정보 토글과 연동.

ALT Info Mode ON:
Deck list row hover/select 시
해당 카드 상세 정보 표시.

Deck list 자체가 text-only여도
카드 상세 보기 접근성은 유지.

==================================================
7. 색상/시각 표현
==================================================

과도한 장식 금지.

읽기 쉬운 compact list.

가능하면:
- cost는 왼쪽 aligned
- name은 가운데 flexible
- quantity는 오른쪽
- Legendary/Champion rarity는 작은 accent 정도
- hover highlight
- selected row highlight

전체 카드 배경 이미지 사용 금지.
deck panel에서 card art 사용하지 말 것.

==================================================
8. 덱 상태 요약
==================================================

Deck panel 상단에 compact summary:

DECK 23 / 25

Normal: 18
Legendary: 5
Champion: Pandora

또는 현재 deck-rule 관련 핵심만.

Legendary max 5 규칙 위반 시:
5/5 정상
6/5 빨간 경고

==================================================
9. 덱 유효성
==================================================

현재 공식 규칙 유지:

- 정확히 25 cards
- Champion separately
- Legendary max 5
- same Legendary duplicate forbidden
- normal duplicate rule 유지
- token direct-add 금지
- invalid legacy deck auto-cut/delete 금지
- invalid status 표시

Deck list redesign 때문에
validation logic 바꾸지 말 것.

==================================================
10. 미보유 카드와 연동
==================================================

이전 UX 유지:

카드 브라우저에서 미보유 카드도 보임.

미보유 카드 클릭:
→ Craft UI

미보유 카드는 덱 list에 직접 추가 금지.

제작 후:
owned state update
→ 다시 클릭하면 deck add 가능

==================================================

좌측 card browser + 우측 compact deck panel

Tablet:
deck panel width 줄이되 text truncate 가능
hover/title 또는 inspector로 full name 확인

Mobile:
25장 전체를 한 화면에 강제로 욱여넣지 말 것.
모바일에서는:
- collapsible compact list
또는
- deck tab
또는
- bottom sheet

모바일 UX는 읽기 가능성이 우선.

"스크롤 없음" 목표는 Desktop Deck Editor의 현재 덱 영역 기준.

==================================================
12. 너무 긴 카드 이름
==================================================

긴 이름은:

- 1줄 유지
- ellipsis
- hover/title/inspector에서 full name 확인

row height 늘어나서 deck panel이 길어지면 안 됨.

==================================================
13. 수량 표현
==================================================

동일 card definition은 하나의 row로 합침.

예:
Zombie x2

not:
Zombie
Zombie

단 서로 다른 ALT art가 같은 CardDefinition이라면
deck identity 기준으로 합쳐야 함.
ALT appearance 때문에 separate deck slot처럼 보이면 안 됨.

카드 definition cost source 사용.
