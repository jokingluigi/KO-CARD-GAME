이번 작업은 세 가지를 한 번에 처리한다.

A. 모든 SUPPORTED 항목의 원문 ↔ Analyzer output ↔ 현재 저장 Structured Effect 3-way semantic audit
B. 최신 보고서의 ANALYSIS_FAILED 11개 generic 처리
C. 새 전역 규칙: HAND/DECK에 있는 WRESTLER의 현재 체력은 절대로 1 미만이 될 수 없음

중요:
단순히 ANALYSIS_FAILED 숫자를 0으로 만드는 것이 목적이 아니다.
원문을 누락하거나 원문에 없는 효과를 추가했는데도 SUPPORTED로 판정하는 false-positive를 제거해야 한다.

==================================================
0. 새 공식 규칙 — HAND / DECK WRESTLER HEALTH FLOOR
==================================================

새 공식 게임 규칙:

HAND 또는 DECK에 있는 WRESTLER 카드의 현재 체력(current health)은
절대로 1보다 낮아질 수 없다.

즉:

HAND WRESTLER health = 1
→ health -1 effect
→ 실제 결과 health = 1

HAND WRESTLER health = 1
→ health -5 effect
→ 실제 결과 health = 1

DECK WRESTLER health = 2
→ health -5 effect
→ 실제 결과 health = 1

FIELD에는 이 floor를 적용하지 않는다.

FIELD WRESTLER:
health <= 0
→ 기존 canonical RETIRE
→ GRAVEYARD
→ RETIRE effect

GRAVEYARD에도 이 HAND/DECK floor를 임의 적용하지 않는다.

==================================================
1. Health Floor 적용 범위
==================================================

다음 모든 stat mutation path에서
HAND/DECK WRESTLER health minimum = 1이 보장되어야 한다.

- BUFF with negative health
- MODIFY_STAT HEALTH
- SET_STAT HEALTH
- SET_STATS health
- generatedModifiers.health
- copied/generated card modifiers
- queued effect
- delayed effect
- listener effect
- SCRIPT_V1 EFFECT
- grantedText effect
- Champion Ability
- Quest Reward
- Admin-generated structured effect
- AI Match
- Online Match
- reconnect/reserialization 이후 효과

즉 특정 Action 하나에만 clamp를 넣지 말고
가능하면 canonical stat mutation layer에서 zone-aware invariant로 처리한다.

==================================================
2. Health Floor 의미
==================================================

중요:

"시도한 감소량"이 아니라 "실제 적용된 결과"가 기준.

예:

HAND health 1
effect health -1
→ final health 1
→ actualHealthDelta = 0

HAND health 3
effect health -5
→ final health 1
→ actualHealthDelta = -2

이 실제 delta를 event/history/stat-trigger에 사용.

clamp 때문에 실제 값이 변하지 않았다면
"체력이 감소했다" 계열 후속 trigger를 임의 발생시키지 마.

==================================================
3. FIELD와 혼동 금지
==================================================

절대 전역 Math.max(1, health)로 만들지 마.

그렇게 하면 FIELD 카드가 죽지 않는다.

반드시 zone-aware:

if card.type === WRESTLER && zone in [HAND, DECK]
→ currentHealth >= 1

else
→ 기존 규칙

FIELD lethal:
0 이하 가능
→ RETIRE

==================================================
4. Max Health와의 관계
==================================================

사용자가 지정한 새 규칙은 "현재 체력" floor다.

MAX_HEALTH를 무조건 1 이상으로 바꾸는 별도 규칙을 임의 추가하지 마.

단 현재 엔진 invariant가:

currentHealth <= maxHealth

를 강제하고 있고
HAND/DECK currentHealth=1을 유지하려면 maxHealth 조정이 불가피한 경우:

- 기존 stat model 확인
- 최소한의 invariant-preserving 처리
- 최종 보고에 명시

`MODIFY_MAX_HEALTH` semantics를 몰래 바꾸지 마.

==================================================
5. Hidden Zone에서 RETIRE 금지
==================================================

HAND/DECK WRESTLER는 health reduction으로 0 이하가 되지 않으므로
그 stat reduction만으로 RETIRE하지 않는다.

즉:

HAND health 1
→ -3 health
→ health 1
→ GRAVEYARD 이동 없음
→ RETIRE event 없음
→ RETIRE effect 없음

DECK도 동일.

==================================================
6. Board 진입 시
==================================================

HAND/DECK에서 감소 효과를 받은 WRESTLER가 나중에 FIELD에 들어오면
clamp된 실제 체력 값을 가지고 정상 진입한다.

예:

HAND base/current health 1
→ health -2 attempt
→ HAND health 1
→ PLAY_FROM_HAND
→ FIELD health 1

그 이후 FIELD에서 1 damage:
→ health 0
→ RETIRE

==================================================
7. Generated Card
==================================================

생성되는 WRESTLER가 HAND/DECK로 들어갈 때:

generatedModifiers.health 결과가 0 이하라면
최종 current health는 1.

예:

base health 2
generatedModifiers.health = -5
destination HAND
→ final current health 1

단 FIELD에 직접 SUMMON되는 카드의 stat 생성 규칙은
기존 summon semantics를 그대로 따른다.
FIELD lethal/invalid spawn semantics를 임의로 바꾸지 마.

==================================================
8. HAND Stat Trigger와 actual delta
==================================================

현재 프로젝트 공식 규칙상
HAND의 실제 stat increase는 일부 trigger를 발생시킬 수 있다.

이번 health floor와 결합 시:

HAND health 1
→ -1 attempt
→ actual delta 0

따라서 actual delta 기반 trigger/history에는 0으로 기록.

반대로:

HAND health 3
→ -5 attempt
→ final 1
→ actual delta -2

실제 변경량 -2.

원문 각 clause가 Analyzer에 정확히 1:1 대응하는지 확인.

11. 현재 반드시 재검사할 알려진 예

37. 최종 완료 조건
==================================================

다음이 모두 충족되어야 완료:

1. SUPPORTED가 원문 전체 semantic을 실제로 커버함.
2. 원문 clause 누락 0.
3. 원문에 없는 hallucinated effect 0.
4. 최신 ANALYSIS_FAILED 11개를 generic하게 처리.
5. HAND/DECK WRESTLER current health가 항상 최소 1.
6. FIELD health floor는 적용하지 않아 정상 RETIRE 유지.
7. health floor는 모든 stat mutation 경로에서 동일.
8. clamp 후 actual delta가 정확히 기록됨.
9. hidden-zone stat reduction으로 RETIRE 발생하지 않음.
10. stored effect drift는 production 자동수정 없이 식별/보고.
11. 기존 RETIRE/DESTROY 규칙 회귀 없음.
12. Analyzer → Save → Runtime semantic 일치.
13. Production 데이터 직접 수정 없음.

이 범위 전체를 구현·검증한 뒤 멈춰라.
