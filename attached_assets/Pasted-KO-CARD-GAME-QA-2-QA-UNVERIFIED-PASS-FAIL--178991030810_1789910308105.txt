이번 목표는 이전 QA에서 UNVERIFIED로 남은 카드 효과를
실제 결과까지 검증해서 최대한 PASS/FAIL로 확정하는 것이다.

이전 결과:

- published cards: 49
- PASS: 17
- FAIL: 0
- UNVERIFIED: 32
- champions: 4
- AI full match: 정상 종료
- 예거 Quest required count가 8로 되어 있었으나
  공식 게임 규칙은 7회가 맞다.

==================================================
2. 기존 UNVERIFIED 32장 집중 검사
==================================================

이전 QA 결과 파일을 읽어서
UNVERIFIED 카드 목록을 자동으로 가져와라.

이미 PASS인 카드를 반복하는 것보다
UNVERIFIED를 우선한다.

각 카드마다 현재 description과 effect config를 읽고
설명에서 검증 가능한 기대 결과를 명시적으로 작성한 뒤 테스트한다.

예:

초기 상태
→ Action
→ 예상 GameState 변화
→ 실제 GameState 변화
→ Event Log

형태로 검증.

단순히:
- crash가 없다
- Action이 accepted 됐다
- effect handler가 호출됐다

만으로 PASS 처리하지 마.

실제 수치/zone/status/target/result까지 일치해야 PASS.

==================================================
3. Token 전수 검사
==================================================

다음 Token들을 일반 손패 플레이가 아니라
실제 생성 경로로 검사:

- 용병
- 강화 용병
- 잔상
- 위리녀
- 좀비
- 챔피언 판도라(폭주)

각각 가능한 실제 경로:

SUMMON
CARD_GENERATED
REVIVE
CHAMPION_DEPLOY

중 해당 Token의 올바른 경로를 사용.

검사:

- isGenerated
- card definition
- stats
- keywords
- entryCause
- ON_ENTER 발동 여부
- board slot
- graveyard 이동
- RETIRE
- Champion Token 특수 규칙

특히 SUMMON된 WRESTLER는
등장/ON_ENTER가 발동하지 않는지 확인.

==================================================
4. 카드 설명과 실제 결과 직접 비교
==================================================

각 효과마다 최소 하나 이상의
명시적인 assertion을 작성.

예:

"공격력 +2"
→ 정확히 +2인지

"다음 턴 골드 +1"
→ 다음 personal turn에만 +1인지

"무작위 선수"
→ Technique 제외 여부

"다른 아군"
→ 자기 자신 제외 여부

"묘지에서 손으로"
→ graveyard 감소 + hand 증가 + 동일 instance인지

"제거"
→ graveyard가 아니라 removedFromGame인지

등을 검사.
