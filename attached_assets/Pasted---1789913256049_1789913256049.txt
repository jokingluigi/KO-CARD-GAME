==================================================
추가 중요 패치: 인게임 카드 정보/키워드 가독성 개선
==================================================

이번 tags 시스템 추가와 함께
실제 경기 화면의 카드 정보 가독성을 개선해줘.

중요:
게임 규칙이나 카드 효과 수치는 변경하지 말 것.
이번 항목은 UI/UX 표시 개선이다.

현재 문제:

1. 게임 중 ALT를 눌렀을 때 나오는 카드 정보의 글자가 너무 작다.
2. 기습 / 러쉬 / 도발 등의 키워드가 카드 위에 표시되지만 너무 작아서 읽기 어렵다.
3. 새로 추가되는 카드 tags도 경기 중 쉽게 확인할 수 있어야 한다.

==================================================
1. ALT 카드 정보창에 태그 추가
==================================================

기존 ALT 카드 정보/Inspector 기능을 유지하면서
카드의 tags를 표시한다.

예:

태그
[용병] [인간]

또는:

태그: 용병 · 인간

조건:

- tags가 []이면 태그 영역 숨김
- 최대 3개
- 카드 definition의 canonical tags 사용
- 카드 이름에서 태그를 추론하지 말 것
- Token / generated card도 해당 definition의 tags 표시

키워드도 같은 정보창에서 명확하게 보여줘.

예:

키워드
[도발] [러쉬]

태그
[용병] [인간]

키워드와 태그는 시각적으로 서로 구분되어야 한다.

==================================================
2. ALT 카드 정보창 글씨 크기 대폭 개선
==================================================

현재 ALT Inspector의 전체 typography를 조사하고
실제 경기 중 한눈에 읽을 수 있을 정도로 키워줘.

특히 다음 항목:

- 카드 이름
- 비용
- 공격력
- 체력
- 카드 타입
- 키워드
- 태그
- 효과 설명

을 개선.

목표:

카드 효과 설명이 가장 작은 글씨가 되더라도
1366×768 환경에서 정상적으로 읽을 수 있어야 한다.

너무 작은 9px/10px/11px 수준의 텍스트를 사용하지 말 것.

권장 범위는 현재 UI를 보고 조정하되 대략:

카드 이름:
20~26px

공격력 / 체력 / 비용:
18~24px

키워드 / 태그 badge:
14~17px

효과 설명:
15~18px

보조 정보:
13~15px

단 무조건 이 숫자를 하드코딩하기보다
현재 responsive layout에 맞게 clamp() 등을 사용해도 된다.

예:

font-size: clamp(15px, 1.1vw, 18px);

가독성이 최우선.

==================================================
3. ALT 정보창 크기 자체도 개선
==================================================

글자만 키우다가 내용이 잘리면 안 된다.

Inspector panel/card preview 자체도
필요하면 현재보다 크게 확장.

Desktop 기준:

- 1920×1080
- 1600×900
- 1366×768

에서 모두 검사.

화면 밖으로 잘리거나
효과 설명이 카드 아래로 넘치지 않아야 한다.

필요하면:

- panel width 확대
- padding 확대
- 내부 section spacing 확대
- 설명 영역 max-height + scroll

등을 적용.

단 한 카드의 정보를 읽으려고
매우 좁은 스크롤 박스를 만들지는 말 것.

==================================================
4. 필드 카드 위 키워드 가독성 개선
==================================================

현재 경기 중 카드 위에 표시되는:

- 기습
- 러쉬
- 도발
- 회피
- 침묵
- 기절
- 기타 실제 표시되는 keyword/status

badge를 조사해.

현재보다 확실히 크게 만든다.

중요:
"조금 키운 정도"가 아니라
실제 경기 중 카드가 축소된 상태에서도
텍스트를 바로 읽을 수 있어야 한다.

각 badge는:

- 충분한 font-size
- 충분한 padding
- 강한 foreground/background contrast
- 겹치지 않는 간격
- 카드 그림과 구별되는 배경

을 사용.

추천 최소 방향:

font-size:
12~14px 이상

font-weight:
600~700 정도

padding:
적당한 horizontal/vertical padding

카드 크기에 따라 clamp 사용 가능.

==================================================
5. 키워드 여러 개 있을 때
==================================================

예:

[도발] [러쉬] [회피]

처럼 여러 keyword를 가진 카드도 지원.

카드 영역을 벗어나지 않게:

- wrap
또는
- compact horizontal layout

을 사용.

단 글자를 다시 작게 줄여서 해결하지 말 것.

최대 몇 개가 표시될 수 있는지 현재 engine 데이터를 조사하고
최악 조건에서도 readable하게 만든다.

==================================================
6. Keyword와 Status 구분
==================================================

가능하면 현재 architecture에서 다음을 구분해서 표시:

고유/지속 keyword:
- 도발
- 러쉬
- 기습
- 회피 등

상태:
- 침묵
- 기절
- 기타 temporary status

하지만 기존 데이터 구조상 구분이 어렵다면
이번 작업 때문에 게임 모델을 과도하게 뜯지 말 것.

최소한 모든 표시가 읽기 쉽게 만드는 것이 우선.

==================================================
7. ALT 동작 유지
==================================================

기존 ALT Inspector 동작 방식을 깨뜨리지 말 것.

현재:

ALT 누름
→ 카드 상세 정보 표시

동작을 유지.

확인:

- 손패 카드
- 내 필드 카드
- 상대 필드 카드
- 가능하면 graveyard/detail 대상

기존 지원 범위가 있다면 모두 유지.

ALT를 떼면 기존 의도대로 닫히는 동작도 유지.

마우스 위치/hover와 연동되는 기존 UX가 있다면
그것도 깨뜨리지 않는다.

==================================================
8. ALT + 태그 + 키워드 예시
==================================================

예를 들어 카드가:

이름: 레이븐
비용: 2
공격력: 2
체력: 2
keywords: ["러쉬"]
tags: ["용병", "악마"]

이라면 ALT 정보에는 최소:

레이븐

비용 2
공격력 2
체력 2

키워드
[러쉬]

태그
[용병] [악마]

효과 설명
...

이 명확하게 보여야 한다.

==================================================
9. 카드 본체에는 태그를 강제로 표시하지 않음
==================================================

중요:

태그는 인게임 카드 본체에
항상 전부 표시하지 않아도 된다.

카드 본체는 이미 공격력/체력/비용/키워드가 있어서
시각적 과밀을 피한다.

이번 기준:

필드 카드 본체:
→ 전투 관련 keyword/status는 크게 표시

ALT Inspector:
→ keyword + tags + 상세 설명 모두 표시

Card Detail:
→ tags 표시

이 구조를 우선한다.

==================================================
10. 카드 효과 설명 가독성
==================================================

ALT 정보창의 효과 설명은 특히 중요하다.

다음 문제를 방지:

- 지나치게 작은 글씨
- 너무 좁은 line-height
- 카드 배경 이미지 때문에 글씨 안 보임
- 긴 설명이 잘림
- 텍스트가 frame 밖으로 넘침

적절한:

font size
line-height
background contrast
padding
word wrapping

적용.

설명에는 최소 line-height 1.35~1.5 정도를 검토.

==================================================
11. 반응형 확인
==================================================

최소 아래 화면 기준으로 실제 렌더 확인:

1920×1080
1600×900
1366×768

가능하면 작은 노트북 환경도 확인.

목표:

1366×768에서도
ALT 카드 설명과 키워드가 정상적으로 읽혀야 한다.

해상도가 작다고 글자를 9~10px까지 줄이지 말 것.

필요하면 panel 자체를 viewport 기준으로 조정한다.

==================================================
12. 기존 alt-inspector test 문제 확인
==================================================

이전에:

alt-inspector.test.ts

가 Node 직접 실행 환경에서:

import.meta.env.BASE_URL

때문에 실패하는 STALE_TEST 문제가 있었다.

이번 ALT UI 작업을 하면서
해당 테스트를 정상적인 Vite/test environment에서
실행 가능하도록 정리할 수 있으면 정리한다.

단 게임 로직을 억지로 변경해서
테스트를 맞추지 말 것.

==================================================
13. 테스트
==================================================

다음 확인:

1.
tags=[] 카드
→ ALT에서 태그 section 없음

2.
tags=["용병"]
→ [용병] 표시

3.
tags=["용병","인간","전사"]
→ 3개 모두 표시

4.
keyword=["도발"]
→ 필드 카드에서 읽을 수 있는 크기로 표시
→ ALT에서도 표시

5.
keyword 여러 개
→ 겹치거나 카드 밖으로 잘리지 않음

6.
긴 효과 설명
→ ALT panel 내에서 읽을 수 있음

7.
Token
→ 자신의 tags/keywords 정상 표시

8.
generated card
→ 원본 definition tags 정상 표시
