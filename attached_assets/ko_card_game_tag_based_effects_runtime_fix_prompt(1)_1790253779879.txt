KO CARD GAME — TAG-BASED EFFECTS RUNTIME FIX
"'~~' 태그 카드들에게" 효과가 실제로 전 구역에서 작동하도록 수정

현재 문제:
`cards.tags`를 조건으로 하는 효과가 Analyzer에서는 생성되거나 저장되더라도 실제 Runtime에서 제대로 적용되지 않는 경우가 있다.

대표 예:
"등장:어디에 있든 '실험체' 태그가 달려있는 모든 아군 카드들에게 +1/+1을 부여합니다."

목표:
특정 '실험체' 카드 하나만 고치는 것이 아니라,
"'~~' 태그가 있는 카드들에게 ..."라는 전체 계열의 효과가 generic하게 작동하도록 수정한다.

공식 규칙:
- 카드 태그 source of truth = `cards.tags`
- keywords/name/description/flavor/rarity로 태그 추론 금지
- old combo tag system과 혼동 금지
- generated/token card도 CardDefinition.tags 기준
- Champion Token context는 tags와 별도
- exact normalized tag match 사용, fuzzy tag match 금지

대표 효과 기대값:

Trigger:
ENTER_FIELD

Target:
owner = SELF
selection = ALL
filter.tagsAny = ["실험체"]
zones = 프로젝트의 canonical "어디에 있든" mutable owned-card zones

Action:
BUFF
attack +1
health +1

먼저 현재 프로젝트에서 "어디에 있든"의 canonical zone contract를 확인한다.
기본 의도는 BOARD + HAND + DECK처럼 경기 중 살아 있는 owned card instances 전체다.
GRAVEYARD 포함 여부는 기존 project convention을 확인한 뒤 하나로 통일하고 최종 보고에 명시한다.
카드별 hardcode 금지.

다음 문제를 모두 검사:
- Analyzer가 filter.tagsAny를 생성하지 않는지
- 저장 중 target.filter가 유실되는지
- target resolver가 tagsAny를 무시하는지
- BOARD만 검사하고 HAND/DECK를 빠뜨리는지
- CardInstance에서 tags를 직접 찾다가 실패하는지
- CardDefinition.tags lookup이 실패하는지
- generated/token definition tags가 resolve되지 않는지
- hidden-zone sanitizer 때문에 effect 실행 자체가 skip되는지
- ALL selection인데 1장만 처리되는지
- +1/+1 중 한 stat만 적용되는지
- Runtime은 맞지만 UI/reload가 stale인지

canonical target filter는 shared schema를 사용.
예시 개념:

target: {
  owner: "SELF",
  cardType: "WRESTLER",
  selection: "ALL",
  filter: {
    tagsAny: ["실험체"]
  }
}
