KO CARD GAME — FIX ONLY:
CARD STATE CONSISTENCY + COMBAT UX

이번 작업에서는 아래 문제만 수정한다.

1. SILENCE 이후 Rush / 기습 / 도발 등의 텍스트와 배지가 남는 문제
2. DODGE 상태가 사라졌는데 UI 텍스트/배지가 남는 문제
3. 묘지로 이동한 카드가 변경된 공격/체력/비용을 유지하는 문제
4. 공격이 불가능할 때 왜 공격할 수 없는지 이유가 표시되지 않는 문제
5. 공격 자체가 불가능한 선수도 공격 모드에서 선택되는 문제
6. Random Walker의 Rush 표시가 누락되는 문제

다른 카드 효과,
Pandora,
Champion Token,
AI scheduler,
Online connection,
Admin AI,
신규 기능

은 수정하지 마.

==================================================
0. FIX-FIRST
==================================================

이번 작업은 UI만 대충 숨기는 작업이 아니다.

각 문제마다:

canonical state 확인
→ UI state 확인
→ root cause
→ 실제 수정
→ regression test

순서로 처리한다.

특히:

SILENCE
DODGE
Rush
Taunt
Attack legality

는 실제 GameState와 UI 표시가
항상 일치해야 한다.

==================================================
PART A — SILENCE 이후 KEYWORD 표시 제거
==================================================

현재 신고:

카드가 SILENCE를 당한 뒤
실제 능력은 제거되었는데도

- Rush
- 기습
- 도발
- 기타 silence 대상 keyword

텍스트/배지가 카드 UI에 계속 남는다.

==================================================
1. 먼저 canonical semantics 확인
==================================================

SILENCE가 실제로 무엇을 제거하는지
현재 engine 규칙을 확인.

예:

keywords
abilities
temporary effects
text-generated status

를 구분.

SILENCE가 제거하지 않는 항목까지
UI에서 무조건 숨기면 안 된다.

==================================================
2. UI가 CardDefinition만 보고 있지 않은지 확인
==================================================

가능성:

UI가 현재 CardInstance의 effective keywords가 아니라
원본 CardDefinition keywords를 직접 렌더하는 경우.

그렇다면:

CardDefinition = 원본
CardInstance = 현재 실제 상태

를 구분.

UI는 실제 경기 중에는
effective/current state를 렌더해야 한다.

PART C — 묘지 이동 시 원본 스탯 복구
==================================================

현재 요구:

카드가 GRAVEYARD로 이동하면

- 비용
- 공격력
- 체력

은 원본 CardDefinition 값으로 복구되어야 한다.

즉:

임시 buff
debuff

가 묘지까지 유지되면 안 된다.

==================================================
6. CardInstance modifier lifecycle 확인
==================================================

현재 zone transition:

FIELD/HAND
→ GRAVEYARD

에서 어떤 state를 유지하는지 확인.

가능성:

- currentAttack/currentHealth/currentCost를 그대로 유지
- modifier stack을 그대로 보존
- zone만 바꿈

이런 구조라면
graveyard entry 시 reset semantics를 추가.

==================================================
7. 무엇을 reset할지 정확히 구분
==================================================

묘지 진입 시:

base CardDefinition은 절대 수정하지 않는다.

CardInstance의:

temporary modifiers
effective attack
effective health
effective cost

를 원본 기준으로 되돌린다.

단 게임에 "묘지에서도 유지되는 영구 성장" 같은
명시적 mechanic이 존재한다면
그건 별도 rule에 따라야 한다.

이번 요구의 기본값은:

GRAVEYARD = original stats reset.

11. Attack legality reason 구조 사용
==================================================

가능하면 기존 boolean:

만 쓰지 말고

attack legality 결과에:

allowed

를 제공.

예:

{
  allowed: false,
  reasonCode: "TAUNT_RESTRICTION"
}

또는 현재 architecture에 맞는 equivalent.

==================================================
12. 최소 표시해야 할 이유
==================================================

현재 실제 게임 규칙에 해당하는 범위에서:

- 아직 공격할 수 없는 상태
- Rush/기습 조건 미충족
- 상대 Taunt 때문에 다른 target 공격 불가
- 유효한 공격 대상 없음
- 해당 카드가 attack 불가 상태
- 이미 공격함
- effect/keyword에 의해 attack 제한
- pending targeting/action 때문에 현재 공격 불가

등.

존재하지 않는 규칙을 새로 만들지 마.

==================================================
13. 사용자에게 이해하기 쉬운 문구
==================================================

reasonCode는 내부용.

UI는 한국어 설명 표시.

예:

TAUNT_RESTRICTION
→ "도발을 가진 적을 먼저 공격해야 합니다."

ALREADY_ATTACKED
→ "이 선수는 이번 턴 이미 공격했습니다."

NO_VALID_TARGET
→ "공격할 수 있는 대상이 없습니다."

정확한 기존 규칙에 맞춰 구현.

exception

그냥:

attack rejected
→ 이유 표시

해야 한다.
