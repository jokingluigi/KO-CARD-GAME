==================================================
1. stale Champion Token QA 수정
==================================================

파일:

artifacts/ko-game/src/game/qa/published-effects-qa2.test.ts

테스트:

"QA2 linked Champion Token deploy is distinct from a normal summon"

이 테스트가 아직 옛 규칙:

Champion Token base HP 10
+
원본 Champion HP 13
=
23

을 기대하고 있다.

현재 확정된 공식 규칙은:

Champion Token deploy 시
원본 Champion HP를 절대 합산하지 않는다.

따라서 Token base HP가 10이면:

currentHP = 10
maxHP = 10

이어야 한다.

해당 stale expectation을 새 공식 규칙으로 수정한다.

단 테스트를 단순 삭제하지 말 것.

반드시 계속 검증:

- DEPLOY_CHAMPION_TOKEN 경로는 일반 SUMMON과 구분됨
- Token HP는 definition 기본 HP 그대로
- 원본 Champion 보호 활성화
- 일반 SUMMON된 같은 definition은 보호 활성화 안 됨

수정 후 QA2 전체를 다시 실행.

==================================================
2. root pnpm run build 정리
==================================================

현재 정확한:

pnpm run build

실행이 mockup-sandbox의:

PORT
BASE_PATH

환경변수가 없어서 실패한다.

KO/API/Vite 실제 코드 build failure는 아니다.

목표:

환경변수를 수동으로 주입하지 않아도
repository root에서:

pnpm run build

가 정상 통과하도록 한다.

중요:
Production/개발 실행 설정을 깨뜨리지 말 것.

mockup-sandbox의 Vite config를 조사하고
build command에서만 필요한 경우 안전한 기본값을 사용하도록
최소 수정하는 방식을 우선한다.

예:

build 시에만:
PORT 기본값 5173
BASE_PATH 기본값 "/"

개발 실행에서 기존 명시적 환경변수가 있다면
그 값을 우선 사용해야 한다.

환경변수를 완전히 무시하거나
Production BASE_PATH를 "/"로 강제하지 말 것.

root package 전체를 대규모 리팩터링하지 말 것.
