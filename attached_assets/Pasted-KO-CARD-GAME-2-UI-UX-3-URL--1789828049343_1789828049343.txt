KO CARD GAME의 2차 UI/UX 완성도 개선 작업을 진행해줘.

이번 작업에서는 아래 3가지만 수정해.

중요:
- 카드 아트 / 이미지 / 이미지 URL / 에셋 업로드는 건드리지 마.
- 게임 효과 로직을 변경하지 마.
- 카드 능력의 실제 판정 의미를 임의로 바꾸지 마.
- DB 스키마를 변경하지 마.
- 카드 타입이나 스탯을 임의로 변경하지 마.
- 온라인 PvP / AI 로직은 이번 작업에서 건드리지 마.
- 기존 공용 CardRenderer / 카드 상세 팝업 / ALT UI가 있으면 반드시 재사용해.
- 새 기능을 중복 구현하지 마.

==================================================
1. Deck Editor에서 카드 효과 상세 확인 개선
==================================================

[현재 문제]

Deck Editor의 CARD LOCKER에서
카드를 덱에 추가할 때 카드 효과를 읽기 어렵다.

현재 보이는 정보는 주로:
- 이름
- 타입
- 비용
- 희귀도
- 공격력 / 체력
정도이고 긴 카드 효과를 확인하기 불편하다.

Collection에는 카드 상세 팝업이 있으므로
새로운 상세 시스템을 만들지 말고 기존 상세 UI를 재사용해.

[목표]

덱을 짜면서 Collection으로 나가지 않고도
카드의 전체 효과를 쉽게 확인할 수 있게 한다.

[요구사항]

- CARD LOCKER의 카드 본체와 "+" 추가 버튼 역할을 분리.
- "+" 버튼은 기존처럼 카드 추가만 수행.
- 카드 본체 또는 명확한 상세보기 영역을 누르면 기존 카드 상세 팝업을 연다.
- 카드 추가 동작과 상세보기 동작이 동시에 발생하지 않게 event propagation을 확인.
- 이미 ALT 상세 기능이 있다면 가능한 한 동일한 컴포넌트/데이터를 사용.
- Desktop에서는 click 또는 기존 ALT interaction 지원.
- 모바일/터치에서도 상세보기가 막히지 않도록 고려.
- 카드 상세를 닫은 뒤 Deck Editor 상태가 그대로 유지되어야 함.
- 스크롤 위치나 현재 덱 구성이 리셋되면 안 됨.
- 상세보기 때문에 카드가 덱에 추가되거나 제거되면 안 됨.

가능하면 작은 "상세" 아이콘/버튼을 추가해도 되지만
CARD LOCKER를 복잡하게 만들지 마.

==================================================
2. 사용자에게 보이는 게임 용어 통일
==================================================

내부 코드 enum/API 값은 절대 변경하지 말고,
UI에 보여주는 문자열만 정리해.

예:

WRESTLER
→ 선수

TECHNIQUE
→ 기술

Champion
→ 챔피언

Cost
→ 비용

VALID
→ 사용 가능

INVALID
→ 수정 필요

Close
→ 닫기

Gold / 골드 / G가 혼용되는 부분은
현재 KO 디자인을 조사해서 사용자 UI에서는 일관된 체계로 정리해.

주의:
- 내부 타입 WRESTLER를 "선수" 문자열로 저장하지 마.
- API response 필드를 변경하지 마.
- DB 데이터를 대규모 변환하지 마.
- 개발자/Admin 내부 화면에서 enum이 필요한 경우에는 그대로 유지 가능.
- 카드 프레임 안의 장식용 영문은 변경하지 않아도 됨.
- 디자인 제목인 CARD LOCKER, CARD BATTLE 같은 고유 스타일 영문은 유지 가능.

핵심은 일반 사용자가 실제 조작하거나 규칙을 읽는 곳의 언어를 통일하는 것.

aria-label, title, 접근성 레이블도
일반 사용자 UI에서는 가능하면 한국어로 맞춰.

==================================================
3. 카드 효과 문구 품질 정리
==================================================

카드 효과의 실제 로직은 절대 변경하지 말고
사용자에게 표시되는 한국어 텍스트만 점검해.

QA에서 실제로 다음과 같은 문제가 관찰됨:

- "현재 공격과 체력을의 수치"
- "소환될때"
- "이번턴"
- 묘지 / 무덤 혼용
- 퇴장 / 리타이어가 문맥 없이 혼용되는 부분

[원칙]

KO의 규칙 용어는 실제 엔진 의미를 존중해야 한다.

예:
- 등장
- 퇴장
- 리타이어
- 묘지
- 이번 턴
- 턴 종료 시
- 소환될 때

중요:
"퇴장"과 "리타이어"가 엔진에서 다른 의미라면
절대 같은 단어로 합치지 마.

"소환"과 "등장" 역시 실제 게임 규칙상 다른 개념이라면
문장을 예쁘게 만든다는 이유로 서로 바꾸지 마.

즉:
문법 / 띄어쓰기 / 오탈자는 교정하되
규칙 의미는 변경하지 않는다.

먼저 사용자에게 공개되는 카드 텍스트 전체를 검색해서
명백한 오탈자와 표현 불일치를 찾아 수정해.

불확실한 문장은 임의 수정하지 말고 최종 보고에 따로 적어.

==================================================
검증
==================================================

수정 후 반드시:

pnpm run typecheck

pnpm -r --if-present run build

git diff --check

가능하면 Preview에서:

Deck Editor
→ CARD LOCKER 카드 상세 열기
→ 닫기
→ 카드 추가
→ 카드 제거

를 확인해.

특히:
- 상세를 눌러도 카드가 추가되지 않는지
- +를 눌러도 상세 팝업이 강제로 열리지 않는지
- 상세를 닫은 뒤 덱 상태가 유지되는지
확인해.
