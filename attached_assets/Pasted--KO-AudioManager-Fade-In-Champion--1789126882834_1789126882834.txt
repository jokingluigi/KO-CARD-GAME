현재 KO 카드게임의 AudioManager에
"모든 음악 재생은 반드시 Fade-In으로 시작한다"
라는 전역 규칙을 추가해줘.

중요:
이 규칙은 특정 Champion이나 특정 음악에만 적용하는 것이 아니라
MUSIC 계열 전체에 적용한다.

==================================================
1. 모든 음악 시작 = Fade-In 필수
==================================================

다음 음악들은 재생을 시작할 때
절대로 즉시 최대 볼륨으로 시작하면 안 된다.

반드시 Fade-In을 거쳐야 한다.

적용 대상:

- Match Background Music
- Champion Quest Completion Music
- Wrestler/Card Entrance Music
- 기타 향후 추가되는 MUSIC / STINGER 계열 음악

예:

volume 0
→ 재생 시작
→ 짧은 시간 동안 목표 volume까지 증가

==================================================
2. 권장 Fade-In 시간
==================================================

공통 상수를 사용해.

예:

MUSIC_FADE_IN_DURATION = 0.4 ~ 0.8 seconds

현재 AudioManager 구조에 맞춰 적절한 값 사용.

가능하면 기본값:

500ms

정도로 설정.

하드코딩된 setTimeout을 여러 군데 만들지 말고
AudioManager의 공통 fade 함수로 처리해.

예:

playMusicWithFadeIn(...)
fadeIn(...)
transitionMusic(...)

현재 구조에 맞는 이름 사용.

==================================================
3. BGM 시작
==================================================

매치 시작:

Match BGM
→ volume 0에서 시작
→ Fade-In
→ 설정된 BGM volume까지 상승

갑자기 큰 볼륨으로 시작하면 안 된다.

==================================================
4. Quest Completion Music
==================================================

Champion Quest 완료:

기존 지속 음악 Fade-Out
↓
새 Champion Quest Music 재생
↓
새 음악은 반드시 volume 0부터 Fade-In

즉:

A Quest Music
→ fade out

B Quest Music
→ fade in

방식으로 자연스럽게 전환.

Quest Music이 바로 최대 볼륨으로 튀어나오면 안 된다.

==================================================
5. Wrestler Entrance Music
==================================================

선수 등장 음악도 반드시 Fade-In.

예:

현재 BASE MUSIC 감소/중단
↓
Wrestler Entrance Music volume 0
↓
Fade-In
↓
Entrance Music 재생
↓
종료 시 Fade-Out
↓
현재 BASE MUSIC 복귀

==================================================
6. Base Music 복귀도 Fade-In
==================================================

선수 Entrance Music이 끝난 뒤
BGM 또는 Quest Completion Music으로 돌아올 때도
무조건 Fade-In.

예:

Entrance Music 종료
↓
현재 latest BASE MUSIC 확인
↓
BASE MUSIC resume
↓
volume 0 또는 낮은 volume에서
목표 volume까지 Fade-In

resume라고 해서
기존 볼륨으로 즉시 튀어나오면 안 된다.

==================================================
7. Pause 후 Resume도 음악이면 Fade-In
==================================================

기존 음악의 currentTime을 유지해서 resume하는 경우에도:

resume
→ Fade-In

을 적용해.

즉:

음악이 들리지 않는 상태
→ 다시 들리는 상태

로 전환될 때는 항상 Fade-In.

==================================================
8. 음악 교체 시 Crossfade
==================================================

가능하면:

현재 음악
→ Fade-Out

새 음악
→ Fade-In

으로 처리.

단 두 음악이 높은 볼륨으로 오래 겹치지 않게 해.

짧은 crossfade는 허용.

==================================================
9. SFX에는 적용하지 않음
==================================================

이 Fade-In 규칙은 MUSIC 전용이다.

다음에는 적용하지 마:

- 공격 SFX
- 피격 SFX
- 카드 등장 SFX
- 버튼 SFX
- Turn SFX
- 기타 짧은 효과음

SFX는 즉시 재생되어야 타격감이 유지된다.

즉:

MUSIC
→ Fade-In 필수

SFX
→ 즉시 재생

==================================================
10. Volume 설정과 결합
==================================================

Fade-In 최종 볼륨은
고정 1.0이 아니라
해당 음악의 실제 설정 volume을 사용해.

예:

Quest Music volume = 0.65

재생:

0
→ 0.1
→ 0.3
→ 0.5
→ 0.65

처럼 증가.

사용자의 Music/BGM volume 설정도 반영.

==================================================
11. 음악 중간 교체 안전성
==================================================

Fade-In 도중 다른 음악이 시작되면
이전 fade timer / animation을 정리해.

예:

A Music fade-in 중
→ B Quest Music 요청

이면:

A fade 작업 취소
→ A fade-out/stop
→ B volume 0
→ B fade-in

동시에 여러 fade loop가 volume을 조작하면 안 된다.

==================================================
12. AudioManager 중앙 처리
==================================================

각 React component에서
직접 volume interval을 만들지 마.

모든 음악 Fade-In/Fade-Out은
기존 중앙 AudioManager에서 관리해.

공통 함수 하나를 여러 음악 시스템이 재사용하도록 해.

==================================================
13. 테스트
==================================================

반드시 확인:

1.
매치 시작 BGM
→ Fade-In

2.
Champion Quest Music 시작
→ Fade-In

3.
상대 Champion Quest Music으로 교체
→ 이전 음악 Fade-Out
→ 새 음악 Fade-In

4.
Wrestler Entrance Music
→ Fade-In

5.
Entrance 종료 후 BGM 복귀
→ Fade-In

6.
Entrance 종료 후 Quest Music 복귀
→ Fade-In

7.
pause된 음악 resume
→ Fade-In

8.
SFX
→ Fade-In 없이 즉시 재생

==================================================
최종 전역 규칙
==================================================

어떤 MUSIC이든:

STOPPED / PAUSED / SILENT
→ AUDIBLE

상태로 전환되는 순간

반드시 Fade-In.

음악이 갑자기 최대 볼륨으로 시작하는 경우가
프로젝트 어디에도 남아 있으면 안 된다.

관련 AudioManager 코드만 최소 수정하고
게임 로직은 변경하지 마.
