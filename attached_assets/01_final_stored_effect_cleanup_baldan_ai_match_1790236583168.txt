==================================================
1. 발단 공식 의미
==================================================

최신 Source Text를 먼저 다시 읽고 아래 의도와 일치하는지 확인:

"등장:
내 묘지의 비용 3 이하 카드 중 무작위 카드 1장을 선택하고,
그 카드의 현재 공격력/현재 체력과 같은 수치의 '좀비'를 하나 소환한다."

Canonical intent:

ENTER_FIELD
→ SELECT own GRAVEYARD
→ filter.maxCost = 3
→ RANDOM 1
→ selected target currentAttack/currentHealth snapshot
→ SUMMON exact Zombie CardDefinition
→ summoned Zombie current stats = selected snapshot

규칙:
- selected graveyard card는 이동시키지 않음
- REVIVE 아님
- deterministic RNG
- no target → safe no-op
- Math.random 금지
- Zombie reference는 exact CardDefinition reference
- fuzzy name search 금지
- missing/ambiguous definition이면 ANALYSIS_FAILED

원문에 TAUNT/도발 문구가 없으면:
- Analyzer가 ADD_KEYWORD TAUNT 생성 금지
- stored effect에 legacy TAUNT가 남아 있으면 제거 대상
