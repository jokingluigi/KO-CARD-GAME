18. SOURCE_CAUSED_TARGET_REMOVAL 공식 의미
==================================================

Trigger fires only when THIS exact source CardInstance directly causes
a WRESTLER to leave by:

- RETIRE due to source damage/combat
- explicit RETIRE effect by source
- explicit DESTROY effect by source

Not:
- ally card killed it
- unrelated delayed effect
- global effect with no causal source
- victim later died from another source

source instance identity가 핵심.
