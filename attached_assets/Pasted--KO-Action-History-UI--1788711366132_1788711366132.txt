현재 KO 카드게임 화면 왼쪽에 디지털 카드게임에서 사용하는 것과 비슷한 "플레이 기록 / Action History" UI를 추가해줘.

중요:
기존 게임 엔진이나 게임 규칙은 변경하지 말고,
현재 존재하는 Event/Event Log 데이터를 활용해서 UI 기능으로 구현해줘.

================================
목표
==

게임 화면 왼쪽에 세로 형태의 최근 행동 기록 영역을 만든다.

플레이어가 카드를 사용하거나 중요한 행동을 하면
해당 기록이 최신순으로 위에서 아래 또는 아래에서 위로 쌓이게 해줘.

화면을 너무 많이 차지하지 않는 작은 UI로 만들어줘.

================================
우선 기록할 행동
=========

다음 이벤트를 플레이 기록에 표시해줘.

CARD_PLAYED

* 선수를 손에서 플레이했을 때
* 기술 카드를 사용했을 때

ENTER_FIELD

* 카드 효과 등으로 선수가 직접 소환됐을 때

USE_CHAMPION_ABILITY

* 챔피언 고유 능력을 사용했을 때

CARD_GENERATED

* 효과로 카드가 생성됐을 때

CARD_DESTROYED

* 효과로 카드가 파괴됐을 때

CARD_RETIRED

* 선수가 리타이어했을 때

ATTACK

* 선수가 공격했을 때

단순한 내부 시스템 이벤트나 디버그용 이벤트는 플레이 기록에 표시하지 않아도 된다.

================================
카드 기록 디자인
=========

카드를 플레이한 기록은 작은 카드 미니어처 형태로 보여줘.

가능하면 다음 정보를 사용한다.

* 카드 이름
* 카드 이미지가 있으면 작은 이미지
* 이미지가 없으면 카드 이름 또는 간단한 placeholder
* 해당 카드를 사용한 플레이어 구분

예:

[카드 이미지]
피 스타 세븐

또는 아주 작은 카드 형태.

Player 1과 Player 2가 사용한 기록을 시각적으로 구분할 수 있게 한다.

단, 지나치게 화려하게 만들지 않는다.

================================
마우스 Hover
=========

플레이 기록의 카드 미니어처에 마우스를 올리면
해당 카드의 상세 정보를 작은 팝업으로 보여줘.

예:

피 스타 세븐
6G
5 / 6
등장: ...

실제 카드 데이터에서 정보를 읽어와야 한다.

로그용으로 카드 정보를 별도로 하드코딩하지 마.

================================
공격 기록
=====

공격 기록은 가능하면:

공격한 선수 → 공격 대상

관계가 이해되게 보여줘.

예:

[나토마토] → [위리놈]

또는

[나토마토] → [상대 챔피언]

처럼 표시한다.

이미지가 있으면 작은 초상화나 아이콘을 사용할 수 있다.

================================
챔피언 능력 기록
=========

챔피언 고유 능력을 사용하면:

[챔피언 초상화]
고유 능력 사용

형태로 보여줘.

가능하면 대상이 있는 능력이라면 대상도 함께 기록한다.

================================
최대 표시 개수
========

최근 기록만 화면에 유지해줘.

예:

최근 8~12개의 행동만 왼쪽에 표시.

더 오래된 기록은 화면에서는 사라져도 되지만
기존 전체 Event Log 데이터를 삭제할 필요는 없다.

UI에서만 최근 기록을 잘라서 보여줘.

================================
애니메이션
=====

새 기록이 추가될 때 아주 짧게:

* fade in
* slide in

정도의 가벼운 애니메이션만 사용한다.

무거운 애니메이션 라이브러리는 추가하지 마.

================================
중복 이벤트 주의
=========

중요:

카드를 손에서 플레이한 뒤 ENTER_FIELD가 발생한다고 해서
같은 카드가 플레이 기록에 두 번 표시되지 않게 해줘.

예:

손에서 나토마토 사용
→ CARD_PLAYED
→ ENTER_FIELD

이 경우 기본 플레이 기록에는 "나토마토 플레이"를 한 번만 보여준다.

하지만 다른 카드 효과로 나토마토가 직접 소환되어
CARD_PLAYED 없이 ENTER_FIELD만 발생했다면
"나토마토 소환" 기록을 보여줘.

즉 이벤트 원인을 확인해서 중복 로그를 방지해줘.

================================
플레이 기록과 디버그 로그 분리
=================

현재 텍스트 형태 Event Log가 있다면
그것은 개발/디버깅용으로 유지해도 된다.

새로 만드는 왼쪽 기록은
플레이어가 보는 "Play History" UI다.

둘을 같은 UI로 합치지 않아도 된다.

내부 Event Log
→ 상세한 시스템 기록

Play History
→ 플레이어에게 중요한 행동만 간단하게 표시

이렇게 역할을 분리해줘.

================================
레이아웃
====

PC 기준 게임 화면 왼쪽에 배치한다.

중앙 게임 보드가 밀리거나 작아지지 않도록
폭이 좁은 오버레이 형태를 우선 사용한다.

예:

왼쪽 가장자리
┌─────────┐
│ 카드    │
│ 카드    │
│ 공격    │
│ 기술    │
│ 카드    │
└─────────┘

스크롤이 필요하면 얇은 스크롤 영역을 사용한다.

모바일에서는 화면을 가리지 않도록
접거나 숨길 수 있는 형태로 만들어도 된다.

================================
매우 중요
=====

이번 작업은 플레이 기록 UI 추가 작업이다.

기존:

* GameState
* 카드 사용 규칙
* 공격 규칙
* 턴 시스템
* 골드 시스템
* 챔피언 시스템

을 변경하지 마.

기존 Event 데이터를 읽어서 표현하는 방식으로 구현하고,
정상 작동하는 게임 엔진을 대규모 리팩터링하지 마.

완료 후 직접 확인:

1. 선수 카드 사용 → 왼쪽 기록 생성
2. 기술 카드 사용 → 기록 생성
3. 공격 → 기록 생성
4. 상대 플레이어 행동도 기록됨
5. Hover 시 카드 상세 표시
6. 같은 카드가 CARD_PLAYED + ENTER_FIELD로 두 번 표시되지 않음
7. 턴 종료나 게임 진행에 영향을 주지 않음
