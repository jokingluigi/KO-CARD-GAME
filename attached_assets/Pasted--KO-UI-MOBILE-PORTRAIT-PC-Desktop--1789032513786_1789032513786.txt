현재 KO 카드게임에 "모바일 세로 화면 전용" 반응형 UI만 추가해줘.

가장 중요:
이 작업은 MOBILE PORTRAIT 전용이다.

PC / Desktop / 큰 태블릿 / 가로 화면의 기존 UI는 절대로 변경하지 마.

현재 데스크톱 레이아웃, 위치, 크기, 카드 배치, 챔피언 UI, 로그 UI를 그대로 유지해야 한다.

모바일 전용 CSS/Layout은 반드시 명확한 breakpoint 안에서만 적용해.

예:
@media (max-width: 768px) and (orientation: portrait)

또는 현재 프로젝트 구조에 맞는 mobile-only breakpoint를 사용해.

공통 CSS를 수정해서 Desktop까지 영향을 주는 방식은 금지.

================================
모바일 세로 화면 전용 레이아웃
================================

상단:
- 상대 챔피언
- 상대 HP
- 상대 Gold
- 상대 손패

중앙:
- 상대 필드 4슬롯
- 내 필드 4슬롯
- 턴 표시
- 턴 종료 버튼

하단:
- 내 챔피언
- 내 HP
- 내 Gold
- 내 손패

내 손패는 하단에서:
- 가로 스크롤
또는
- 모바일용 부채꼴 배치

중 현재 구조에 더 안정적인 방식을 사용해.

카드를 탭하면 확대해서 효과를 읽을 수 있게 해.

================================
보조 UI
================================

모바일에서만 다음 UI는 화면을 계속 차지하지 않게 해:

- Play History
- Graveyard
- Removed From Game
- Quest 상세
- 설정

작은 버튼 또는 접이식 패널 / 모달로 열게 해.

Desktop에서는 기존 위치 그대로 유지.

================================
카드 UI
================================

NORMAL / LEGENDARY / CHAMPION 프레임은 그대로 유지.

모바일에서만 카드 크기를 반응형으로 줄여줘.

공통 Card Renderer는 유지하되
모바일 전용 size/layout 값만 별도로 적용해.

Desktop 카드 크기나 글자 크기는 변경하지 마.

================================
모바일 카드 상세보기
================================

Desktop:
기존 Alt + Hover 유지.

Mobile:
Alt/Hover를 요구하지 말고
Tap / Long Press / 정보 버튼 중 안정적인 방식으로
같은 상세정보를 볼 수 있게 해.

Desktop Alt+Hover 동작은 절대 변경하지 마.

================================
모바일 공격/플레이 애니메이션
================================

현재 카드 공격/플레이 애니메이션이 있다면
모바일에서는 모바일 DOM 위치를 기준으로 계산해.

Desktop 좌표를 하드코딩하지 마.

기존 Desktop 애니메이션은 그대로 유지.

================================
모바일 화면 안전성
================================

모바일에서만:

- 100dvh 고려
- safe-area-inset-top
- safe-area-inset-bottom
- 버튼 터치 영역 확보
- 페이지 전체 불필요한 가로 스크롤 방지
- 주소창 때문에 UI 잘림 방지

를 적용해.

pinch zoom을 강제로 막지 마.

================================
절대 수정 금지
================================

이번 작업으로 다음 Desktop UI를 바꾸면 안 된다:

- Desktop 게임 보드 크기
- Desktop 카드 크기
- Desktop 손패 위치
- Desktop 챔피언 위치
- Desktop 로그 위치
- Desktop 턴 종료 버튼 위치
- Desktop 전체 레이아웃
- Desktop 배경 배치

또한 게임 엔진 / Effect / Combat / Gold / Turn 규칙도 수정 금지.

================================
반드시 테스트
================================

모바일:
390x844
430x932

에서 portrait UI 확인.

그리고 반드시 Desktop도 확인:

1920x927

Desktop 화면이 작업 전과 시각적으로 동일해야 한다.

최종 조건:

MOBILE PORTRAIT
→ 새 모바일 UI 적용

DESKTOP
→ 기존 UI 100% 유지

TABLET/LANDSCAPE
→ 기존 Desktop UI 또는 현재 기존 responsive 동작 유지

모바일 전용 responsive CSS/layout만 최소 수정하고,
완료 후 추가 기능은 만들지 말고 종료해줘.
