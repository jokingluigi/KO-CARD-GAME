현재 KO 카드게임의 게임 로직과 게임 엔진은 변경하지 말고 UI/UX와 스타일만 리디자인해줘.

목표는 전통적인 디지털 카드 배틀 게임처럼 직관적인 화면 구조를 만드는 것이다.

Hearthstone 같은 게임의 정보 배치와 사용성을 참고할 수 있지만, 그래픽이나 자산을 그대로 복제하지 말고 KO 프로레슬링 게임만의 독창적인 디자인으로 만들어줘.

====================
전체 화면 구조
========

게임 화면은 한 화면 안에서 대부분의 전투 상황을 확인할 수 있게 한다.

상대 플레이어는 화면 위쪽,
내 플레이어는 화면 아래쪽에 배치한다.

중앙에는 넓은 전투 보드를 배치한다.

기본 구조:

[상대 챔피언]

[상대 손패]

[상대 선수 4칸]

---

```
  전투 보드
```

---

[내 선수 4칸]

[내 손패]

[내 챔피언]

화면을 불필요하게 여러 패널로 나누지 말고 카드게임 보드 자체가 화면 대부분을 차지하게 해줘.

====================
챔피언 UI
======

상대 챔피언은 화면 상단 중앙 근처.

내 챔피언은 화면 하단 중앙 근처.

챔피언은 원형 또는 육각형 초상화 형태로 표현한다.

챔피언 주변에:

* 현재 체력
* 챔피언 고유 능력 버튼
* 퀘스트가 있을 경우 퀘스트 진행도

를 자연스럽게 배치할 수 있게 한다.

체력은 크게 보여서 항상 바로 확인할 수 있어야 한다.

챔피언 고유 능력 버튼은 챔피언 초상화 옆에 별도의 원형 버튼으로 배치해도 좋다.

====================
골드 UI
=====

현재 골드는 화면 오른쪽 아래,
상대 골드는 오른쪽 위에 표시한다.

예:

3 / 5

형태로 표시할 수 있게 한다.

현재 사용 가능한 골드가 시각적으로 즉시 구분되게 해줘.

프로레슬링 게임이므로 마나 수정 같은 디자인 대신:

* 금색 메달
* 챔피언 벨트 장식
* 링 조명
* KO 로고 토큰

같은 느낌으로 디자인할 수 있다.

====================
보드
==

각 플레이어 보드는 정확히 4개의 선수 슬롯을 가진다.

빈 슬롯 자체가 너무 강하게 보이지 않게 하고,
카드를 드래그하거나 선택했을 때만 빈 슬롯이 강조되게 한다.

선수 카드는 필드에 나오면 손패 카드보다 작고 간결한 형태로 표시한다.

필드 선수에서 가장 중요한 정보:

* 공격력
* 체력
* 이름
* 주요 키워드 상태

공격력은 왼쪽 아래,
체력은 오른쪽 아래처럼 일관성 있게 배치해줘.

====================
손패
==

내 손패는 화면 하단 중앙에 부채꼴 또는 완만한 곡선 형태로 배치한다.

손패 카드가 많아질수록 서로 조금씩 겹치게 해서 공간을 절약한다.

마우스를 카드 위에 올리면:

* 카드가 위로 올라오고
* 확대되며
* 전체 텍스트를 읽을 수 있게 한다.

선택된 카드는 주변 카드보다 앞으로 나오게 한다.

상대 손패는 카드 뒷면만 보여준다.

상대 카드의 내용은 절대 노출하지 않는다.

상대 손패 장수는 화면에서 알 수 있어야 한다.

====================
카드 디자인
======

카드에는 다음 정보를 명확하게 표시한다.

상단 왼쪽:
비용

중앙:
카드 이미지 영역

하단:
카드 이름

그 아래:
효과 텍스트

선수 카드:
공격력 / 체력 표시

기술 카드:
공격력과 체력 없음

현재 실제 카드 이미지는 placeholder로 유지해도 된다.

향후 imageUrl만 추가하면 이미지를 쉽게 넣을 수 있게 만들어줘.

====================
프로레슬링 KO 테마
===========

전체 테마는 판타지 여관이나 마법 세계가 아니라 현대 프로레슬링 경기장이다.

중앙 보드는 프로레슬링 링 또는 PPV 메인 이벤트 무대 느낌.

배경에는:

* 어두운 관중석
* 경기장 조명
* LED 전광판
* 링 로프
* 금속 장식

등을 절제해서 사용할 수 있다.

UI가 너무 복잡해져 카드 가독성이 떨어지면 안 된다.

카드와 게임 정보가 항상 배경보다 우선한다.

전체적으로:

프로레슬링 PPV 방송 그래픽
+
디지털 카드 배틀 게임

의 조합을 목표로 한다.

====================
턴 표시
====

현재 플레이어의 턴인지 아주 명확하게 보여줘.

내 턴이라면 내 영역에 약한 빛이나 강조 효과를 사용한다.

상대 턴이라면 상대 영역을 강조한다.

턴 종료 버튼은 화면 오른쪽 중앙에 크게 배치한다.

버튼 텍스트:

턴 종료

내 턴이 아닐 때는 비활성화한다.

====================
공격 UX
=====

공격 가능한 선수는 마우스를 올렸을 때 또는 선택했을 때 시각적으로 표시한다.

선수를 선택하면 공격 가능한 대상만 강조한다.

공격 불가능한 대상은 강조하지 않는다.

공격 대상 선택 전:

선수 선택

공격 대상 선택 후:

ATTACK Action 실행

기존 게임 엔진의 validation을 그대로 사용한다.

UI에서 공격 가능 여부를 임의로 결정하지 말고 게임 엔진의 결과를 기준으로 표시한다.

====================
카드 사용 UX
========

손패 카드를 선택하면 사용할 수 있는 보드 슬롯을 강조한다.

골드가 부족한 카드는 어둡게 표시한다.

하지만 실제 카드 사용 가능 여부는 반드시 기존 게임 엔진 validation을 사용한다.

UI validation만으로 게임 규칙을 처리하지 않는다.

====================
애니메이션
=====

과도하지 않은 간단한 애니메이션만 추가한다.

예:

카드 드로우
카드가 필드에 등장
공격 시 짧게 전진
피해 숫자 표시
리타이어 시 사라지는 효과
챔피언 피해 시 흔들림

지금은 화려한 3D 효과나 무거운 라이브러리는 추가하지 않는다.

CSS transition 또는 가벼운 애니메이션으로 처리한다.

====================
반응형 화면
======

우선 PC 플레이를 기준으로 디자인한다.

16:9 화면에서 가장 보기 좋게 만든다.

하지만 모바일 브라우저에서도 UI가 완전히 깨지지 않게 반응형 구조를 유지한다.

모바일 전용 UI는 나중에 별도로 개선할 예정이므로 지금은 과도한 모바일 작업을 하지 않는다.

====================
매우 중요
=====

게임 엔진,
GameState,
Action,
카드 효과,
턴 규칙,
골드 규칙,
공격 규칙,
챔피언 시스템

등 기존 게임 로직은 변경하지 마.

이번 작업은 UI 컴포넌트와 CSS/스타일링 중심으로만 진행한다.

기존 정상 기능을 대규모 리팩터링하지 마.

UI 변경 후:

* 카드 사용
* 공격
* 턴 종료
* 골드 표시
* 체력 표시
* 보드 4칸

이 기존과 동일하게 정상 작동하는지만 확인해줘.
