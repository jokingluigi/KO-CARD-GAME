현재 KO 카드게임에
"매치 결과 화면"
기능을 구현해줘.

목표:

게임이 승리/패배로 끝나면
즉시 게임 화면이 사라지는 게 아니라

승리 또는 패배 결과를 명확하게 보여주는 화면이 뜨고,
[메인 화면으로]
버튼을 눌러 Main Menu로 나갈 수 있게 해.

기존 Match Result / Victory 판정 로직이 있다면 반드시 재사용하고
승패 판정을 UI에서 새로 계산하지 마.

==================================================
1. 결과 화면
==================================================

Match가 종료되면
게임 화면 위에 Result Overlay 또는 Result Screen을 표시해.

승리한 플레이어:

승리
VICTORY

패배한 플레이어:

패배
DEFEAT

형태로 명확하게 표시.

현재 KO UI 스타일에 맞춰
검정 기반 + 금색/밝은 강조를 사용해.

==================================================
2. 결과 화면 표시 시점
==================================================

매치 종료 판정이 발생했다고
즉시 결과 화면을 덮어씌우지 마.

마지막:

- 공격
- 피해
- RETIRE
- DESTROY
- Champion 피해
- Champion Token RETIRE

등의 최종 연출이 끝난 뒤
짧은 딜레이 후 결과 화면을 표시해.

즉:

Game Engine Match End
→ 남아 있는 Presentation/Animation 처리
→ Result Screen 표시

형태.

마지막 타격 연출이 결과 화면 때문에 잘리면 안 된다.

==================================================
3. 공통 Match Result 사용
==================================================

기존 GameState / Match State에 있는
공식 Match Result를 사용해.

예:

matchResult {
  winnerPlayerId
  loserPlayerId
  reason
}

실제 구조는 기존 프로젝트에 맞춰.

UI에서 Champion HP를 보고
별도로 승패를 다시 계산하지 마.

==================================================
4. 종료 원인
==================================================

기존 Match Engine에서 발생하는 모든 정상 종료가
같은 Result Screen으로 연결되어야 한다.

예:

- 상대 Champion HP <= 0
- 내 Champion HP <= 0
- SURRENDER
- Active Champion Token RETIRE로 패배
- 기타 기존 Match Result

종료 원인에 따라
별도 Result 화면을 여러 개 만들지 마.

==================================================
5. 결과 문구
==================================================

기본:

WINNER:
"승리"

LOSER:
"패배"

필요하면 작은 보조 문구로 종료 이유를 표시 가능.

예:

상대 챔피언을 쓰러뜨렸습니다.

또는

챔피언 토큰이 리타이어했습니다.

하지만 핵심은 승리/패배를 가장 크게 표시.

==================================================
6. 메인 화면 버튼
==================================================

결과 화면에:

[메인 화면으로]

버튼 추가.

누르면 기존 KO Main Menu route로 이동.

예:

/

또는 현재 Main Menu route 사용.

페이지 reload로 해결하지 말고
기존 React Router/navigation 방식을 사용해.

==================================================
7. Match 정리
==================================================

메인 화면으로 나갈 때:

- Match 전용 Animation 정리
- temporary audio 정리
- Reveal/Combat timer 정리
- pendingSelection 정리
- targeting UI 정리

등 현재 Match cleanup 구조를 사용해.

하지만 User의:

- 로그인 Session
- Collection
- Deck
- Pack
- Prism
- Shop Currency

데이터는 절대 초기화하지 마.

==================================================
8. Match 종료 후 입력 금지
==================================================

matchResult가 확정된 뒤에는:

- 카드 플레이
- 공격
- Champion Ability
- End Turn
- Target 선택

등 새로운 Game Action을 할 수 없어야 한다.

최종 애니메이션은 계속 재생할 수 있지만
새 게임 입력은 차단.

==================================================
9. Surrender
==================================================

기존 항복 기능도 동일 Result Screen 사용.

내가 항복:

→ 나는 패배
→ 상대는 승리

정상 Match Result로 처리.

항복 후 reload/reset 방식 사용 금지.

==================================================
10. Champion Token 패배
==================================================

기존 규칙:

특수 배치된 Active Champion Token이 RETIRE하면
소유자가 즉시 패배.

이 경우에도:

Token RETIRE Animation
→ 짧은 연출
→ DEFEAT / VICTORY Result Screen

순서로 표시.

==================================================
11. Audio
==================================================

Result Screen이 뜰 때
기존 임시 Combat/Effect 음악이 남아 있지 않게 정리해.

현재 AudioManager를 사용.

원한다면 향후:

VICTORY_MUSIC
DEFEAT_MUSIC

추가가 가능하도록 구조는 열어둘 수 있지만
이번 작업에서 새 음악 업로드 시스템은 만들 필요 없음.

==================================================
12. 모바일
==================================================

390x844
430x932

에서도:

승리/패배 문구
[메인 화면으로]

버튼이 화면 안에 명확하게 보여야 한다.

==================================================
13. 반드시 테스트
==================================================

TEST 1

상대 Champion HP 0
→ 마지막 피해 Animation
→ 승리 화면
→ 메인 화면 버튼 작동

TEST 2

내 Champion HP 0
→ 패배 화면

TEST 3

항복
→ 패배 화면
→ 상대는 승리 처리

TEST 4

Active Champion Token RETIRE
→ Token RETIRE 연출
→ 즉시 해당 Player 패배

TEST 5

Result 확정 후
카드 플레이/공격/능력 사용 불가

TEST 6

[메인 화면으로]
→ KO Main Menu 이동

TEST 7

메인으로 이동 후
Session / Collection / Deck 데이터 유지

TEST 8

모바일에서도 Result 화면 정상

==================================================
14. 수정 금지
==================================================

이번 작업 때문에:

- Victory 조건 변경 금지
- Combat Engine 변경 금지
- Champion HP 규칙 변경 금지
- Champion Token 패배 규칙 변경 금지
- User 데이터 reset 금지

기존 Match Result를 UI에 연결하는 작업만 해.

==================================================
최종 흐름
==================================================

마지막 전투/효과
↓
Engine에서 Match Result 확정
↓
남은 마지막 Animation 완료
↓

승리
또는
패배

↓
[메인 화면으로]
↓
KO Main Menu

이 흐름을 구현해.
