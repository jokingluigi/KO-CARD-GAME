현재 KO 카드게임에 "Alt 상세정보 보기" 기능을 추가해줘.

이번 작업은 UI/UX 기능 추가이며,
기존 게임 규칙, GameState, 카드 효과, 공격 시스템, 골드 시스템을 변경하지 마.

================================
기본 동작
=====

사용자가 다음 UI 요소 위에 마우스를 올린 상태에서 Alt 키를 누르면 해당 요소의 상세 정보를 보여줘.

대상:

1. 손패의 카드
2. 필드의 선수 카드
3. 플레이 기록에 표시된 카드
4. 챔피언 고유 능력
5. 챔피언 퀘스트
6. 향후 챔피언 토큰 및 기타 카드형 UI

동작:

마우스 Hover
+
Alt 키를 누르고 있음
→ 상세정보 표시

Alt 키를 놓음
→ 상세정보 즉시 닫힘

마우스가 대상에서 벗어남
→ 상세정보 닫힘

즉 클릭할 필요는 없다.

================================
카드 상세정보
=======

카드 위에 마우스를 올리고 Alt를 누르면
해당 카드의 확대된 상세정보 패널을 표시해줘.

최소 표시:

* 카드 이름
* 카드 종류
* 비용
* 공격력
* 체력
* 효과 텍스트
* 키워드
* 카드 이미지가 있다면 이미지

중요:

게임 중 버프/디버프된 카드라면
가능하면 현재 상태를 보여줘.

예:

기본 공격력 2
현재 공격력 5

이라면 현재 공격력 5가 눈에 띄게 표시되게 한다.

필요하다면 작은 글씨로 기본 수치도 표시할 수 있다.

카드 상세정보를 위해 카드 정보를 별도로 하드코딩하지 말고
기존 card definition과 card instance 데이터를 사용해줘.

================================
챔피언 고유 능력 상세정보
==============

챔피언 고유 능력 버튼 위에서 Alt를 누르면:

* 능력 이름
* 비용
* 효과 설명
* 현재 사용 가능 여부

를 표시해줘.

예:

고유 능력
비용: 2G

선수 카드 하나에게 피해 1을 줍니다.

사용할 수 없는 상태라면 이유도 작은 글씨로 표시 가능하다.

예:

"현재 골드가 부족합니다."

단, 상세정보 표시가 실제 능력 사용을 발생시키면 안 된다.

================================
퀘스트 상세정보
========

퀘스트 UI 위에서 Alt를 누르면:

* 퀘스트 이름
* 조건
* 현재 진행도
* 완료 보상

을 표시해줘.

예:

판도라 퀘스트

조건:
고유 능력으로 선수 카드 5장을 리타이어

진행:
3 / 5

보상:
고유 능력을 강화하고 판도라가 직접 출전합니다.

퀘스트 완료 후에는:

완료됨

상태도 표시할 수 있게 한다.

================================
키워드 설명
======

카드 상세정보 안에 키워드가 있다면
키워드 이름과 간단한 설명도 표시할 수 있게 구조를 만들어줘.

예:

기습
→ 등장한 턴에도 적 선수 카드를 공격할 수 있습니다.

러쉬
→ 등장한 턴에도 선수 또는 상대 챔피언을 공격할 수 있습니다.

도발
→ 상대는 가능한 경우 이 선수를 먼저 공격해야 합니다.

회피
→ 처음 받는 피해 1회를 완전히 무효화합니다.

키워드 설명 데이터는 한 곳에서 관리하고
각 카드마다 중복 작성하지 마.

================================
정보창 위치
======

정보창은 마우스 바로 아래를 가리지 않게 해줘.

기본적으로 Hover한 요소의 옆에 표시한다.

화면 오른쪽 공간이 부족하면 왼쪽에 표시하고,
아래 공간이 부족하면 위쪽으로 자동 배치해줘.

정보창이 화면 밖으로 잘리지 않도록 viewport 범위를 고려한다.

================================
디자인
===

KO 게임 UI 스타일에 맞는 작은 카드 정보 패널로 만들어줘.

너무 큰 모달창은 사용하지 않는다.

게임 화면 위에 floating tooltip / inspection panel 형태로 표시한다.

추천:

* 어두운 반투명 배경
* 명확한 테두리
* 카드 이름 강조
* 공격력/체력/비용을 쉽게 구분
* 효과 텍스트는 읽기 편한 크기

게임 화면을 심하게 가리지 않게 한다.

================================
Alt 입력 처리
=========

전역적으로 Alt 키 상태를 추적할 수 있게 한다.

예:

Alt keydown
→ isAltPressed = true

Alt keyup
→ isAltPressed = false

하지만 브라우저 기본 동작이나 다른 입력을 불필요하게 방해하지 마.

Alt 키만 눌렀다고 정보창이 뜨면 안 된다.

반드시:

현재 Hover 중인 Inspect 가능한 대상이 존재하고
+
Alt가 눌려 있을 때

만 상세정보를 표시한다.

================================
포커스 문제 방지
=========

Alt 키를 누른 뒤 브라우저 창의 포커스를 잃거나
Alt keyup 이벤트를 놓치는 경우가 있을 수 있다.

window blur 또는 document visibility 변경 시
isAltPressed 상태를 false로 초기화해서
정보창이 계속 열린 채로 남지 않게 해줘.

================================
게임 조작과 충돌 방지
============

Alt 상세정보 기능은 게임 Action을 실행하면 안 된다.

예:

Alt + Hover
→ 카드 사용 안 됨
→ 공격 안 됨
→ 챔피언 능력 사용 안 됨

오직 정보 표시 기능이다.

카드 클릭이나 공격 대상 선택 등 기존 조작은 그대로 유지한다.

================================
플레이 기록과 연동
==========

왼쪽 Play History에 표시된 카드 미니어처도
Alt + Hover로 상세정보를 볼 수 있게 해줘.

가능하면 당시 사용된 카드의 정보를 보여준다.

단순히 이름 문자열만 저장되어 있다면
cardDefinitionId 또는 관련 card id를 통해 실제 카드 데이터를 참조하도록 해줘.

================================
재사용 가능한 구조
==========

공통 Inspectable UI 구조를 만들어줘.

예:

Inspectable
CardInspector
InfoTooltip
useAltInspect

등 기존 코드 스타일에 맞게 구현해도 된다.

카드, 챔피언 능력, 퀘스트마다
Alt 처리 코드를 따로 복붙하지 마.

한 개의 공통 상세정보 시스템을 사용해줘.

================================
모바일 대비
======

Alt 키가 없는 모바일에서는 이 기능이 작동하지 않아도 된다.

하지만 향후 모바일에서:

길게 누르기
또는
정보 버튼

으로 같은 상세 패널을 열 수 있도록
상세정보 UI 자체는 Alt 입력과 완전히 결합하지 말아줘.

즉:

"정보를 표시하는 시스템"
과
"PC에서 Alt + Hover로 여는 입력 방식"

을 분리해서 설계한다.

================================
테스트
===

다음을 확인해줘.

1. 손패 카드 Hover + Alt
   → 카드 상세정보 표시

2. Alt 놓기
   → 즉시 닫힘

3. Hover 해제
   → 닫힘

4. 필드 카드
   → 정상 표시

5. 챔피언 능력
   → 능력 비용/효과 표시

6. 퀘스트
   → 조건/진행도/보상 표시

7. Play History 카드
   → 상세정보 표시

8. 화면 가장자리에서도 패널이 잘리지 않음

9. Alt + Hover 때문에 카드가 사용되거나 공격되지 않음

10. 창 포커스를 잃어도 정보창이 고정되어 남지 않음

기존 게임 로직을 수정하거나 대규모 리팩터링하지 마.
