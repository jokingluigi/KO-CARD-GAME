KO CARD GAME — CLICKABLE CARD TAG POPUP / TAG CARD DIRECTORY

목표:
카드 상세정보(Card Info / Card Detail)에서 `태그`를 클릭하거나 탭하면,
그 태그를 가진 카드들이 어떤 카드들인지 즉시 확인할 수 있는 팝업을 추가한다.

예:

카드 상세정보

태그:
[좀비] [언데드]

사용자가 [좀비] 클릭

→ 팝업:

┌──────────────────────────────┐
│ 좀비 태그                     │
│ 이 태그를 가진 카드 8종        │
│                              │
│ [카드] [카드] [카드]          │
│ [카드] [카드] [카드]          │
│                              │
│                      [닫기]   │
└──────────────────────────────┘

중요:
이 기능은 cards.tags canonical metadata를 사용한다.
옛날 effect keyword "태그"나 카드 텍스트를 문자열 검색해서 만들지 않는다.

==================================================
1. CANONICAL TAG SOURCE
==================================================

KO CARD GAME의 카드 태그 source of truth는:

cards.tags

이다.

절대 하지 말 것:
- card text에서 태그 이름 문자열 검색
- keyword와 tags 혼합
- effect DSL의 tagsAny를 카드 자체 tag처럼 사용
- 카드 이름으로 tag 추정
- 별도 hardcoded tag → card list 테이블 만들기

Popup 목록은 실제 CardDefinition.tags를 기준으로 동적으로 생성한다.

==================================================
2. 클릭 가능한 TAG CHIP
==================================================

현재 Card Detail에서 태그가 텍스트로만 표시된다면
각 태그를 clickable/tappable chip으로 변경.

Desktop:
click

Mobile:
tap

Keyboard:
focus + Enter/Space 가능하면 지원.

hover 전용 기능 금지.

==================================================
3. TAG POPUP 기본 동작
==================================================

Tag chip 클릭:

openTagPopup(tag)

Popup에:
- 선택한 태그 이름
- 해당 태그를 가진 카드 개수
- 카드 목록
- 닫기 버튼

표시.

==================================================
4. 카드 목록
==================================================

Popup의 카드들은 실제 CardDefinition을 사용.

최소 표시:
- 카드 이미지
- 카드 이름
- 비용
- 희귀도
- Card Type
- ATK / HP (WRESTLER인 경우)

Card Type에 따라 없는 stat을 억지로 표시하지 말 것.

==================================================
5. 카드 클릭
==================================================

Tag Popup 안의 카드를 클릭하면
그 카드의 Card Detail을 확인할 수 있게 한다.

권장:
Tag Popup
→ Card click
→ Card Detail

가능하면 Card Detail 닫기 후 기존 Tag Popup으로 돌아올 수 있게 한다.

==================================================
6. PUBLISHED / UNPUBLISHED 보안
==================================================

일반 사용자에게는 공개되지 않은 CardDefinition을 Tag Popup을 통해 노출하면 안 된다.

NORMAL PLAYER:
→ 현재 일반 카드 Catalog에서 볼 수 있는 카드만 표시
→ 기본적으로 PUBLISHED public cards only

ADMIN:
관리자 전용 catalog context라면 현재 권한 정책에 따라 DRAFT 등을 볼 수 있어도 됨.

하지만 일반 Collection/Deck/Battle의 Tag Popup에서:
DRAFT/비공개 카드 이름, 이미지, 텍스트가 새어 나오면 FAIL.

==================================================
7. 미보유 카드
==================================================

공개된 카드라면 사용자가 보유하지 않아도 Tag Popup에는 표시 가능.

PUBLISHED + owned
→ 표시

PUBLISHED + unowned
→ 표시

UNPUBLISHED
→ 일반 사용자에게 비표시

==================================================
8. 보유 여부 표시
==================================================

가능하면:
보유 2
미보유

등 기존 ownership UI를 재사용.

단 ownership fetch 실패가 Tag Popup 전체를 막으면 안 됨.

보유 수량 source of truth는 Collection/Inventory.

Deck count와 혼동 금지.

==================================================
9. 여러 태그
==================================================

예:
Card A tags = ["좀비", "마족"]

[좀비] → 좀비 카드 목록
[마족] → 마족 카드 목록

각 chip은 독립적으로 동작.

==================================================
10. 정렬
==================================================

기본 정렬은 현재 Card Catalog 정렬 convention을 재사용.

태그마다 랜덤 순서 금지.

==================================================
11. 카드 수 표시
==================================================

count는 실제 필터링 후 사용자에게 보이는 결과 기준.

예:
전체 DB 좀비 10
PUBLISHED 8
DRAFT 2

Normal Player popup:
`이 태그를 가진 카드 8종`

hidden count도 노출하지 말 것.

==================================================
12. 빈 결과
==================================================

0개면:
`이 태그를 가진 공개 카드가 없습니다.`

crash 금지.

14. TAG CHIP 디자인
==================================================

현재 KO CARD GAME UI 색상 체계 재사용.

==================================================
15. 적용 범위
==================================================

가능하면 shared Card Detail component 기준으로:
- Collection
- Deck Editor
- AI Match
- Online Match에서 공개된 카드 상세
- Pack result
- Craft detail

에서 재사용.

Admin-only component에만 구현 금지.

==================================================
16. ONLINE / HIDDEN INFO
==================================================

Tag Popup은 public CardDefinition catalog를 조회하는 기능.

절대 노출 금지:
- 상대 hand identity
- 상대 deck identity
- hidden generated card
- unpublished card
- randomSeed

==================================================
17. PERFORMANCE
==================================================

태그 클릭마다 DB 전체를 무조건 새로 요청하지 말 것.

가능하면 이미 로드된 public CardDefinition catalog 사용.
또는 기존 public card catalog endpoint에 tag filter 추가.

Tag별 cache 가능.

==================================================
18. API
==================================================

새 API가 필요하면 일반 사용자용 public catalog read.

예:
GET /api/cards?tag=좀비

일반 Card Detail에서 `/api/admin/cards` 사용 금지.

==================================================
19. TAG 비교
==================================================

DB tag canonical exact value 기준.

기존 normalization이 있다면 재사용.

이번 기능에서 임의 fuzzy matching 새로 만들지 말 것.

==================================================
20. 태그 설명은 필수 아님
==================================================

요청 핵심은:
"이 태그에 어떤 카드들이 있는지"

따라서 필수:
Tag → matching cards

태그 설명/도감 lore 시스템은 만들 필요 없음.

==================================================
21. Normal User 우선 검증
==================================================

최근 Admin-only 적용 회귀가 있었으므로 반드시 NORMAL AUTHENTICATED USER로 먼저 검증.

Admin 계정에서만 Tag Popup이 작동하면 FAIL.

23. Deck Ownership 회귀 금지
==================================================

Popup에서 ownership count를 표시할 경우:

ownedCount != deckCount

Tag Popup은 inventory를 mutate하지 않는다.

읽기 전용.

29. 완료 조건
==================================================

1. Card Detail의 각 tag가 클릭/tap 가능.
2. 클릭한 tag를 가진 공개 카드들을 popup으로 표시.
3. cards.tags만 source of truth로 사용.
4. 미보유 공개 카드도 목록에 포함.
5. 일반 사용자에게 DRAFT/비공개 카드 노출 없음.
6. Popup에서 카드 선택해 상세정보 확인 가능.
7. 여러 tag 각각 정상 작동.
8. Collection/Deck/Match 등 shared Card Detail에서 재사용.
9. 모바일 tap 지원.
10. Normal User에서 정상 작동.
11. Admin privilege 불필요.
12. Deck ownership count와 혼동 없음.
13. Production 데이터 mutation 없음.

핵심:
태그를 단순 텍스트가 아니라 "같은 태그를 가진 카드들을 탐색하는 진입점"으로 만든다.

사용자가 카드 상세에서 [좀비]를 누르면
현재 공개된 모든 좀비 태그 카드가 즉시 보이는
간단하고 빠른 카드 도감형 팝업을 구현하라.
