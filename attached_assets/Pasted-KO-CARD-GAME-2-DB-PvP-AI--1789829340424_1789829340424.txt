KO CARD GAME 다음 수정 작업을 진행해줘.

이번 작업은 2가지다.

중요:
- 카드 아트/이미지는 건드리지 마.
- DB를 초기화하지 마.
- 온라인 PvP/AI 구조를 대규모로 재작성하지 마.
- 기존 generic Technique 시스템을 그대로 사용해.
- 카드 이름 하드코딩으로 전투 효과를 새로 구현하지 마.

==================================================
1. 골드/G 표시 정규화 안전성 검증
==================================================

지난 작업에서 사용자 표시 용어를 한국어로 통일하면서
Gold/G 표현을 골드로 정규화했다.

반드시 현재 구현을 확인해서 숫자가 유실되지 않는지 검사해.

예:

"1G를 얻습니다"
→ "1골드를 얻습니다"

"다음 턴 +1 Gold"
→ "다음 턴 +1골드"

절대로:

"1G"
→ "골드"

처럼 수치가 사라지면 안 된다.

검사 대상:
- 카드 효과 텍스트
- 챔피언 능력 텍스트
- 상점
- 덱 편집
- AI Match
- Online Match
- Collection

정규식/string replace가 있다면
1G, 2G, 3G, +1G 등 수치를 보존하는지 확인해.

실제 공개 카드 49장 및 Champion 텍스트에서
G/Gold가 포함된 문장을 검색하고 변환 전/후 예시를 보고해.

숫자 손실 문제가 있으면 수정해.

==================================================
2. 오심정정 / 저지먼트를 TECHNIQUE 카드로 수정
==================================================

오심정정과 저지먼트는 기획상 WRESTLER가 아니라 TECHNIQUE 카드다.

현재 QA에서는 둘 다
WRESTLER / 공격 0 / 체력 0으로 표시되고
TECHNIQUE 필터에도 포함되지 않았다.

이 두 카드를 TECHNIQUE로 정상화해.

대상 카드:
- 오심정정
- 저지먼트

수정 시 반드시 확인할 것:

1. cardType을 TECHNIQUE로 변경
2. Collection의 TECHNIQUE 필터에 포함
3. 덱 편집에서도 기술 카드로 표시
4. 선수 카드처럼 공격력/체력을 핵심 정보로 표시하지 않음
5. Board slot을 차지하지 않음
6. 빈 Board slot이 없어도 사용 가능
7. PLAY_WRESTLER 경로가 아니라 기존 PLAY_TECHNIQUE 경로 사용
8. targeted Technique라면 기존 pendingSelection / PLAYER_CHOICE 사용
9. no-target Technique라면 즉시 resolve
10. 사용 후 정상적인 Technique zone 이동 처리
11. 0/0 선수로 필드에 올라가는 일이 절대 없어야 함
12. 기존 효과의 실제 의미는 유지
13. Technique 전환을 이유로 카드 효과를 이름 하드코딩하지 말 것

==================================================
오심정정
==================================================

기존 카드 효과 의미는 유지.

묘지의 선수 카드를 회수하는 기술 카드로 동작해야 한다.

확인:
- 기술 카드 사용
- 필요한 선택이 있다면 기존 generic target/selection 시스템 사용
- 선수로 필드에 생성되지 않음
- 효과 해결 후 Technique 카드 처리 정상

==================================================
저지먼트
==================================================

기존 카드 효과 의미는 유지.

상대 선수를 리타이어시키는 기술 카드로 동작해야 한다.

확인:
- 기술 카드 사용
- 대상 선택이 필요하면 기존 generic PLAYER_CHOICE/pendingSelection 사용
- 대상은 효과 문구와 기존 규칙에 맞는 상대 WRESTLER
- 선수로 필드에 생성되지 않음
- 효과 해결 후 Technique 카드 처리 정상
