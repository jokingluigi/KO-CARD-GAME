KO CARD GAME — FIX ONLY: PANDORA TARGETING + LINKED CHAMPION TOKEN DEPLOYMENT

이번 작업에서는 판도라 관련 아래 두 문제만 수정한다.

1. 판도라 Champion Ability가 현재 아군 WRESTLER만 지정되는 문제
2. 판도라가 자신의 "연결된 Champion Token 카드"를 정상적으로 소환하지 못하는 문제

매우 중요:

Champion Token은 generic token이 아니다.

각 Champion에게는 해당 Champion과 연결된
전용 Champion Token CardDefinition이 존재한다.

Champion이 Champion Token을 소환할 때는
반드시 그 Champion에게 연결된 Champion Token 카드를 찾아
그 CardDefinition으로 CardInstance를 생성/배치해야 한다.

예:

Pandora Champion
→ Pandora에 연결된 Champion Token CardDefinition
→ 해당 Token CardInstance 생성
→ Champion Token context로 배치

다른 Token 카드,
동일 tag 카드,
이름이 비슷한 카드,
fallback token

을 임의로 사용하면 안 된다.

==================================================
10. CardDefinition과 Champion Token context는 별개
==================================================

같은 Token CardDefinition을 사용하더라도
Champion Token으로 배치된 instance는
Champion Token deployment context/marker를 가져야 한다.

즉:

CardDefinition identity

와

Champion Token status

를 구분.

예:

linked Token CardDefinition X를
Champion Token deploy action으로 생성

→ isChampionToken = true

반면 동일 X가
일반 SUMMON으로 생성될 수 있다면:

→ ordinary summon
→ isChampionToken = false

이어야 한다.

==================================================
11. ordinary SUMMON != Champion Token
==================================================

매우 중요.

Champion Token의 특별 규칙은:

"어떤 CardDefinition인가?"

만으로 판정하면 안 된다.

Champion Token 전용 deployment context를 통해 판정.

동일 CardDefinition을 일반 SUMMON했다고 해서
원래 Champion이 보호되거나
Champion Token 규칙이 발동하면 안 된다.

==================================================
12. Champion Token 공식 공통 규칙
==================================================

Pandora linked Champion Token이 정상 field 배치되면:

- Token은 자신의 CardDefinition stats 사용
- original Champion HP를 Token에 합산하지 않음
- Token RETIRE != 즉시 경기 패배
- Token이 정상 field에 있는 동안 original Champion 보호
- original Champion Ability 계속 사용 가능
- Token이 field를 떠나면 original Champion protection 종료
- original Champion HP는 Token 생성 전 값을 그대로 유지

Champion Token은 기존 공식 규칙에 따라:

SILENCE
DESTROY
REMOVE_FROM_GAME

면역 유지.

하지만:

normal DAMAGE
combat DAMAGE

는 정상 적용.

HP <= 0:

RETIRE.
