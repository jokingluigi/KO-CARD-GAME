# 10월 30일 관리자 카드 변경: 실제 효과 반영

별도 작업 브랜치 `feat/final-sprite-reactions-review`. 정상 관리자 인증 후 `/api/admin/cards`, `/api/admin/champions` GET으로 최신 정의를 확인했다. 점검 모드는 유지했다. 카드·챔피언·덱·보상에 대한 운영 수정 요청이나 직접 SQL 변경은 하지 않았다. 관리자 로그인에 따른 세션 생성은 일반 인증 경로를 사용했다.

## 확인한 변경과 구현

| 카드 | 저장된 최신 내용 | 실제 처리 |
|---|---|---|
|절멸|현재 공격력 2 이하인 모든 선수 침묵|양쪽 필드의 현재 공격력으로 대상을 결정하고 기존 SILENCE 처리. 파괴 효과와 교체. 고유 파괴·리타이어 효과를 새로 발동시키지 않는다.|
|헬뻑|선수가 소환되거나 등장하면 1피해, 상대 한정 문구 제거|기존 CARD_ENTERED 경로에서 아군/상대 각각 관찰. 손에서 내기·효과 소환에 한 번씩 적용. 자신의 첫 등장에는 기존 관찰자 규칙대로 자기 반응을 추가하지 않으며, 침묵·필드 이탈 시 기존 정지 규칙 적용. 이전 턴 종료 전체 피해로 돌아가지 않는다.|
|폭죽광|상대 선수에게 무작위 총 2피해, 1코스트 1/1|기존 결정적 난수로 1피해를 두 번 처리하며 매번 살아 있는 유효 대상을 다시 고른다. 적 챔피언에게 넘기지 않는다. 기존 면역·아머 처리 유지.|
|묘지지기|아군 리타이어마다 다른 아군 선수 중 무작위 한 장 +1/+1|기존 리타이어 리스너의 무작위 단일 선택으로 변경. 상대 리타이어·파괴·소멸은 새로 포함하지 않는다. 자기 자신 강화·대상 선택 팝업 없음.|
|좀비 플래티넘구슬 마스터|아군 언데드 한 장 +2/+2 후, 그 카드의 공격력만큼 자신의 공격력 증가; 6코스트 0/7|선택 → +2/+2 → 강화 후 현재 공격력 읽기 → 자신의 공격력에 더하기. 적/비언데드 선택 불가. ‘다른’ 제외 조건이 없어 자기 자신도 선택 가능하며 이 경우 0/7 → 4/9. 이전 좀비 생성·최대 능력치 흡수는 실행하지 않는다.|
|퍼플레인|설명/효과 설정은 이전과 동일, 비용만 5→6|저장된 비용 6을 그대로 읽는 것 확인. 기존 효과를 별도 밸런스로 덮어쓰지 않았다.|

**좀비 플래티넘구슬 마스터는 저장된 현재 상태가 DISABLED다.** 효과 구현을 위해 이 상태를 PUBLISHED로 바꾸지 않았다. 브라우저 검증은 격리된 QA 상태에 이 정의를 넣어 수행했으며 실제 일반 게임에서 비활성 카드가 사용 가능해졌다는 뜻은 아니다.

기존 정의 변환기에서 안정 ID와 최신 설명이 일치할 때만 검토된 효과를 선택한다. 다른 카드·이전 문구·앞으로 변경되는 문구에 최신 효과를 강제로 씌우지 않는다. 공통 `@workspace/game-engine`을 사용하는 클라이언트, 서버 AI, 온라인 전투가 같은 변환기를 참조한다. 기존 경기 스냅샷은 새 카드 정의로 덮어쓰지 않는다.

## 심리학/표현 연결

무작위 한 장 강화와 직접 한 장 선택을 구분해 사용자의 통제감을 보존했다. 좀비 마스터는 기존 유효 대상 강조와 선택 수 안내를 사용하며, 강화 후 공격력 참조 순서를 실제 수치 변경 이벤트로 표현한다. 기존 피해·침묵·리타이어·능력치 피드백을 재사용해 같은 사건을 중복 연출하지 않는다. 설명과 실제 결과를 일치시키는 것이 이번 작업의 핵심이다. 사용자 만족도나 체감 개선을 입증했다고 주장하지 않는다.

## 코드

- 신규 `game/cards/reviewed-admin-content-20261030.ts`: 검토된 다섯 효과의 런타임 정의.
- `game/cards/published-cards.ts`: 새 정의 우선 연결 및 이전 콘텐츠 동작 표식 혼입 방지.
- `lib/effect-registry/src/index.ts`: SCRIPT_V1 선택 대상의 `allowSource?: boolean` 명시적 옵션과 형식 검증. 기본값은 기존대로 자기 제외.
- `game/effects/effect-engine.ts`: 명시적으로 허용한 SCRIPT 선택에서만 자기 대상 허용. 다른 카드의 기본 대상 규칙은 변경하지 않는다.
- 신규 `game/qa/card-revisions-20261030.test.ts`, 브라우저 검사 및 날짜별 관리자 정의 스냅샷.

## 실제 검증

- 프런트/서버 TypeScript, effect-registry 선언 빌드, 프런트/서버 프로덕션 빌드 통과.
- 효과·회귀 **487개 통과**: 신규 26개 시나리오와 기존 10/24 밸런스, 10/14 선수·주문, 저장 효과, SCRIPT 선택/반복/연속 처리 검사.
- 신규 검사는 실제 손패 사용·효과 소환·퇴장·JSON 직렬화 후 대상 선택을 사용했다. 피해 0/면역/아머, 첫 대상 사망 후 재선택, 양측 등장, 복수 헬뻑, 무대상, 리타이어/파괴/소멸 구분, 침묵, 자기 선택의 명시적 허용과 기본 금지를 포함한다.

## 미검증/유의점

실기기, 실제 2인 PvP·재접속, 운영 서버의 라이브 경기/보상 처리는 실행하지 않았다. 운영 데이터를 쓰는 테스트 경기는 생성하지 않았다. 변경은 새 경기의 최신 정의 변환에 적용하며, 시작된 경기의 수치를 도중에 새 문구에 맞춰 바꾸지 않는다. 비활성 카드의 공개 여부는 관리자가 별도로 결정한다.
