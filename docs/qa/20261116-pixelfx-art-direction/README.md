# KO art direction revision

Feedback: effect shape and atmosphere do not fit the card game. The prior library expansion mixed stock arcane, holy, sci-fi and cartoon silhouettes and automatically layered two effects. Counting visible preview pixels did not validate stylistic fit.

Authored 21 transparent effects with the actual PIXELFX painter, using a shared brass/charcoal vocabulary. Heal uses muted jade, negative status burgundy, dark champion signatures muted violet. Metal cuts, angular fragments, card corners, low landing ellipses and restrained streaks replace stock holograms, towering holy pillars, multicolour orbs and magical circles in ordinary interactions. Champion/finisher motifs retain semantic family distinctions through the same authored style.

All 140 event recipes resolve through the art direction policy. The raw 137-effect catalogue remains archived as source material; it is not automatically mixed into active scenes. The active 21-atlas set totals 240,292 bytes, loaded on demand with four common effects preloaded. Each recipe now plays one authored composition; duplicate generic attack/ability charge bursts were removed. Game rules, targets, physical contact clocks and input locks are unchanged.

Settings now provides a dark card target on a warm board-like background. Replay uses this target instead of exploding on the replay button.

Validation:

- Frontend typecheck and production build.
- 16 tests: existing combat/preferences plus semantic family routing and all-area asset availability.
- 140 preview recipes on desktop and true touch browsers; visible pixels, bounds, cleanup, concurrency and accessibility preferences.
- Actual attack/heal, status/capture/countdown, pack seal and rarity reveals, crafting, identical snapshot baseline, missing asset fallback and touch landscape.
- Settings route independently tested; inspected contact sheet, card-stage heal and mobile battle contact screenshots.
- All 21 PNG hashes, nonempty alpha and transparent final frames checked.

Visual fit remains a subjective review. No claim that this style has been accepted by the user or that every live champion/finisher combination was played. Browser emulation is not a physical-device test.
