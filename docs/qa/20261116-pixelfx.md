# PIXELFX battle effects

Uses [patch-gg/pixelfx](https://github.com/patch-gg/pixelfx) at `5294518ce7c72e48b6100a744596e0acf57f2826` (MIT). Followed its [authoring skill](https://github.com/patch-gg/pixelfx/blob/5294518ce7c72e48b6100a744596e0acf57f2826/skills/pixelfx/SKILL.md) and drawing API. No Patch account, plugin, paid service, gallery font, or stock character is required or shipped.

Four original KO effects are rendered into transparent atlases: a six-ray gold contact, a larger critical burst, a cyan prism guard, and a mint renewal ring with rising crosses. Inspected three impact drafts, revised the burst/guard opacity and healing silhouette, then checked the resulting frames over the actual board at mobile and desktop sizes.

- IMPACT below 8 strength: contact atlas. IMPACT at 8 or above: critical atlas.
- BLOCK and ARMOR: guard atlas. Wrestler HEAL: renewal atlas. Other effect kinds retain their existing renderer.
- Existing event duration, delay, contact position and impact direction drive playback. No extra input lock or engine timer is introduced.
- PNG requests use content-hashed filenames. Four PNGs total 146,894 bytes. Only cached atlas images and a frame draw run in the browser; the procedural authoring library is not bundled.
- Reduced motion suppresses animation. Flash intensity controls opacity; zero flash and failed atlas loads use the existing renderer. Frames clear at the end and on tab hiding/unmount.
- Upstream license and notices are included with the generated public assets.

Validation:

- PIXELFX `tools/check.mjs ko`: 4/4 passed, zero warnings (bounds, deterministic frames, empty ending, render budget).
- Existing combat presentation/preference model tests: 13 passed.
- `node docs/qa/pixelfx-browser.mjs`: Chromium 390×844 and 1440×900; nonempty frames, visual samples, end cleanup, pointer passthrough, actual engine combat/block/heal, zero-flash fallback and reduced motion passed. Separate missing-atlas fallback passed. Physical devices were not tested.
- Frontend type check and production build passed.

Regenerate the committed assets with `node scripts/vfx/render-pixelfx.mjs /path/to/pinned-pixelfx`. The companion authoring file is `scripts/vfx/ko-pixelfx-effects.mjs`. No authoring dependency install is needed.
