# 필드 드래그 공격·덱 제거 버튼 — 2026-10-15

기존 소환 드래그는 유지하고, 아군 필드 선수에서 상대 선수·챔피언으로 끌어 놓는 공격을 추가한다. 엔진의 `getLegalActions`로 드래그 시작과 드롭을 검증하고 기존 탭 공격 콜백을 사용한다. 공격 수치·게임 규칙·연출·서버 판정은 변경하지 않는다. 9px 이하는 기존 탭이며, 드래그 후 합성 click은 한 번 억제하여 중복 공격을 막는다. 잘못된 대상·영역 밖·Escape·터치 취소·화면 회전·백그라운드·턴 변경은 공격을 보내지 않는다.

덱 편성의 제거 버튼은 카드 정보 감지 래퍼 밖의 형제 요소로 분리한다. 기존 구조는 모바일 `−`의 pointer 이벤트가 래퍼에서 차단된 뒤 합성 hover가 정보창을 여는 문제가 있었다. 기존 main으로 브라우저 테스트를 실행해 첫 제거에서 정보창이 열리는 실패를 재현했다. 패치 후 제거 2회·다시 추가·의도적 카드 상세보기·로컬 모의 덱 저장을 검사했다. 운영 계정/덱에 저장하지 않았다.

- 드래그 공격: 360×740, 390×844, 412×915, 1440×900 통과. 실제 CDP touch/mouse 입력으로 선수·챔피언 공격, 방어·도발·챔피언 토큰·소환 턴·상대 턴 차단, 취소·영역 밖 복귀, 기존 탭 공격, 확대율 1, 가로 넘침 없음 검사.
- 덱 제어: 320×740, 390×844, 430×932, 1440×900 통과. API는 전부 로컬 fixture로 가로채고 저장 요청은 모의 응답한다.
- 실제 모바일 기기 검증 미실행. Chromium 모바일 에뮬레이션.
- 두 브라우저 검사를 기존 CI에 등록했다. 최종 CI/배포 결과는 PR에 기록한다.

최신 관리자 선수 효과 변경 작업은 규칙 답변 대기 항목이 있어 별도 브랜치로 보존한다. 이 조작 수정에는 카드·챔피언 효과 변경을 포함하지 않는다.
