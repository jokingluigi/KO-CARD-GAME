# 실제 플레이 전후의 품질 개선 — 2026-11-03

메타크리틱 90점이라는 외부 평가를 달성했다고 주장하지 않는다. 이번 패치는 덱 준비 중의 데이터 보존, 실패 상태의 명확성, 화면 업데이트 복구와 탐색 편의에 집중했다. 카드·챔피언 효과, 전투 엔진, 카드 데이터, 퀘스트와 보상은 변경하지 않았다. 기존 작업 브랜치를 유지하며 main 병합과 DB 변경은 하지 않는다. 사용자 지시에 따라 검증 후 프론트엔드를 직접 배포한다.

## 구현

- **작성 중인 덱 보존:** 초기 덱 목록 로딩 실패에만 읽기 재시도를 제공한다. 저장 오류 안내에서 인증과 목록 전체를 다시 불러와 현재 편집을 바꾸던 경로를 없앴다. 저장 실패 시 현재 편집 내용과 기존 계정별 임시 보관은 유지된다. 오류 위치로 초점을 이동해 화면 아래에서 실패를 놓치지 않게 한다.
- **요청 중 입력 보호:** 저장·출전 지정·삭제는 동기적인 요청 잠금으로 중복 클릭을 막는다. 네이티브 disabled fieldset으로 이름·챔피언·추가/제거·덱 전환을 잠깐 막는다. 실패 또는 완료 후 해제한다. 응답 유실 뒤 새 POST를 영구적으로 중복 방지하는 서버 구현을 추가했다는 뜻은 아니다.
- **확정된 결과 표시:** 출전 지정·삭제의 성공 응답을 바로 목록에 반영한다. 성공 후 불필요한 GET 실패 때문에 작업까지 실패했다고 안내하지 않는다. 출전 지정 시 이전 덱의 선택 표시도 갱신한다. 삭제는 서버가 성공한 경우에만 로컬 목록에서 제거한다.
- **삭제 확인창:** 브라우저 기본 확인창 대신 기존 Radix 확인창을 사용한다. 대상 이름과 ‘덱 구성만 삭제, 보유 카드·스킨 유지’를 설명한다. 기본 초점은 취소인 ‘계속 보관’, 취소하면 삭제 버튼으로 초점을 복귀한다. 삭제 후 새 편집의 이름으로 이동한다. 44px 버튼·작은 화면 높이·움직임 감소를 지원한다.
- **검색 막힘 해소:** 덱/컬렉션의 빈 검색 결과에 ‘검색·필터 초기화’를 제공한다. 이름·종류·보유/등급/태그/코스트·즐겨찾기를 초기화하고 검색 입력으로 초점을 돌린다. 컬렉션의 정렬 순서는 유지한다. 빈 보유 목록과 필터 때문에 결과가 없는 경우의 설명을 정리했다.
- **화면 파일 복구:** 배포/연결 문제로 lazy 화면 모듈 또는 CSS를 불러오지 못하면 전용 설명과 ‘화면 다시 불러오기’를 표시한다. React.lazy의 거절된 모듈을 같은 화면에서 반복 실행하는 대신 현재 문서를 다시 불러온다. 자동 새로고침 루프나 구매 자동 재시도는 없다. 일반 렌더링 오류의 기존 ‘다시 시도’는 유지한다.
- **느린 화면 로딩:** 라우트 로딩이 10초를 넘으면 기다림 또는 사용자가 선택하는 새로고침을 안내한다. 뒤늦게 로딩이 완료되면 정상 화면으로 진입한다. 컴포넌트 이탈/경로 변경 시 타이머를 정리한다.

## 심리학 적용

행동 통제감(작성 내용 보존·명확한 결과·초점 복귀), 실수 방지(중복 요청 잠금·삭제 취소 우선), 인지 부하 감소(초기화 한 번으로 목록 복귀), 피츠의 법칙(44px 확인 버튼), 감각적 피로와 접근성(움직임 감소 시 확인창 축소 전환 생략)을 적용했다. 실제 사용자 오류율/만족도 개선을 실험으로 입증한 결과는 아니다.

## 실제 검증

- 전체 타입 검사·프론트엔드 프로덕션 빌드 통과. 관련 단위 검사 21개 통과: 화면 오류 구분, 요청 제한/취소, 출전 덱, 덱 구성 검증과 카드 추가 가능 여부.
- 실제 앱을 개발 서버와 프로덕션 빌드에서 실행하고, 390×844·844×390·1440×900에서 API 응답을 격리해 검사했다. 모바일 세로는 터치/모바일 컨텍스트를 사용했다. 물리 기기 검증은 아니다.
- 초기 목록 503 → 읽기 재시도, 저장 중 이름/덱 전환 비활성·중복 클릭 1회 요청, 저장 거절 뒤 이름·임시 보관 유지, 오류 초점, 출전 지정/삭제 성공 뒤 목록 GET 없음, 삭제 취소 시 요청 없음과 초점 복귀, 버튼의 44px/화면 내 배치, 검색 초기화를 확인했다.
- 화면 모듈 요청을 1회 차단한 뒤 전용 오류 안내 → 사용자의 새로고침 → 실제 설정 패널 진입을 확인했다. 별도 페이지에서 모듈 요청을 보류하고 브라우저 시계를 10.1초 진행해 복구 버튼 표시, 이후 응답 재개로 정상 진입을 확인했다.
- 기존 48개 경로/화면 조합과 비회원 실제 연습 소환 통과. 10경로×3크기의 첫 화면에 보이는 컨트롤 검사에서 가로 넘침·작은 대상·이름 없는 대상·페이지 오류 0개. 전체 관리자나 화면 밖의 모든 조작을 감사했다는 뜻은 아니다.
- 확인창 첫 측정 실패는 등장 애니메이션 중 44px 버튼이 일시 축소된 순간을 측정한 결과였다. 움직임 감소 모드에서 애니메이션을 생략하고 전환 완료 후 배치 검사를 다시 통과했다.

## 남은 범위

실물 iOS/Android, 장시간 두 클라이언트 PvP, 실제 사용자의 탐색/오류/피로, 전체 사운드의 청감과 밸런스·메타 평가는 이번 검사에 포함하지 않았다. 신규 덱 저장 응답 유실 시 서버 측 idempotency, 장시간/복수 탭 편집 충돌의 완전한 해결도 이번 작업 범위에 포함되지 않는다. 90점이나 모든 결함 해결을 선언하지 않는다.
