# 꾸미기 화면·챔피언 이미지 이모티콘 개선

## 바뀐 경험

꾸미기는 각 아이템마다 큰 미리보기·설명·장착·비교·전투 미리보기·찜 버튼을 모두 반복하던 형태에서, 보유 목록과 선택 항목 상세를 분리했다. PC는 오른쪽 미리보기, 모바일/좁은 가로 화면은 상세 다이얼로그다. 챔피언·카드·뒷면·이모티콘 네 분류와 보유 수, 이름/캐릭터 검색, 최근 획득/이름 정렬, 장착 중 필터를 제공한다. 이미지만 눌러도 장착되지 않고 명시적인 적용 버튼을 사용한다. 실패 시 선택을 유지하고 메시지를 표시한다. 카드 프레임·원본 데이터·스킨 소유/장착 API는 그대로다.

이모티콘은 슬롯 없이 보유 목록에서 사용하는 기존 동작을 유지한다. 새 목록은 이미지와 이름 중심으로 정리했고, 실제 장착/해제는 스킨과 카드 뒷면에만 제공한다. 기존 비교·전투 액자/표정 미리보기·수집 목표 기능은 선택 상세로 모았다. 기본/장착 상태와 미선택/검색 결과 없음/조회 실패를 구분한다. 신규 재화·교환소·뽑기 보상 정책은 이번 변경에 추가하지 않았다.

대전 이미지 이모티콘은 발화한 챔피언 옆에 꼬리가 향하는 말풍선으로 바꿨다. 내/상대 방향을 구분하고 화면 경계에 맞춘다. 기존에 서로 따로 동작하던 고정 2초 CSS 이동과 이벤트 만료 대신, 실제 이벤트의 남은 시간에 맞춰 나타남→유지→퇴장한다. 이미지 로딩 전 빈 말풍선을 표시하지 않고 실패 시 숨긴다. 한 플레이어의 새 이벤트는 이전 표현을 대체한다. 애니메이션은 transform/opacity로 처리하고, 움직임 감소 설정에서는 확대 없이 명암 전환만 한다. 리사이즈·스크롤·초상화 크기 변화 때 기준 좌표를 갱신하고 종료 시 observer/리스너/타이머를 정리한다. 보드·HUD·대상 지정 영역을 움직이지 않으며 말풍선은 입력을 가로채지 않는다. 전투 이벤트·네트워크·턴 시간·소유권 검증·서버의 표시 만료 시간은 변경하지 않았다.

정보 위계: 목록은 일러스트/이름/장착 상태, 상세는 큰 미리보기/적용 순서로 정리했다. 인지 부하: 보조 기능을 상세로 모았다. 행동 통제감: 선택과 장착을 분리하고 저장 결과를 알린다. 피츠의 법칙: 조작부에 최소 44px 높이를 유지한다. 게슈탈트: 분류·목록·선택 상세의 역할을 분리했다. 챔피언 옆 말풍선은 발화 주체와 표현의 연결을 강화한다. 실제 사용자 만족도나 탐색 시간 개선을 측정했다고 주장하지 않는다.

## 실제 실행한 검사

- 프런트 타입 검사·운영 빌드 통과.
- 실제 운영 빌드(Vite preview), 격리 PGlite/Express/스토리지/WS: 360×740·390×844·844×390·1440×900에서 가로 넘침 없음, 목록/상세, 실제 장착→서버 재조회→새로고침 유지, 기본 외형 복귀, 검색 초기화, 장착 필터, 원본 카드 프레임 상세, 이모티콘 무장착 사용 안내 확인.
- 장착 PUT 실패를 브라우저에서 통제하여 모바일 상세창에 오류가 표시되고 선택이 유지되는지 확인했다.
- 실제 격리 PvP 두 인증 클라이언트: 현재 보유한 미장착 이모티콘 전송→양측 이미지/말풍선, 방향·화면 안 좌표, input pointer-events none, 만료 후 DOM 제거 확인. 상대 숨기기, 표시 중 844×390 회전, 시스템 움직임 감소의 opacity 전환도 확인했다.
- 같은 실제 서버 fixture의 DB/HTTP/WS 회귀 26개 통과(검증용 DB/유저만 사용).
- 실제 격리 드래프트 HTTP 회귀 18개 및 양측 브라우저 4개 검사 통과: 스킨/뒷면 유지, 이모티콘 양방향 전달, 재진입, 모바일 너비.
- 실제 AI 경로/엔진 390×844·1440×900에서 VS→전투→보유 이모티콘 말풍선→만료를 확인했다. AI 검사는 API/WS 응답을 격리한 실제 UI/엔진 검사다.
- 화면 구성 검토는 프로젝트의 기존 일러스트를 읽기 전용 보유 목록 fixture에 넣어 390×844·1440×1000에서 수행했다. 모바일 상세창의 불투명 배경·최종 opacity 1과 가로 넘침 없음을 확인했다. 실제 운영 아이템을 새로 생성하거나 등록한 스킨 화면으로 오인하면 안 된다.
