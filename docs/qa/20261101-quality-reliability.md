# 플레이 신뢰성·정보 전달 개선 — 2026-11-01

## 실제 변경

- **입력과 취소**: 손패·공격 드래그 중 턴 변경, 사용 조건 상실, 창 포커스 이탈 시 유령 카드와 선택 상태를 정리한다. 다른 손가락의 pointercancel이 진행 중인 드래그를 취소하지 않는다. 드래그를 시작하면 설명의 길게 누르기를 취소하여 원치 않는 팝업이 열리지 않게 한다. 로그·감정표현 창을 연 동안 배후 드래그를 차단한다.
- **온라인 복구**: 행동 ACK가 8초간 없으면 읽기 전용 재동기화를 요청하고, 16초에도 대기 중이면 연결을 재설정한다. 공격·카드 사용 요청 자체를 자동 재전송하지 않는다. 확인 중·연결 복구 상태를 공통 대전 안내줄에 표시한다. 이전 버전 응답이 최신 전투 상태를 되돌리지 않게 하고, 다른 매치로 이동하면 버전·대기 상태를 새로 초기화한다.
- **과거 소리 재생 방지**: 전체 스냅샷으로 복구할 때 이미 지나간 소환 사건의 재생 위치도 복원한다. 새 사건은 한 번 재생한다.
- **오디오 안정성**: 실제 등록 파일명의 강도 등급을 사용해 강공격·초강공격이 약공격에 쉽게 끊기던 우선순위 오류를 수정했다. 같은 Audio 인스턴스의 이전 play() 실패가 새 재생을 지우지 못하게 하고 중단 시 ended 리스너를 정리한다. 새 음원 추가·음량 재조정은 하지 않았다.
- **이미지 복구**: 카드 참조·전체 일러스트에서 로딩 실패를 명확히 알리고 원래 URL로 재시도할 수 있게 했다. 스킨/이미지 변경 시 이전 fallback·로딩 완료 상태가 남지 않는다. 서명된 URL에 임의 쿼리를 붙이지 않는다.
- **스프라이트 업로드**: 중복 시작을 막고 준비·전송·검증 단계에 취소 신호를 연결했다. 취소 버튼을 제공하며, 화면 이탈 후 늦은 응답이 다른 표정을 덮지 않는다. 실패·취소 시 기존 이미지와 배치 보정을 보존한다.
- **정확한 안내**: 각성 후 고유능력의 실제 비용을 버튼과 상세창에 동일하게 표시한다. 현재 사용할 수 없는 카드·능력의 이유를 안내한다. 능력·퀘스트 설명 속 카드명·키워드도 참조 팝업으로 연결한다. 참조 카탈로그는 연결 복구·화면 복귀 시 다시 시도한다. 이름 매칭 정규식은 같은 카탈로그에서 반복 생성하지 않는다.
- **변경 출처**: 좀비의 리타이어 강화와 별도 소환 흡수 버프를 숫자 변경 내역에서 구별한다. 기존 게임 로직이 참조하는 statHistory와 별개의 제한된 표시용 기록을 사용하므로 FIRST_ATTACK_GAIN 등 실행 판정 횟수는 바뀌지 않는다. 침묵·영역 이동 시 관련 기록도 정리한다. 내역의 턴은 실제 화면의 묶음 턴 번호를 사용한다.
- **학습·접근성**: 기존 튜토리얼을 공통 Dialog로 통합해 포커스 가둠·Escape·44px 이상 이동 버튼을 제공한다. 현행 드래그/대상 취소/ALT, 필드에 있는 동안 액티브 총 1회, 좀비의 표시 턴당 2회 제한을 설명한다. 상세창 닫기 버튼도 명시적으로 제공한다.

## 심리학 원칙의 적용

행동 통제감과 예측 가능성은 즉각적인 처리 상태·취소·실패 복구로, 인지 부하 감소는 실제 능력 비용과 강화 출처·턴 단위의 일치로 적용했다. 힉의 법칙은 튜토리얼의 단계별 안내, 피츠의 법칙은 최소 터치 영역, 감각적 적응·시청각 일치는 과거 소리 중복 방지와 타격음 우선순위 유지에 반영했다. 이는 설계 근거이며 사용자 만족도 개선을 입증한 사용자 실험은 아니다.

## 남은 검증·개선 범위

실기기 브라우저, 두 실사용자 간 실서버 PvP, 실제 업로드 저장소 권한·관리자 저장 후 재진입, 운영 계정의 드래프트·타워 전체 흐름, 장시간 네트워크 단절, 실제 소리를 포함한 체감 평가, 저사양 모바일 GPU/FPS, 밸런스·온보딩 사용자 연구는 이번에 검증하지 않았다. 온라인/업로드 브라우저 검증은 네트워크를 모의했고 오디오는 재생 호출을 계측했다. 새 외부 VFX/SFX 자산이나 대규모 아트 리디자인을 완료한 작업이 아니다. 모든 부족함이 해결되었다고 주장하지 않는다.
