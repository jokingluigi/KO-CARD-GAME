# 모바일 중앙 챔피언·몸짓 가독성·테스트 도구 수정 — 2026-10-29

기존 기능 브랜치 `feat/final-sprite-reactions-review`를 이어서 수정했다. main 병합·스키마 변경·운영 데이터 수정 없음.

## 원인과 수정

1. 테스트 게임의 도구가 `fixed left-1/2 top-2`의 항상 떠 있는 패널이었다. 상대 챔피언 영역과 겹칠 수밖에 없는 배치였다. 고정 패널을 제거하고 **⚙ 설정 → 테스트 경기 도구**로 옮겼다. 덱 구성·불사 샌드백·체력1 샌드백·타워 테스트 설정은 기존 처리 함수를 그대로 사용한다. 도구를 누르면 설정은 닫히고 해당 동작/편집기만 열린다.
2. 모바일의 작은 초상화 표시창 높이와 몸짓 축소 비율이 곱해져 동작이 작게 보이는 구조였다. 모바일 세로는 최소 동작 비율0.8, 작은 가로 화면은0.7을 사용한다. 기존 상황별 프로파일·스킨 설정·강도 배율·움직임 감소 옵션·반응 우선순위는 유지한다.
3. 세로 휴대폰에서 내/상대 챔피언을 각각 하단/상단 중앙에 배치했다. 정보는 좌우 레일에 분리해 초상화를 덮지 않는다. 확대된 표시창에서도 등록된 이미지 크롭·정렬·스킨·반전 설정을 사용한다.
4. 중앙에 놓인 챔피언의 주문·능력·소환·놀람·승리 동작은 중앙 필드 방향의 세로 축으로 표현한다. 피격은 실제 공격 출발 위치의 방향을 계속 사용한다. PC 및 가로 화면의 대각선 배치/동작 축은 유지한다. 짧은 모바일 가로에서는 필드/손패 공간 때문에 세로 화면처럼 상하 중앙 배치를 강제하지 않았다.

## 공간 배분

390×844에서 초상화 표시창은 기존 약112×91px에서 **163×124px**가 되어 면적이 약2배다. 초기 시안의140px 높이는 필드 공간과 균형을 맞춰124px로 조정했다. 전체 챔피언 대상 영역은 약179×164px다.

손패는 같은 화면에서 약131×183px로 유지한다. PC1440×900은 기존 초상화 표시창258×353px, 손패160×224px와 대각선 위치를 유지한다. 모바일 세로에서는 큰 챔피언 공간을 확보하면서 필드 카드가 일부 작아진다. 최종390×844의 필드 슬롯은 약71×100px이고 검사한 최단360×640에서도 약44×62px의 대상 영역을 확보했다. 필드 카드/손패 조작과 상세 확인을 제거하지 않았다.

모바일 금색 체력판·이름판은 유지하되 두꺼운 하단 여백을 줄였다. 고유능력·골드·퀘스트·덱/묘지·조작 안내/취소는 중앙 초상화와 분리된 레일에 둔다. 손패 확대 및 가로 스크롤을 유지하며 게임 화면 전체의 세로 스크롤은 생기지 않는다.

- 기존7해상도10표정 검사와 양측 스킨/자동 상대 반전/대체 이미지 검사도 통과했다. 세로 중앙 배치에 맞게 구형 대각선 위치만 가정하던 테스트 기대값을 수정했다.
