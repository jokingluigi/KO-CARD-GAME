# 관리자 편집 공간 및 피니셔 준비 정리 — 2026-11-10

## 구현
- 관리자 공통 메뉴, 입력창, 버튼, 목록의 여백·색·대비·터치 크기를 정리하고 대시보드에 주요 편집 바로가기를 추가했습니다.
- 카드·챔피언 편집을 넓은 공통 작업 공간으로 통일했습니다. PC에서는 설정 탐색/입력/미리보기, 모바일에서는 설정과 미리보기 전환을 제공합니다.
- 저장 상태, 저장 단축키, 저장 실패 시 입력 유지, 중복 저장 방지, 닫기 전 변경 확인과 키보드 포커스 처리를 적용했습니다.
- 챔피언의 기존 퀘스트 탭을 ‘피니셔 준비’로 통일했습니다. 단일 방식은 준비 조건 → 완료 효과 → 완료 연출 순서입니다. 선택지 방식에서는 선택지별 조건·피니셔 카드를 표시합니다.
- 표시용 설명과 실제 판정 설정을 구분했습니다. 조건 분석, 기존 강화 능력, 특수 각성 템플릿은 접어서 보관합니다. 기존 설정은 열거나 탭을 바꾸는 것만으로 수정하지 않습니다.
- 조건 이벤트 목록을 공통화하고 실제 엔진에 등록된 이벤트만 제공합니다. 기존의 알려지지 않은 이벤트 값도 유지·표시합니다.
- 특수 각성 템플릿 적용 시 저장 대상 참조가 갱신되지 않던 편집기 문제를 수정했습니다.

## 사용
1. 관리자 → 챔피언 → 수정 → 피니셔 준비로 이동합니다.
2. 단일 준비 조건 또는 피니셔 선택지를 선택합니다.
3. 단일 방식에서는 표시 설명과 실제 판정 방식/행동/필요 진행도를 각각 설정합니다. 조건 분석 결과는 명시적으로 적용해야 판정 설정이 바뀝니다.
4. 기존 완료 효과와 완료 연출을 확인하고 ‘수정 저장’을 누릅니다. Ctrl/Cmd+S도 같은 저장 과정을 실행합니다.
5. 모바일에서는 상단의 설정 편집/미리보기 버튼을 사용합니다. 입력 내용은 화면 전환 중 유지됩니다.

## 실제 검증
- pnpm build: 전체 타입 검사 및 프로덕션 빌드 통과.
- 관리자 단위 테스트 20개 통과: 메뉴, 효과 설정, 세션 처리, 준비 조건 편집 헬퍼.
- 배포 보호 장치 테스트 8개 통과.
- 실제 관리자 라우트 + 실제 HTTP/API + 일회용 PGlite DB: Chromium 390×844, 844×390, 1440×900 모두 통과. 테스트가 운영 DB에 저장한 데이터는 없습니다.
- 메뉴 검색, 포커스 유지, 오류 필드로 이동, 변경 취소 방지, 실패 후 재저장, 빠른 연속 저장의 단일 요청, 이미지 파일 선택창, 모바일 미리보기 전환, 저장 버튼 노출, 가로 넘침 없음 확인.
- 세 화면 크기에서 기존 단일 조건과 메타데이터, 피니셔 선택지, 준비 없는 챔피언의 설정 보존을 실제 저장 후 DB 조회로 확인했습니다.
- PC에서 필요 진행도/행동 변경 저장과 재진입, 기존 특수 각성 템플릿의 실제 저장을 확인했습니다. 각성 템플릿 검증에 따른 초안 카드는 일회용 DB에만 생성했습니다.
- 브라우저 JS 오류 0건. 결과는 browser-results.json 참조.

## 한계
- 물리 모바일 기기 및 스크린리더는 실행하지 않았습니다. 모바일 검증은 터치 설정을 적용한 Chromium 뷰포트입니다.
- 이번 변경은 관리자 UI와 편집/저장 연결입니다. 실제 전투 규칙·보상·조건 엔진 및 운영 카드 데이터는 변경하지 않았습니다. 전투 전체 회귀 시나리오는 이번 작업에서 실행하지 않았습니다.
- 카드 미리보기는 기존 카드 컴포넌트, 챔피언 미리보기는 정보/일러스트 미리보기이며 전투 시뮬레이션이 아닙니다. 스크린샷의 콘텐츠는 격리된 테스트 데이터입니다.
- 공통 스타일과 카드·챔피언 편집 흐름을 개선했습니다. 모든 전문 관리자 모듈을 개별 재구축한 것은 아닙니다.
