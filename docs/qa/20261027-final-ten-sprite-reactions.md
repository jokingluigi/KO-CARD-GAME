# 챔피언 스프라이트 최종 10표정 통합 — 2026-10-27

작업 브랜치: `feat/final-ten-sprite-reactions`. **운영 배포, main 병합, Production DB 변경 없음.** 기존 실제 대전의 `ChampionBattleActor`와 별도 관리자 스프라이트 관리 화면을 확장했다. 별도의 전투 렌더러나 인벤토리 시스템을 만들지 않았다.

## 구현

| 표정 | 실제 판정 / 유지 |
|---|---|
| 기본 | 전투 중 HP 6 이상 |
| 공격 | 확정된 TECHNIQUE 카드 사용 / CHAMPION_ABILITY_USED. 선수의 일반 공격·선택·실패·취소는 제외 |
| 피격 | 챔피언에 적용된 DAMAGE_DEALT 1~4. 자해 포함 |
| 강한 피격 | 동일한 피해 사건 한 번의 적용량 5 이상. 약한 피격과 중복 재생하지 않음 |
| 저체력 | HP 1~5. 0은 저체력으로 취급하지 않고 기존 승패 판정을 사용 |
| 소환 | 실제 ENTER_FIELD. 일반 손패 소환과 효과 소환 포함 |
| 놀람 | 내 LEGENDARY 선수의 실제 필드 RETIRE / DESTROY / VANISH / REMOVE_FROM_GAME 결과. 반환·변신·상대 선수·비레전더리·숨겨진 영역 소멸 제외 |
| 승리 / 패배 | FINISHED의 기존 winnerId 기준으로 지속. 다른 반응보다 우선 |
| 안도 | 실제로 적용된 챔피언 회복량이 양수일 때. 과회복 0과 최대 체력 증가 버프 제외 |

순간 반응 종료 시 **현재** 체력·승패·각성 세트를 다시 선택한다. HP 2→4는 안도→저체력, 4→7은 안도→기본, 6→5는 피격→저체력이다. 자해 전용 별도 표정 및 공격자가 상대에게 큰 피해를 주었을 때의 예전 반응은 최종 사양에 따라 사용하지 않는다.

우선순위는 승패 > 각성 전환 > 강한 피격 > 놀람 > 피격 > 공격 > 안도 > 소환이다. 초기 시간은 공격800 / 피격600 / 강한 피격900 / 소환600 / 놀람900 / 안도700ms, 각성 전환1500ms이며 관리자에서 순간 반응 시간을 조정할 수 있다. 이미 재생 중인 동일 피격은 종료 시각을 계속 연장하지 않는다. 대기열은 없다.

실제 공격 연출이 진행 중이면 피격/강한 피격 반응을 기존 접촉 신호와 맞추며, 확정 피해를 새로 계산하거나 서버·턴 타이머를 기다리게 하지 않는다. 기존 챔피언 대상 영역과 VFX 좌표를 유지하고 장식 스프라이트는 입력을 가로채지 않는다.

## 기존 구현에서 수정한 원인

- 이전 ATTACK_DECLARED 연결은 선수의 일반 공격에도 공격 표정을 발생시켰다. 최종 사양의 주문/고유능력 확정 사건으로 교체했다.
- 이전 BIG_HIT는 상대에게 큰 피해를 준 공격자의 반응이었다. 별도의 HEAVY_HIT를 **피해받은 챔피언**에 연결했다.
- 이전 주요 아군 기준은 고코스트 비레전더리도 포함하고 CARD_RETIRED만 보았다. 레전더리와 실제 필드 이탈 종류를 각각 확인한다. 기존 퇴장 판정은 합치지 않았다.
- 단순 이전/현재 HP 비교는 한 스냅샷 안의 피해+회복을 놓치고 체력 버프를 회복으로 오인할 수 있었다. 실제 회복 함수에서 표시 전용 누적 회복량/순번을 기록한다. 게임/퀘스트 이벤트는 추가하지 않는다.
- ENTER_FIELD에는 효과 처리 식별자가 없었다. 기존 직렬화 효과 프레임에 표시 전용 식별자를 유지하고 실제 소환 사건에 붙인다. 같은 처리의 다수 소환과 대상 선택 중단/복원 후 소환을 중복 재생하지 않는다. 게임 사건 수·순서·트리거·원본 sourceContext는 바꾸지 않는다.
- 누락된 순간 표정이 저체력 등 다른 상태 표정으로 대체되던 부분을 **현재 스킨·현재 세트의 기본 이미지**로 수정했다.

## 스킨·각성·복구

챔피언 → 실제 선택 스킨(기본 외형도 논리적인 스킨) → 일반/각성 세트 → 표정 순서다. 다른 스킨의 스프라이트를 가져오지 않는다. 각성 KEEP은 일반 세트를 유지하고 REPLACE는 각성 기본 이미지가 있어야 저장할 수 있다. 각성 반응이 누락되어도 각성 기본 이미지로 남는다. 각성은 11번째 표정이 아니다.

기존 저장 형식 version1과 기존 저장 위치(`presentationLines.BATTLE_SPRITE`, `imageAssets.__battle`)를 유지한다. 과거의 선택 표정/연결은 관리자에서 최종 10슬롯으로 투영하며 **단순히 화면을 여는 것만으로 데이터를 덮어쓰지 않는다**. 저장할 때만 적용된다. 별도 테이블·스킨 지급·스킨 장착 규칙 변경은 없다.

이미지 실패 시 현재 세트 기본→선택 스킨의 기존 일러스트→기존 대체 표시로 진행한다. 관리자 미리보기에도 기본/일러스트 대체를 적용했다. 이미지는 선택 스킨의 등록 세트만 미리 불러온다. 새 대전/세트 전환 시 이전 반응과 접촉 대기를 정리하고, 재접속 시 과거 사건을 재생하지 않는다.

## 관리자 등록 방법

1. **스프라이트 관리 → 대전 스프라이트**에서 챔피언과 편집할 스킨을 선택한다.
2. `편집 세트: 일반`에서 기본 PNG/WebP를 먼저 등록한다. 파일당 최대5MB. 나머지 9표정은 선택 사항이다.
3. 표정을 선택하고 업로드·교체·등록 해제한다. 같은 파일을 여러 표정에 쓰거나 연결 목록에서 같은 이미지를 선택할 수 있다.
4. 내 위치/상대 위치를 선택해 배율, 가로·세로 기준점, 크롭, 좌우 반전을 각각 조정한다. 새 표정은 같은 세트 기본 이미지의 배치값으로 시작한다. 반응 연결을 기본 이미지로 바꾸어도 이미 등록한 개별 표정 파일을 덮어쓰지 않는다. 표정별로 따로 조정할 수 있다.
5. 각성 세트를 쓸 경우 각성 기본 이미지를 먼저 등록하고 `전용 세트 교체`를 선택한다. 나머지 각성 표정은 없어도 된다. 외형 유지라면 KEEP을 선택한다.
6. 큰 미리보기의 `상태·반응 확인`에서 체력을 바꾸고 반응을 재생한다. `실제 회복 +2`는 변경된 HP 기준으로 안도 후 복귀한다. 각성/양측 배치/전체 화면도 확인한다.
7. **스프라이트 저장** 후 다시 진입해 확인한다. 실제 테스트 게임은 현재 계정에 **실제로 장착된 스킨**을 사용한다. 편집 대상을 골랐다는 이유로 자동 장착하지 않는다.

캔버스와 얼굴/어깨의 기준 위치를 표정 간 일치시킨 투명 PNG/WebP를 권장한다. 전용 스프라이트 원화는 이번 작업에서 등록하지 않았다.

## 미검증 / 남은 일

- **최종 전용 스프라이트를 등록한 외형·표정·정렬 검증**: 에셋 미등록으로 미완료. 일반/각성 실루엣 차이, 얼굴 정렬과 실제 이미지의 메모리/로딩 성능은 원화 등록 후 확인해야 한다.
- 실기기 터치·GPU/프레임 시간·메모리 측정, 모바일 Safari 전체 화면은 미검증이다. 데스크톱 Chromium의 모바일 뷰포트/포인터 테스트와 구분한다.
- 실제 브라우저 두 개로 전체 PvP 경기·재접속을 진행하는 반응 행렬 및 AI·드래프트·타워 전체 흐름의 시각적 검증은 이번 실행에서 하지 않았다. PvP 서버 스냅샷/복원과 공통 엔진/컴포넌트 회귀 결과를 전체 모드 실플레이 통과로 확대하지 않는다.
- 운영에 배포하지 않았다. 운영의 스프라이트/스킨/카드 데이터는 변경하지 않았다.
