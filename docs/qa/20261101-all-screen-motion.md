# 전투·메뉴 애니메이션 통합 — 2026-11-01

작업 브랜치: `feat/home-battle-mode-art`. 기존 전투 연출, 스프라이트 반응, 카드 이동, 팩 공개 시스템을 확장했다. 실제 페이지와 공통 대전 컴포넌트에 연결했으며 중복 엔진이나 별도 제품용 시연 화면을 만들지 않았다. 기존에 완성되어 있던 기능은 재사용하고 회귀 검사했다. 카드/챔피언 데이터, 전투 효과·판정, 보상 정책, API/DB/스키마 변경 없음.

## 공통 제어와 심리학 적용

`components/motion/interface-motion-policy.ts`, `interface-motion.tsx`, `interface-motion.css`를 추가했다. 상태 기반으로 선택·처리 중·성공·오류·교체를 구분한다. 한 요소의 이전 동작을 취소하고 새 동작으로 대체하며, 보이지 않는 요소에는 연출을 실행하지 않는다. 동작 완료를 서버 요청/게임 입력 조건으로 사용하지 않는다.

- 시각적 위계/인지 부하: 제목·선택·변경된 결과만 짧게 강조하고 화면 전체를 반복 입장시키지 않는다.
- 행동 통제감: 입력 인식과 실제 저장/구매/수령 성공을 구분한다. 실패는 성공처럼 보이지 않고 바로 재시도할 수 있다.
- 기대감/대비: 공격 접촉과 착지 시점은 유지한 채 준비·정점·복귀 곡선을 구분한다. 작은 메뉴 행동에 큰 전투 연출을 쓰지 않는다.
- 근접성/연속성: 카드 상세는 클릭한 카드로, 보상은 잔액으로, 탭 선택 표시는 새 위치로 이어진다.
- 반복 피로/접근성: OS와 기존 게임 모션 감소 설정을 공통 적용. 모션 감소에서는 이동·확대를 생략하고 짧은 명암/테두리 및 텍스트로 결과를 전달한다.

조절: 홈 **음량 설정 → 화면·접근성**, 전투 **설정 → 연출/접근성**의 기존 모션 감소·초상화 강도·화면 충격 설정을 사용한다. 공통 UI 시간은 `interface-motion-policy.ts`, 전투 곡선은 `battle-vfx-model.ts`/`screen-impact-policy.ts`, 스프라이트는 기존 스킨·세트별 관리자 설정에서 조절한다.

## 남은 검증과 한계

실제 사용자 2명의 PvP, 드래프트 전체 런, 실제 Android/iOS·저사양 GPU의 FPS/메모리·스크린리더, 최종 등록 스프라이트의 외형, 사용자 만족도/오조작 감소율은 이번에 검증하지 않았다. 시청각 품질의 주관적 완성도나 메타크리틱 점수 향상을 수치로 입증했다고 주장하지 않는다. 공통 화면에 적용되는 변경과 실제 각 모드 전체 실행 검증은 구분한다.
