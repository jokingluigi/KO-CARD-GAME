# 카드 조작감·타격감 패치 검증 기록

브랜치: feat/fighting-game-feel-20261012
기준 커밋: 308ba538297a687424e6bf3c288a5f83dd16a40a
범위: 손패 입력과 공통 전투 연출. 카드 수치·효과·경제·DB 변경 없음.

## 구현

- Pointer Events로 손패 드래그. 이동 중 React 전체 상태를 갱신하지 않고 복제 카드만 이동한다.
- 기존 getLegalActions로 소환 가능 슬롯을 표시하고 기존 소환·주문 콜백으로 확정한다.
- 잘못된 드롭, Escape, 포인터 취소, 화면 크기 변경 시 복귀하고 선택을 해제한다. 가로 터치는 손패 스크롤에 양보한다.
- 공격 대상 방향선. 기존 손패 정렬·선택·드로우 연출 재사용.
- 기존 AttackAnimation을 공통 타격 실행기로 확장. 준비 → 가속 → 충돌 → 동시 히트스톱 → 방향성 반동 → 복귀.
- 실제 피해량 기준 히트스톱: 1~2 피해 30ms, 3~5 피해 65ms, 6~9 피해 105ms, 10+ 피해 120ms, 결정타 165ms.
- 기존 CSS 변형이 WAAPI 피격 타이밍을 덮어쓰던 중복을 제거했다.
- 충돌 순간 기존 피해·타격음 콜백, 히트스톱 종료 시 충격파·카메라 반동·기존 저음 음원 레이어.
- 화면 흔들림과 카메라는 필드 행에 적용해 HUD 조작 위치를 유지한다.
- 그래픽 품질·타격 강도·모션 감소 설정을 저장. 기존 Screen Shake Full/Reduced/Off 유지.
- 타워 서버 결과 저장과 화면 전환 분리. 공통 초상화 파괴·KO·승리/패배 화면 이후 다음 진행 버튼으로 보상 이동. 결과 대기 안전 타이머 포함.

## 실제 실행한 검증

- TypeScript 전체 검사 및 게임 production 빌드 성공.
- 연출 정책 단위 테스트 27개 성공.
- 공통 카드 엔진 회귀 테스트 1,855개 성공.
- Chrome 실제 포인터/터치: 360×740, 375×812, 390×844, 412×915, 1440×900. 슬롯 소환·잘못된 드롭·취소·골드/손패 보존·설정 저장·가로 넘침 검사 성공.
- Chrome 연출 회귀: 데스크톱, 모바일, 작은 화면, 가로 화면, reduced motion. 공격·방어·주문·소환·회복·파괴·리타이어·퀘스트·결과·피니시 완료/오류 검사 성공.
- 모바일 입력 회귀: 주문 사용, 덱 카드 제거, 리사이즈, 감정표현 접근 성공.
- PC 손패 회귀: 4개 해상도, 1/6/10장 접근 및 마지막 주문 사용 성공.
- 모바일 세로 전투 회귀: 손패 최대 수량, 소환·공격·고유능력·로그·묘지·감정표현·턴 종료·회전 성공.
- 실제 애니메이션 시계 검사: 390×844 및 1440×900. 공격/피격 동시 정지, 정지 이후 충격파, blocked 0ms, 크기 변경 및 WAAPI 실패 시 정확히 한 번 완료 성공.
- 안전한 로컬 DB/HTTP 타워 fixture: 실제 전투 승리 → 공통 KO/결과 → 보상 → 덱 카드 교체 및 25장 유지 성공.

## 검증 범위 제한

물리 Android 기기, 실제 두 사용자 PvP 네트워크 대전, 물리 게임패드, 각 보스/히든 보스의 개별 실전, FPS 수치는 이번 패치에서 측정하지 않았다. 운영 DB 테스트나 계정 자산 변경은 수행하지 않았다. 브라우저 검증은 실제 Chrome과 로컬 테스트 데이터로 실행했다.

DB 마이그레이션과 신규 음원 자산은 필요 없다. 기존 저음·타격·유리 파괴 음원을 재사용한다.

## 배포 전 회귀 수정

새 설정 항목 때문에 768px 경계 화면의 설정창이 뷰포트 밖으로 밀리는 문제를 CI에서 발견했다. 설정창을 동적 화면 높이 안에 고정하고 내부 스크롤을 적용했다. production CSS로 모바일/가로/태블릿/PC 11개 뷰포트에서 설정 → 경기 로그 → 닫기 → 입력 복구를 재검증했다.
