# 주문 카드 챔피언 등급

## 변경

- 주문(내부 타입 `TECHNIQUE`)의 등급 선택을 에픽·챔피언·토큰으로 확장했다. 관리자 카드 편집, 목록 필터, 카드 프레임 관리가 같은 허용 등급 함수를 사용한다.
- 관리자 입력 검증, 편집 초기값, 토큰 플래그 변경, 공개 카드의 런타임 변환, 카드 렌더러에서 명시적인 `CHAMPION` 등급을 유지한다. 생성되는 토큰 주문도 선택한 챔피언 등급을 유지하며 토큰 여부는 별도 필드로 보존한다.
- 챔피언 등급 주문은 기존 챔피언 프레임을 기본으로 사용하며 `주문 / 챔피언` 전용 프레임도 등록할 수 있다. 컬렉션·덱 편집의 공통 상세 필터에 챔피언을 추가하고 컬렉션 등급 정렬을 보완했다.
- 기존 카드의 효과·등급·소유권을 일괄 수정하지 않는다. 주문의 비용·효과, 토큰 덱 편성 제한, 제작 경제·팩 확률은 변경하지 않았다. 신규 카드나 신규 마이그레이션은 추가하지 않았다. 과거 주문 등급 정리 마이그레이션은 재실행하지 않는다.

## 사용 방법

관리자 → 카드 관리 → 카드 추가 또는 수정 → 기본 정보에서 카드 종류를 `기술`(주문), 카드 등급을 `챔피언`으로 선택하고 저장한다. 일반 주문으로 보유·덱 편성이 필요하면 토큰 체크를 사용하지 않는다. 효과로만 생성하는 주문은 용도에 맞는 기존 토큰 설정을 사용한다.

## 검증

- `epic-rarity.test.ts`와 `epic-techniques.test.ts` 합계 50개 통과. 에픽·레전더리·일반 덱 제한 회귀, 챔피언 주문의 일반/토큰/챔피언 토큰 플래그별 저장·재편집·런타임 등급 보존, 기존 주문 효과 등을 확인했다.
- `champion-spell-browser.mjs`: 390×844 및 1440×900의 실제 관리자 UI와 격리 API/PGlite DB에서 등급 선택, 미리보기, 저장, 재진입, 목록 필터, 전용 프레임 설정 저장, 컬렉션 챔피언 필터를 통과했다. 운영 계정·카드는 수정하지 않았다.
- 실제 전투 엔진에서 저장된 챔피언 주문을 사용해 비용 2 소모 및 카드 1장 뽑기를 확인했다. 등급 외 효과 설정은 동일하게 유지됐다.
- 전체 타입 검사, API 및 프론트엔드 빌드 통과. 실물 모바일·장시간 두 클라이언트 PvP 검증은 이번 범위에 포함하지 않았다.
