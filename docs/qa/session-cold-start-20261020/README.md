# 기존 세션 복원 지연 후속 패치 — 2026-10-20

사용자가 최초 접속 시 재시도 전용 화면을 다시 제보했다. 재확인 시 운영 API와 프런트 프록시의 기존 세션 읽기는 모두 200/authenticated=true(약 0.29~0.35초)였으며, 캡처 당시 지연 원인은 재현·확정하지 못했다. Render 로그 API는 403이라 읽지 못했다. 첫 패치의 정상 로그인 검증만으로 간헐적인 접속 문제가 해결됐다고 볼 수 없다.

기존 세션 읽기와 HTML 사전 조회는 여전히 8초에 중단돼 22.6초처럼 늦은 응답을 받을 수 없었다. 로그인 POST 전 준비 대기만 길어진 첫 패치와 구분해, 세션 읽기 기본 상한도 60초로 맞췄다. 로그인 폼은 별도로 1.2초 후 열리므로 입력을 60초 동안 막지 않는다. 명시적인 짧은 호출 제한, 단일 동시 요청 공유, 로그아웃/로그인 후 늦은 응답 무효화, 권한 확인 및 세션 수명은 보존한다.

관리자/덱의 연결 실패 복구도 기존 AuthPage를 사용하여 입력·수동 확인·자동 세션 재확인을 함께 제공한다. 기존의 큰 오류 문구와 재시도 버튼만 표시하는 화면을 제거했다. 실패를 로그인 성공이나 guest로 바꾸지 않는다. 자동 로그인 POST나 서버 상시 깨우기 타이머는 추가하지 않았다. 서버가 계속 응답하지 않으면 실패는 입력 폼에 표시된다.

검증: 타입 검사/API·Vite 빌드 PASS, 인증·시작·메뉴·서버 제한 자동 검사 30/30 PASS. localhost 브라우저에 기존 세션 응답을 25초(모바일)/9초(데스크톱) 늦춰 최초 세션 GET 한 번으로 기존 로그인을 복원하는 회귀 검사를 추가했다. 다른 회귀 검증 및 최종 배포 결과는 실행 완료 후 기록한다. 실제 스마트폰 검증은 미실행이다.

운영 점검은 승인된 기존 세션 GET만 사용했다. 운영 DB/스키마/카드/챔피언/재화/보상/플랜/설정 변경 없음. 플랫폼 최초 응답 지연 자체를 없앤 패치라고 주장하지 않는다.
