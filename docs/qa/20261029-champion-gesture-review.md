## 기존 구현 점검과 변경

기존 시스템은 10표정·스킨·각성·사건 우선순위 및 공통 ChampionSpriteVisual을 이미 갖고 있었다. 다만 주문/소환/감정표현이 유사한 3단계 전진을 공유했고, 피격에서 이동·회전 정점이 같았으며, 회복은 위로 튀었다. 저체력은 명암·호흡만 바꾸었고 양측 호흡의 주기가 같았다. 기존 시스템을 교체하지 않고 이 부분을 통합 개선했다.

| 상황 | 이번 몸짓 |
|---|---|
| 대기 | 표시 크기에 맞춘 미세 호흡. 양측에 다른 시작 위상·주기를 사용 |
| 주문 | 작은 후방 준비 → 빠른 전진 → 늦게 따라오는 기울기 → 작은 한 번의 복귀 반동 |
| 고유능력 | 살짝 낮추고 축소 → 중앙 전진·제한 확대 → 기울기 → 안정 복귀 |
| 피격 | 이동이 먼저 발생하고 기울기가 뒤따름. 복귀 시 작은 반동 한 번 |
| 강한 피격 | 더 큰 이동·젖힘 → 버팀 구간 → 한 번의 반동 → 복귀 |
| 소환 | 작은 준비 뒤 중앙으로 기울며 지시. 레전더리는 강도를 구분하며 같은 처리의 다수 소환은 한 번 |
| 놀람 | 뒤로 물러나 약간 축소 → 잠깐 굳음 → 천천히 복귀. 타격 흔들림과 구분 |
| 저체력 | 조금 처진 지속 자세 + 얕고 느린 호흡. 순간 동작과 별도 합성 |
| 안도 | 상체가 조금 내려가며 긴장이 풀림 → 현재 기본/저체력 자세로 복귀 |
| 승리 | 몸을 세우며 중앙 전진·확대 후 자세 유지 |
| 패배 | 아래로 처지며 약하게 기울고 명암 저하 후 유지. 기존 유리 파괴가 동시에 표시되는 순간은 그 연출이 우선 보임 |

동작 단계의 위치·회전 정점을 분리하고 비기계형에는 구간별 감속 곡선을 적용했다. 반복적인 여러 번의 통통 튐을 제거했다. 확대는 균일한 비율을 사용한다.

## 합성과 타이밍

배치/크롭/스킨 이미지 → 지속 자세 → 대기 호흡 → 순간 몸짓을 별도 레이어로 합성한다. 체력·퀘스트·능력 버튼·챔피언 대상 지정 영역은 움직이지 않는다. 저체력에서 몸짓이 끝나면 현재 저체력 자세 위에서 원점으로 돌아간다.

- 이동은 실제 표시 높이에 비례하고, 사용자 연출 강도와 프리셋을 반영한다. 최종 이동 X ±18px/Y ±16px, 회전 ±3.5도, 추가 확대/축소 ±4.5%로 제한한다.
- 회전 기준점은 세트별 X/Y 설정을 사용하며 기본은 상반신 아래쪽 50%/90%다.
- 움직임 중 교체될 때 현재 표시된 transform/filter를 새 동작의 첫 프레임으로 사용한다. 스킨·세트가 다르면 이전 동작 자세를 가져오지 않는다.
- 주문·능력·소환 표정은 짧은 준비 뒤 힘을 내는 구간 시작에 맞춘다. 피격·놀람·회복·승패는 즉시 표정 전환한다. 표시용 지연만 사용하며 게임 효과 처리·입력·네트워크는 기다리지 않는다.
- 몸짓 길이와 표정 유지 시간은 별개다. 느린 속도 설정에서도 표정 복귀 때문에 몸짓이 잘리지 않도록 순간 동작 길이에 상한을 둔다.
- 각성은 기존 700ms 연출과 220ms 세트 교체 시점을 유지한다. 세트 교체 시 이전 몸짓을 정리하고 새로운 세트 기준 자세를 사용한다.
- ResizeObserver로 표시 크기를 갱신하고 회전·리사이즈 시 임시 몸짓을 정리한다. 프레임마다 React 상태를 갱신하지 않는다.
- 기존 우선순위·연속 피격 묶음·같은 처리의 소환/놀람 중복 방지를 유지한다. 감정표현도 기존 연결과 낮은 우선순위를 유지한다.
- 움직임 감소 설정에서는 이동·회전·확대·반동·호흡을 제거하고 표정과 짧은 명암으로 전달한다.

## 관리자 조정

관리자 → **스프라이트 관리** → 챔피언/스킨 → 일반 또는 각성 세트 → **현재 세트의 움직임 성격·강도**.

| 프리셋 | 성격 |
|---|---|
| 기본형 | 균형 잡힌 이동·회전·복귀 |
| 중량형 | 작은 이동, 느리고 묵직한 복귀, 적은 반동 |
| 민첩형 | 빠른 동작과 회복 |
| 절제형 | 작은 이동·회전·반동 |
| 과격형 | 더 큰 전진·기울기 |
| 기계형 | 반동 없는 복귀, 선형 구간으로 정확히 멈춤 |

캐릭터 성격을 자동 추정해 배정하지 않는다. 미설정 시 기본형이다.

이동·회전·확대는 0–1.5배, 속도는 0.5–1.5배, 반동은 0–1배, 기준점은 0–100%를 조절한다. 프리셋 기본 특성에 배율이 적용된다. 개별 숫자를 비우거나 **상속으로 초기화**하면 챔피언 기본 → 선택 스킨 일반 세트 → 현재 세트 순서로 상속한다. 기본 외형 자체를 편집할 때는 이전 저장값을 다시 상속하지 않는다.

내/상대 위치, 일반/각성, 10표정과 상황별 동작 버튼을 사용한다. **피격 → 강한 피격 전환**, **저체력에서 안도 후 복귀** 버튼도 추가했다. 실제 대전과 동일한 표시·프로파일·표정 단계 로직을 사용한다.

선택 스킨의 현재 세트 이미지·정렬·크롭을 유지하며 상대 자동 좌우 반전도 유지한다. 기본 이미지가 없더라도 기존 일러스트/이름 대체 표시 위에 움직임을 적용한다. 표정·판정·각성 능력은 설정에 영향을 받지 않는다.

## 남은 문제·미검증

- 최종 캐릭터별 스프라이트로 얼굴·윤곽·일반/각성 실루엣 차이 검증 필요. 임시 이미지 검사만으로 최종 미술 품질을 보증할 수 없다.
- 인터넷상의 실제 양측 PvP 전체 매치, 운영 AI/빠른 대전/타워/드래프트 전체 흐름, 실제 모바일 GPU·메모리·장시간 플레이는 미검증이다. 공유 UI·로컬 엔진·격리 서버 검사를 각 모드 전체 성공으로 확대하지 않는다.
- 표정과 주요 동작의 단계는 공유 시간값으로 연결하고 브라우저에서 실행했으나, 실제 기기 화면 녹화로 접촉/표정 프레임의 시차를 계측하지는 않았다.
- 기존 패배 초상화 유리 파괴가 상체 처짐을 가릴 수 있다. KO 연출은 유지했다.
- 사용자 실험은 하지 않았으므로 만족도·무게감 향상이 입증됐다고 주장하지 않는다.
