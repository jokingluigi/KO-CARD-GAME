# 챔피언 효과·피니셔 관리자 간소화

브랜치 `ui/simple-champion-effects`.

챔피언 관리의 효과 JSON 편집기와 관련 임시 JSON 초안/파싱 UI, 준비 조건의 이벤트·유형·원인 필터·진행량·복합 조건 편집기, 선택지 ID·이름 편집, 특수 각성 템플릿 적용/전환 도구를 제거했다. 기존 능력용 선수 토큰의 부가 상세 표시도 제거했다. 다른 카드 관리 화면은 변경하지 않았다.

남긴 항목은 능력/시작/완료/강화 효과의 텍스트, 기본 비용, 준비 조건의 텍스트, 단일·복수 선택지 선택, 선택지별 조건 설명·피니셔 카드·손패 추가/즉시 발동, 선택지 추가/삭제, 완료 음악이다. 기존 피니셔 공개 확인 후 저장 절차도 유지한다.

설명 입력이 새로운 실제 효과나 조건을 자동 구현하는 기능은 추가하지 않았다. 기존 실행 효과·조건은 저장 데이터로 보존하고, 문장에 맞춘 효과 변경은 별도 코드 구현으로 진행한다. 기존 선택지 생성과 준비 사용 토글의 기본 동작은 바꾸지 않았다. 카드·챔피언 전투 엔진, API 스키마, 생산 데이터는 변경하지 않았다.

## 확인한 결과

- 전체 타입 검사 및 API/프런트 빌드 통과. [빌드 로그](build.log).
- 실제 관리자 라우트, 실제 HTTP 저장, 폐기 가능한 PGlite DB를 사용해 **390×844 / 844×390 / 1440×900**에서 검증했다. [결과](results.json), [브라우저 로그](browser.log).
- 고유/시작/완료/강화 효과 설명과 준비 조건 설명을 수정하고 저장 후 재진입해 유지되는 것을 확인했다.
- UI에서 제거한 네 종류의 실제 효과 JSON이 저장 전후 동일함을 확인했다.
- 이벤트 원인·카드 유형·엄격 집계·진행도·복합 조건과 메타데이터가 보존됨을 확인했다.
- 복수 선택지의 설명·연결 카드·완료 방식을 수정했을 때 기존 선택지 ID와 실제 조건이 유지됨을 확인했다.
- 고급 UI가 실제 편집 화면에서 없고 브라우저 JS 오류가 0임을 확인했다.
- [모바일 효과 편집](ability-390.png), [모바일 준비 조건](preparation-390.png), [선택지 편집](options-390.png), [PC 효과 편집](ability-1440.png).

검증은 실제 운영 DB가 아닌 격리 DB에서 수행했다. 모바일은 Chromium 터치 뷰포트 검증이며 실기기 검증은 수행하지 않았다. 전투 규칙을 변경하지 않았으며 이번 변경에서 실제 운영 대전을 생성하지 않았다.
