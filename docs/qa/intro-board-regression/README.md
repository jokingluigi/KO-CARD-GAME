## 상호 대사 경로 추가 조사/수정

일반 AI 및 빠른 대전 AI는 createAiMatchOpening에서 introLineOne만 사용하여 champion_intro_interactions를 조회/해석하지 않았다. PvP의 resolveChampionIntro/mapIntroToSeats를 재사용하는 loadAiMatchIntro를 연결했다. AI 시작 준비 응답에 해석된 대사/발화 순서를 포함하고, 빠른 AI의 기존 handoff 메타데이터로도 전달한다. 공개된 해당 조합 한 건만 유니크 쌍 조건으로 조회하며, 공유 전투 판정과 챔피언 데이터는 변경하지 않는다. 명시적으로 비어 있는 상호 대사는 기본 대사로 덮어쓰지 않는다. 기존 빠른 AI 저장 기록에 intro가 없으면 기존 기본 대사로 호환한다.

대사 해석→양쪽 좌석 매핑→AI opening 전송의 두 좌석 순서 검사 등을 포함해 14개 자동 테스트 통과. 최초 교차 경로 테스트 import 경로 오류를 수정한 후 통과했다. 실서버 DB를 이용한 AI 시작 요청/지급/보상 테스트는 하지 않았다.

운영 공개 챔피언 API에서 이미지 URL이 존재함을 읽기 확인했고 라 칼라베라 원본 PNG(2,995,689바이트)가 HTTP200으로 반환됨을 확인했다. 이전 요청은 시간 초과되었지만 이후 성공했다. 동일 이미지 바이트를 로컬 테스트에 공급하여 390×844/360×740/1440×900의 실제 intro 컴포넌트에서 초상화 렌더링 및 복구·스킵을 확인했다. after-*.png는 이제 해당 실원화를 사용한 개발 fixture이며, 실제 계정 경기 화면은 아니다. 늦은 네트워크 전송/운영 인트로 전체 실패의 인과관계는 아직 확정하지 않는다. 앞선 코드 수정과 이번 수정은 아직 운영에 배포하지 않았다.
