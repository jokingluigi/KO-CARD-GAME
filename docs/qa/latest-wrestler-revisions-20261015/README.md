# 최신 관리자 선수 효과 수정 — 2026-10-15

인증된 공식 관리자 API의 GET으로 공개·비공개·비활성·토큰을 포함한 카드 163장(선수 142, 주문 21; 토큰 합집합 24), 챔피언 11명을 확보했다. 일반 로그인은 사용자가 이전에 허용한 해당 관리자 계정의 로그인 부수 처리 범위에서 실행했다. 운영 카드·챔피언·덱·재화·보상을 직접 수정하지 않았다. 스냅샷에는 계정·구매·컬렉션·개인 덱·세션·인증정보가 없다.

[스냅샷/해시](../snapshots/20261015-wrestler-revisions/manifest.json). 이전 배포 전 자료와 흑구슬 수정본을 기준으로 선수 효과 문구 14장, 키워드만 3장, 주문 ‘도적단 모집’ 1장이 달라졌다. 삭제된 선수 2장과 강제 교환 주문은 복원하지 않았다. 태그·공개 여부·기본 수치의 관리자 변경은 원본 그대로 로드하며 코드를 통해 되돌리지 않는다.

## 구현과 사용자 확정 규칙

- 고통 연주자 3 피해, 광신도 공격력만 +1, 루이나 자기 제외 생성, 미숙한 연금술사 자기 제외, 작고 조그마한 악마 2 피해, 파괴의 전령 +1/+1, 카산드라 다른 공개 태그 선수 생성/그 카드만 치유, 판도라 핀폴 자신·다른 태그 아군 +1/+1, 각성 리온 상대 필드가 비어야 본체 공격, 도적단 모집 공격력 +2를 명시적 ID/문구 연결로 구현했다.
- 루나는 필드 조건을 처음 만족할 때 아머(1)와 치유를 각각 획득하고 조건 카드가 사라져도 유지한다. 같은 필드 진입에서 매 효과마다 누적하지 않는다. 이전 피해 시 아머 획득 효과는 제거한다. 일반 침묵·필드 이탈 규칙은 유지한다.
- 디 어쏘리티는 아군 필드 태그 기준이다. 조킹루이지는 자신을 제외한 다른 카드의 진입을 한 번 감지하며 효과 소환은 등장 효과를 재귀 실행하지 않는다. 생성 풀의 공개/토큰 제외 규칙도 유지한다. 휴먼쿠커와 카미사토르의 조건을 추가했다.
- 브리간다는 턴 종료에 자신의 추가 골드를 예약한 뒤 **예약 총합**만큼 즉시 강화한다. 기존 예약 2+수배 3이면 +5/+5. 다음 턴 시작에 다시 강화하지 않는다. 상대의 다음 턴 추가 골드 지급을 막되 기본 턴 골드는 보존하고, 필드의 브리간다 모두 막은 골드 수만큼 강화한다. 즉시 지급하는 고유 능력 등의 현재 턴 골드를 임의로 변경하지 않는다.
- 자동 등장·핀폴 강화가 기존 소환/피해 효과의 후속 처리를 건너뛰던 문제를 해당 자동 강화 경로에 한해 수정했다. 합체·카운트다운 처리 방식을 바꾸는 광범위한 초기 수정은 회귀 실패를 발견해 철회했다.
- 전투 카드와 상세정보에는 현재 실제 아머 수치를 전달해 조건부/추가 아머가 화면과 계산에서 일치하도록 했다. 레이아웃·폰트·연출은 변경하지 않는다.

관리자 문구는 코드 구현의 명세다. 런타임 자연어 분석기를 추가하지 않았다. 텍스트 저장만으로 다음 효과 변경이 자동 구현되는 구조는 아니다. 새 원문은 다시 검토해야 한다.

## 검증 범위

- 변경 카드 집중 시나리오 29/29 통과. 소환·선택·공격·턴 종료 등 실제 엔진 경로와 예외를 검사한다.
- 전체 엔진 회귀 2,670/2,670 통과(실패/건너뜀 0). 기존 과거 자료 기반 테스트를 포함하므로 이것만으로 최신 전수 검증을 주장하지 않는다.
- 최신 163장 개별 사용 후 AI/턴 진행 검사 포함 171/171 통과. 효과별 기대값 전수 검증을 대신하지 않는다.
- 최신 관리자 카드/챔피언 스냅샷으로 별도 AI 100회 정상 종료. 결정론과 상대 숨김 손패 내용 변경에 대한 선택 불변성 검사도 통과했다. 모든 카드 효과를 매치마다 전부 발동했다는 뜻은 아니다.
- 실제 UI 360×740, 390×844, 412×915, 1440×900에서 손패 사용→필드 배치→조건부 아머 획득, 추가 아머 실제 수치와 카드/정보창 표시를 검사했다. Chromium 모바일 에뮬레이션이며 실제 휴대폰 미실행.
- 전 카드 PvP 2인 실전·전 타워 저장/보상 실전·전체 리소스 디코딩은 이번 작업에서 미실행. 운영 데이터를 시험용으로 사용하지 않았다.
- [목록](coverage.csv)은 전체 선수 142장과 변경 주문 1장을 포함한다. A는 이번 집중 시나리오의 정상 결과이며 전 모드·전 예외 검증 완료를 뜻하지 않는다. 변경 없는 선수에는 UNVERIFIED를 유지한다.
