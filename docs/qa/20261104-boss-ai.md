# 모든 봇 최고 난이도 적용 및 전술 판단 개선

작업 브랜치: `feat/smarter-bots`. 사용자가 요청한 기존 봇 난이도 통일과 세션의 배포 지시에 따른 작업이다. 카드·챔피언 원본, 효과·판정, 덱 구성·보상은 변경하지 않는다. main 병합이나 운영 DB 일괄 수정·마이그레이션 없이 실행 정책으로 적용한다.

## 구현

- `DEFAULT_AI_DIFFICULTY = BOSS`. 난이도 미지정 시 옛 판단기로 돌아가던 경로를 제거했다. 실제 브라우저 스케줄러·워커·서버 AI 실행은 이 공통 정책을 사용한다. 기존 NORMAL/HARD 덱과 재개한 과거 경기의 응답도 최고 난이도로 정규화한다. 이전 덱 레코드는 일괄 덮어쓰지 않는다. 관리자 신규·편집·복제에서도 최고 난이도를 사용하고, 낮은 난이도를 고르는 UI를 최고 난이도 안내로 교체했다.
- 최고 프로필을 깊이 3/폭 6/예산 120에서 **깊이 8/폭 8/실제 후보 실행 예산 640**으로 개선했다. 대상 선택도 탐색 단계에 포함되며 임의 길이의 모든 조합을 보장하지는 않는다. 시간 대신 고정된 실행 횟수를 사용해 기기 속도에 따라 결정이 바뀌지 않는다.
- 각 후보의 엔진 결과를 평가와 후속 탐색에서 재사용한다. 기존의 앞쪽 80개 행동 편향을 제거하고, 후보를 빠르게 정렬한 뒤 같은 카드의 슬롯 변형이 다른 카드 후보를 밀어내지 않게 섞는다. 단계별 예산을 배분해 깊은 탐색까지 도달하도록 했다.
- 최선의 후속 수들을 비교하고, 턴 종료 효과와 상대의 **공개된** 공격·액티브·고유능력 반격을 실제 엔진으로 최대 3단계 검사한다. 반격은 첫 행동별 최대 24회 후보와 턴 전환 1회로 제한한다. 상대의 숨겨진 손패를 가정해 주문을 쓰지 않는다.
- 손패 개수뿐 아니라 카드 가치를 반영해 버리기·제거기 보존 판단을 보완했다. 필드에서 이미 끝난 등장 효과와 지속 반응을 구분하고, 피해 관찰자 같은 지속 엔진을 평가한다. 무적 토큰이 있는 본체를 단순 공격력 합산만으로 패배 위험으로 오인하지 않게 했다.
- 손패·덱의 숨겨진 정보와 실제 랜덤 시드를 가린다. 직렬화된 카드 사용 복원 프레임도 가린다. 현재 선택 화면에서 공개된 자기 덱 후보는 판단하되 순서를 정규화해 실제 드로우 순서를 사용하지 않는다. 미니언 A의 무작위 결과는 미리 굴려 보고 선택하지 않는다.
- 브라우저의 탐색을 **Web Worker**로 분리했다. 서버와 같은 순수 판단 함수를 사용한다. 워커 실패/미지원 시 고정 예산의 동기 경로로 복구한다. 종료·재시작·화면 이탈 때 워커를 정리하며, 계산 중 항복·턴 변경·감정표현이 들어오면 오래된 상태를 덮어쓰지 않는다.
- 기존 행동 간 연출 대기는 유지한다. 워커는 실제 판정이나 상태 저장을 소유하지 않고, 선택한 행동만 기존 엔진에 전달한다.

## 검증

실행 묶음이 겹치므로 개수를 더해 고유 테스트 수로 해석하지 않는다. 최종 실행 결과와 배포 수신증은 아래 증거 디렉터리에 기록한다.

- 공통 엔진 검사 987개 통과. 추가 전술 검사로 5행동 결정타, 실제 닌자·헬뻑·고통 수집가 조합, 선택 버리기, 지속 엔진 제거, 숨겨진 정보·복원 프레임, 자기 덱 선택을 확인했다.
- 기존 AI/콘텐츠 검사 153개 통과. 85종 카드·7챔피언·6덱 템플릿·42챔피언 조합으로 **100개의 실제 엔진 대전**이 모두 종료됐다. 카드·효과·네트워크 규칙을 AI 전용으로 바꾸지 않았다.
- 서버 AI/덱/출전 덱 검사 17개 통과. 추가 격리 API 검사에서 기존 NORMAL 덱의 실제 응답 BOSS, 저장 원본 보존, 낮은 난이도를 요청하는 옛 클라이언트의 생성/편집, 과거 경기 복원을 확인했다. 워커 계산 중 취소·항복 검사도 통과했다.
- 실제 Home `/ai-match?quickMatch=...` 화면을 **390×844 / 844×390 / 1440×900**에서 실행했다. 예전 NORMAL 메타데이터로 시작해도 최고 워커가 닌자 소환 → 고통 수집가 공격으로 승리했다. 실제 서버 재생 함수가 전투 기록을 검증했다. API는 격리 응답이며 운영 계정으로 경기를 만든 검사는 아니다.
- 실제 대전에서 수집한 8개 위치에서 워커와 동기 판단이 일치했다. 워커 계산 중 메인 스레드 타이머가 진행됐고, 처리 중 워커 종료도 완료됐다. 첫 실행에는 워커 로딩 비용이 포함된다. 실물 휴대폰 성능으로 대신 보고하지 않는다.
- 전체 타입 검사, API·프론트엔드 빌드 통과.

## 비교 측정의 해석

초기 비교에는 시작 셔플 고정이 빠져 해당 수치는 폐기했다. **셔플 난수를 명시적으로 고정**하고 같은 초기 상태의 SHA-256이 좌석·정책 간 일치하는지 검사한 최종 비교만 보관한다.

기준 `b8c3715`의 기존 기본 판단/기존 BOSS와 같은 공개 카드 25장 덱을 사용해 각각 3시드·양 좌석을 비교했다. 최종 **12전 8승 4패**, 미종료 없음. 기존 기본 판단에는 **5승 1패**, 이전 BOSS에는 **3승 3패**였다. 이 제한된 표본에서 이전 최고 난이도보다 전반적으로 강하다고 단정하지 않는다. 깊은 결정타·상호작용·선택 정확성의 개선은 별도 전술 검사로 확인했다. 다른 덱 조합과 실제 사용자 상대 결과는 후속 측정이 필요하다.

판단 시간은 데스크톱 실행 환경에서 측정한 `benchmark.json`의 p50/p95/max를 기준으로 한다. 브라우저 워커 측정은 로딩·전달 비용을 포함하므로 서로 같은 지표로 섞지 않는다. 보너스 패·골드·능력치를 주거나 숨겨진 정보를 열어 난이도를 높이지 않았다.
