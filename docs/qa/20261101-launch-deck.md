# 출전 덱과 홈 챔피언 배너 — 2026-11-01

브랜치 `feat/selected-launch-deck`. 기존 계정별 `decks.is_selected`와 소유 덱 선택 API를 재사용해 ‘대표 덱’을 실제 **출전 덱**으로 연결했다. 새 스키마·테이블·마이그레이션이나 계정 데이터 일괄 변경은 없다.

## 사용 방법

1. **덱 편집**에서 사용할 덱을 열고 변경 사항을 **전략 저장**한다.
2. **출전 덱으로 지정**을 누른다. 선택된 덱에는 **현재 출전 덱**이 표시된다.
3. 홈 배너에 해당 덱 이름과 챔피언·현재 장착한 스킨이 표시된다. 배너의 **덱 변경**은 해당 덱 편집기로 연결된다.
4. 빠른 대전에 들어가면 그 덱으로 자동 매칭을 시작하고, 일반 AI 대전에 들어가면 그 덱으로 경기를 준비한다. 대전 화면에서 다시 덱을 선택하지 않는다.

## 구현

- **출전 덱 선택:** 저장된 덱만 지정할 수 있다. 편집 중인 내용으로 저장된 다른 구성을 선택하지 않도록 미저장 상태에서는 지정 버튼을 비활성화하고 저장을 안내한다. 저장 후 다시 진입해도 계정 API에서 같은 선택을 읽는다. 다른 덱을 열거나 편집하는 것만으로 출전 덱이 바뀌지 않는다.
- **홈 배너:** 대표 배경은 기존 관리자 설정을 유지한다. PC에서는 메뉴 옆 세로 포스터, 모바일에서는 별도의 가로 배너로 표시한다. 챔피언 경로나 임시 스킨을 코드에 넣지 않고 덱의 챔피언 ID와 기존 장착 스킨의 이미지/위치 보정을 사용한다. 이미지가 없거나 실패하면 기존 일러스트/이름으로 대체한다. 계정 변경 시 이전 선택을 남기지 않고, 화면 복귀 시 다시 조회하며 오래된 응답을 무시한다. 덱 조회는 12초 후 지연 오류를 안내하고 배너에서 재시도할 수 있다.
- **빠른 대전:** 첫 유효 출전 덱 확인과 연결 완료 뒤 입장 요청을 한 번 보낸다. 입장 확인 중에도 취소할 수 있다. 취소 뒤 늦게 도착한 확인은 무시하고 자동 재입장하지 않는다. 재연결해 기존 대기열에 합류할 경우 서버가 확정한 덱 이름·챔피언을 표시한다. 별도의 명시적 같은 덱 재대전 링크는 기존 덱이 여전히 유효한 경우에만 허용한다.
- **일반 AI:** 출전 덱으로 기존 경기 준비·인트로·전투 흐름을 자동 시작한다. 서버 준비 결과에 따라 실제 챔피언 데이터도 맞춘다. 활성 AI 덱 풀과 기존 무작위 상대 선택·난이도 규칙은 바꾸지 않았다. 관리자 테스트용 AI 준비 화면, 타워 샌드박스·드래프트의 고유 덱 구성은 유지한다.
- **예외:** 출전 덱이 없거나 삭제됐거나 유효하지 않으면 이유와 덱 편집기 진입 버튼을 표시한다. 첫 번째 덱이나 다른 유효 덱으로 임의 대체하지 않는다. 경기 결과의 ‘다른 덱 선택’은 덱 편집기로 연결하며 드래프트는 기존 경로를 유지한다.
- **매칭 중 편집:** 대기열 입장 시 서버가 검증한 챔피언·카드 구성·덱 이름을 복사해 보관한다. PvP 매치 생성과 30초 AI 전환 모두 그 구성을 사용한다. 이후 저장된 덱을 편집해도 현재 대기열에 내용이 섞이지 않는다. 시작 직전 소유권·보유 카드·현재 사용 가능 여부는 다시 검증하므로 삭제/공개 중지 등은 오류로 차단하며 다른 덱을 넣지 않는다. 스킨은 기존 경기 생성 시점의 장착 외형을 사용한다. 대기열은 기존처럼 메모리 기반이며 서버 재시작을 넘어 유지되는 영구 큐로 변경한 것은 아니다.

## 심리학 적용

선택은 덱 관리 화면에서 한 번 하고 대전 진입에서는 실행에 집중하도록 단계 수를 줄였다. 홈 배너로 현재 출전 정보를 미리 확인하고, 처리 중·취소·오류·선택 완료를 구분해 통제감을 유지한다. 작은 화면에서도 44px 터치 영역과 스크롤 없는 홈을 유지하며, 화면이 아주 짧을 때는 메뉴를 압축하고 장식 아이콘부터 줄인다. 실제 사용자 오조작/만족도 실험은 수행하지 않았다.

## 실제 검증

- 공통 UI·lib·audio **385/385 통과**.
- 서버 AI 재현·덱 삭제 보호·덱 옵션·덱 검증·출전 선택/구성 복사 등 관련 회귀 **27/27 통과**. 위 385개와 일부 중복이 있어 합산 총계로 주장하지 않는다.
- 실제 빠른 대전 로비 모듈을 사용한 별도 검사 **1/1 통과**: 대기열 입장 후 저장된 덱을 변경하고 재연결해도 기존 구성 유지, PvP 생성과 30초 AI 전환에 동일한 확정 구성 전달. DB/실제 매치 생성 경계는 모의했고 30초는 가상 시계로 진행했다. 실행 명령에는 `--experimental-test-module-mocks`가 필요하며 일반 실행에서는 해당 검사를 명시적으로 건너뛴다.
- 실제 `/`, `/decks`, `/online/quick`, `/ai-match`에서 모바일 390×844와 PC 1440×900 확인: 두 번째 덱이 출전 덱인 경우 첫 덱을 사용하지 않음, 선택/저장/재진입, 장착 스킨 매핑, 빠른 대전 한 번 입장·취소 뒤 재입장 없음, 선택한 덱으로 AI 준비/전투 진입. HTTP/WebSocket은 모의했다.
- 미선택·무효 덱에서 매칭/AI 준비 요청 0회. 503 뒤 재시도, 계정 변경 뒤 이전 선택 제거, 입장 확인 전 취소, 늦은 ACK 무시, 서버가 확정한 기존 큐 덱 표시 확인.
- 실제 공통 AI UI에서 자동 시작 → 항복 → 보상 응답 → 같은 덱 재대전과 새 매치 ID 확인. 보상 서버 응답은 모의했으며 운영 재화 변경 없음.
- 홈 **12해상도**(320×568, 360×568/640/740, 375×812, 390×844, 412×915, 740×360, 844×390, 768×1024, 1024×768, 1440×900)에서 13개 메뉴·44px 터치·겹침/페이지 스크롤 없음·화면 회전·공지·닉네임·음량·설치 안내 회귀 통과.
- 프런트/API 타입 검사 및 production 빌드 통과. 카드 효과·퀘스트·보상 규칙·카드/챔피언 원본 데이터 변경 없음. main 병합 없음.
