# 게임 도움말과 침묵 면역 안내

2026-11-03 (Asia/Seoul). 기존 `feat/product-experience-recovery` 브랜치에서 이어서 구현. 운영 배포·main 병합 없음.

## 실제 추가한 기능

- `/guide`: 로그인 없이 읽을 수 있는 별도 게임 도움말. 튜토리얼과 구별되는 FAQ 28개 + 기존 키워드 설명 18개.
- 시작/덱, 전투/판정, 키워드, 보상/설정 분류. 검색어 정규화·복수 단어 검색·제목 관련성 우선·빈 결과 복구. 자주 찾는 횟수/퇴장/침묵 면역 바로가기.
- 메인 ‘배우기 · 도움말’, 전체 메뉴 ‘게임 도움말’, 로그인 화면 ‘규칙 도움말 먼저 읽기’, 설정 화면 링크.
- 실제 전투의 설정 → ‘게임 도움말 · 규칙 찾기’에서 대전을 나가지 않고 검색. 온라인 턴 시간은 계속 흐른다고 안내. 닫으면 기존 설정/전장으로 복귀.
- 실제 엔진의 `championTokenSilenceImmune` 기준을 재사용하는 표시 도우미. 카드 이름·원화·스킨으로 면역을 추측하지 않음.
- 손패/필드의 기존 배지 영역에 ‘침묵 면역’ 표시. 카드 상세 팝업과 전투 상세정보에 고유 규칙 및 보호 범위 설명.
- 일반 토큰·레전더리 토큰·비토큰 챔피언 등급은 그 이유만으로 면역 표시하지 않음. 런타임 면역 플래그가 실제로 있는 다른 카드는 면역 표시하되 챔피언 고유 규칙이라고 설명하지 않음.

## 안내 내용의 근거

FAQ 유지보수용 `source`에 실제 코드/검사를 기록했다. 이 파일 경로는 플레이어 화면에 노출하지 않는다. 덱 25장/레전더리 3장/동일 카드 등급별 제한은 공통 상수를 사용하고, 필드 4칸/손패 7장도 기존 상수를 참조한다. 키워드 설명은 카드 정보에서 사용 중인 동일 사전을 재사용한다.

특히 액티브 총 1회, 콤보의 피해 전 발동, 러쉬/기습, 공격·효과 피해와 아머, 면역/방어/회피/침묵 면역, 리타이어/파괴/소멸/복귀, 빈 덱 피로, 손패 초과, 기본 골드, 좀비의 각 개체별 강화 제한을 구분했다. 카드별 조건과 예외는 해당 카드의 실제 설명을 함께 확인하도록 명시했다.

**현재 침묵 면역 규칙의 정확한 대상은 챔피언 등급 토큰 선수다.** 등급만 챔피언인 비토큰까지 보호하는 식으로 전투 판정을 바꾸지 않았다. 침묵 면역은 피해·기절·파괴·소멸까지 막는 보호가 아니라는 점도 설명한다.

## 실행한 확인

- 루트 `pnpm run build`: 라이브러리·프런트·API 형식 검사와 빌드 통과.
- 도움말 검색/분류/내용 및 침묵 면역 표시 도우미 + 기존 실제 엔진의 챔피언 토큰 침묵 검사: **14개 통과**. [결과](20261103-game-guide/tests.txt).
- 실제 `/guide` 화면: 360×740, 390×844, 844×390, 1440×900에서 비로그인 접근, ‘침묵면역’ 검색, 분류, 빈 결과 복구, 키워드 펼치기, 가로 넘침 없음.
- 기존 실제 관리자 카드 테스트 대전 경로에서 공개 카드 ‘여울의 보디가드’를 엔진으로 직접 출전. 390×844, 1440×900에서 필드 배지, 상세정보 설명, 전투 안 도움말 검색과 닫은 뒤 복귀 확인. 별도 데모 화면이나 정적 목업을 사용하지 않음.
- API 데이터·인증은 브라우저 격리 응답. 운영 데이터 쓰기 없음. 실운영 PvP·물리 휴대폰·스크린리더 전체 검증을 했다는 의미는 아님.
