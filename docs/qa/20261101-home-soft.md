# 홈 메뉴의 밀도·투명도 조정

2026-11-01. 브랜치 `feat/home-battle-mode-art`에서 실제 홈 메뉴 CSS를 수정했다. 리뷰의 “각지고 빽빽해 답답하다”를 받아들여 배경 그림과 주요 행동 사이의 시각적 여유를 늘렸다.

- 대전 버튼: 진한 배경을 약 91%→74% 불투명도로 낮추고, 2px 금색 테두리→1px 절제된 테두리로 변경. 6px 곡률과 작은 그림자로 각진 인상을 완화.
- 계정·공지·출전 덱·보조 메뉴: 패널 배경을 52~70% 수준으로 낮춤. 글자 자체의 opacity는 낮추지 않고, 작은 글자 뒤 명암과 그림자를 유지. 계정 버튼 글자도 밝게 조정.
- 빠른 대전·AI·드래프트: 하나의 테두리 안에 붙었던 버튼들을 10px 간격으로 분리. 다른 보조 바로가기는 테두리를 제거하고 12px 간격 확보. 전체 메뉴 버튼은 배경을 없애 보조 행동으로 물러나게 함.
- 공간: 모바일 기본 콘텐츠 간격 8→14px, 중간 크기 화면 12→18px. 작은 화면·가로 화면의 기존 압축 배치는 유지. PC 콘텐츠 최대 폭 1440→1240px, 대전 버튼의 과도한 세로 확장을 제한하고 출전 챔피언 배너 위아래에 24px 여백 확보.
- 기존 폰트·대표 이미지·출전 덱·내비게이션·게임 기능 유지. 대표 이미지를 새로 만들거나 원본을 수정하지 않음. 홈 전용 변수로 배너 그림 배경을 분리해 다른 화면에는 기존 색상을 유지.

시각적 위계와 인지 부하 관점에서 모든 패널의 테두리를 같은 강도로 강조하지 않고, 대전 버튼에 초점을 남겼다. 사용자 만족도 향상은 실제 사용자 평가로 입증한 결과가 아니다.
