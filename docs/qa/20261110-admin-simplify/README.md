# 관리자 준비 이름·효과 분석 도구 제거 — 2026-11-10

## 구현
- 단일 피니셔 준비 조건의 이름 입력 및 상세 화면의 이름 제목을 제거했습니다. 표시 설명과 실제 조건 설정을 사용합니다.
- 기존 내부 questName 값은 보존합니다. 새 준비 조건은 공통 내부값 ‘피니셔 준비’를 자동으로 사용합니다. 이름이 없으면 기존 변환기가 준비 조건 자체를 만들지 않던 호환 문제를 방지했습니다.
- 카드·챔피언 관리자의 AI 효과 생성기, 효과/조건 분석, 분석 결과 적용, 전체 분석, Replit 프롬프트 생성·복사, 메커니즘 요청 도구와 불필요한 초기 조회를 제거했습니다. 미사용 관리자 UI 모듈 2개 및 연결 상태·핸들러도 제거했습니다.
- 카드의 기존 효과 ID/JSON, 조건/키워드 설정은 유지했습니다. 챔피언의 각 효과 슬롯에는 기존 데이터를 직접 편집하는 접힌 고급 JSON 입력을 제공합니다. JSON 구문 오류/객체가 아닌 값은 저장 요청 전 차단하며 입력을 유지합니다.
- 특수 각성 템플릿처럼 다른 설정이 효과 정의를 교체할 때 오래된 JSON 입력이 이전 정의를 계속 보여주지 않도록 정리했습니다.
- 실제 전투 규칙·능력·보상·카드 효과는 변경하지 않았습니다. 서버의 기존 효과 컴파일러와 검증 API는 호환성을 위해 보존했습니다. 관리자에서 제거한 분석 UI 요청은 발생하지 않습니다.

## 검증
- pnpm build: 전체 타입 검사와 프로덕션 빌드 통과.
- 관련 기존 단위 테스트 16개 통과.
- 실제 관리자 라우트/API + 일회용 PGlite + Chromium: 390×844, 844×390, 1440×900 통과. 이름 입력 및 분석/프롬프트 버튼 제거, 제거한 도구 API 호출 없음, 잘못된 JSON 저장 요청 차단, 수정 후 저장, 기존 능력 정의·내부 이름·준비 조건·선택지 보존을 확인했습니다.
- PC에서는 준비 없는 챔피언의 준비 사용을 켜고 이름 입력 없이 저장한 뒤 실제 런타임 변환 함수가 준비 조건을 생성하는 것까지 확인했습니다.
- 기존 저장 실패 입력 유지, 중복 저장 방지, 모바일 미리보기 전환과 저장 버튼 노출, 재진입 검증도 통과했습니다. 브라우저 JS 오류 0건.
- 테스트 데이터와 각성 템플릿 초안 카드는 일회용 DB에만 기록했습니다. 운영 DB 수동 변경 없음.

## 사용
관리자 → 챔피언 → 수정 → 피니셔 준비에서 설명·판정 방식·행동·필요 진행도를 설정합니다. 실제 효과를 직접 수정하려면 해당 효과의 ‘실제 효과 설정 (고급)’을 펼칩니다. 설명 본문과 실제 효과 정의는 별도 항목입니다. 기존 효과는 입력을 변경하지 않으면 유지됩니다.

## 한계
물리 모바일 기기 및 전체 PvP 실전 회귀는 이번 관리자 정리에서 실행하지 않았습니다. 스크린샷은 실제 관리자 페이지를 격리된 테스트 데이터로 실행한 화면이며 전투 시연은 아닙니다.

운영 배포 및 정확한 서비스 SHA 확인 결과는 production-verification.json에 기록합니다. main에는 병합하지 않습니다.
