# 최종 10표정 스프라이트 시스템 점검·보완

브랜치: `feat/final-sprite-reactions-review`. 기존 실제 `GameStatePreview`, `ChampionBattleActor`, 공통 표정 선택/우선순위 로직과 관리자 스튜디오를 확장했다. 별도 목업으로 대체하지 않았다. 초기 제출은 브랜치에서만 진행했다. 이후 사용자가 상대 자동 반전 복구와 운영 배포를 명시적으로 지시했다. main 병합과 Production 스키마·카드/챔피언 데이터 변경은 하지 않는다.

## 변경 내용

- 표정은 기본/공격/피격/강한 피격/저체력/소환/놀람/승리/패배/안도 10개. 기존 `relief` 저장 키를 유지하면서 안도(실제 회복)로 표시한다. 각성은 11번째 슬롯이 아니라 KEEP/REPLACE 전환이다.
- 이미 구현된 확정 사건 기반 판정, 실제 회복 카운터, 효과 처리 ID 기반 소환 중복 제거, 결과 우선순위와 시간, 현재 HP로 복귀하는 구조를 재사용했다. 게임 엔진·규칙·카드/챔피언 원본 데이터는 수정하지 않았다.
- 후속 사용자 정정에 따라 상대 자동 좌우 반전을 유지한다. 일반/각성·모든 표정·스킨 일러스트 대체에서 내 초상화는 원본, 상대 초상화는 자동 반전하며 관리자 미리보기도 동일하다. 위치·배율·크롭 보정은 유지한다.
- 선택 스킨의 기본 스프라이트와 기존 일러스트가 모두 실패하면 다른 기본 외형 얼굴을 섞는 대신 이름 대체 표시를 사용한다. 같은 세트 기본 → 같은 스킨 일러스트 → 이름 순서다.
- 관리자 미리보기의 과거 300% 배율과 실제 대전의 200% 제한 차이를 없앴다. 공통 이미지 정규화를 사용하고 새 조절 범위는 최대 200%다. 예전 저장된 300% 원본 수치를 자동 덮어쓰지 않는다. 크롭/전체 보이기와 위치/기준점 보정은 유지한다.
- 직전 손패 확대 요청도 함께 반영했다. 390×844 기준 약 76×107 → 101×141px, 1440×900 기준 약 109×152 → 134×188px. 낮은 가로 화면에서는 기존 안내/취소 DOM을 상대 HUD의 빈 능력 영역으로 재배치해 손패를 선택할 때 다시 줄이지 않는다. 짧은 세로 화면도 빈 영역을 활용한다. 양쪽 공개 각성 상태 문구가 능력/안내에 가려지지 않게 확인했다.
- 테스트 객체 저장소의 다운로드 MIME을 PNG로 고정하던 fixture를 실제 확장자에 맞게 수정했다. 운영 업로드 검증을 완화한 것이 아니다. 이를 통해 실제 투명 WebP의 서명 업로드/완료 검증/저장/재진입도 검사했다.

반응·스킨 단위/실제 엔진 결과 테스트: **40개 통과**. 관리자/API/저장소/PvP 스냅샷 통합 검사: **28개 통과**. 두 계정이 서로 다른 챔피언 스킨과 KEEP/REPLACE 세트를 실제 PvP 시작 시 선택하고, 양측 스냅샷과 서버 런타임 복구 뒤에도 해당 manifest가 유지되는 검사까지 포함한다. 프런트 타입 검사·프런트/API 빌드 통과.

브라우저 검증은 실제 공용 대전 컴포넌트와 로컬 엔진을 사용했다. 서버 두 계정 스냅샷 및 런타임 복구 검증과, 실제 인터넷에서 두 브라우저가 완전한 PvP 경기를 마친 검증은 구분한다. 후자는 이번에 수행하지 않았다.

## 관리자 등록 방법

1. 관리자 → 스프라이트 관리 → 대전 스프라이트에서 챔피언과 **기본 외형 또는 해당 스킨**을 선택한다.
2. 일반 세트의 기본 이미지를 먼저 등록하고, 10개 등록 버튼으로 필요한 표정만 추가한다. 투명 PNG/WebP, 파일당 최대 5MB. 같은 그림을 여러 사건에 연결할 수 있다.
3. 표정별 내 위치·상대 위치를 선택해 배율(최대 200%), 기준점, 전체 보이기/여백 없이 채우기를 설정한다. 상대 좌우 반전은 별도 설정 없이 자동 적용된다. 일반/각성 세트의 표시값은 독립적이다.
4. 각성 전용 세트를 쓰려면 각성 기본 이미지를 먼저 등록한 후 전용 세트 교체를 선택한다. 유지 방식은 일반 세트를 계속 쓴다.
5. 큰 미리보기에서 기본·저체력, 실제 회복 +2 후 복귀, 각성 체크, 양측 배치와 10표정을 확인한 뒤 **스프라이트 저장**을 누른다. 저장되지 않은 변경은 운영 데이터에 반영되지 않는다.

기본 외형은 챔피언의 `presentationLines.BATTLE_SPRITE`, 선택 스킨은 해당 꾸미기의 `imageAssets.__battle`에 저장한다. 새 테이블/스킨 지급 시스템을 만들지 않았다.

## 남은 검증

- 실제 등록 원화 10표정의 얼굴·어깨 정렬, 일반/각성 실루엣이 크게 다른 원화의 최종 시각 튜닝.
- 실제 휴대폰의 브라우저 주소창/노치/회전, GPU·메모리·프레임 성능 측정.
- 인터넷 두 브라우저 전체 PvP 경기, AI/빠른 대전/타워/드래프트 각각의 실제 서버 진입부터 종료까지 전체 흐름. 공용 UI 회귀 통과를 개별 모드 전체 검증으로 대체하지 않는다.
