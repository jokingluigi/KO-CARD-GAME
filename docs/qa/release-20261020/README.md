## 통합 시 추가 수정

- snapshot 전체를 캐시하면 JOIN 때 새로 추가된 상대 외형이 다른 프로세스에 남을 수 있다. SQL에서 `snapshot - 'cosmetics'`로 불변 도감만 캐시하고, 실제 잠긴 세션 행에서 작은 cosmetics를 매번 투영한다. 전투 상태/인증/버전/보상은 캐시하지 않는다.
- 버전이 같아도 이미지 이모티콘은 독립적으로 전달돼야 한다. 작은 `DRAFT_HEARTBEAT`에도 유효한 이모티콘을 넣고 클라이언트가 중복 제거해 렌더링한다. 전투 버전/판정은 변경하지 않는다.
- 실제 HTTP 테스트에서 입장 전 도감 캐시를 채운 뒤 JOIN하고 양쪽 외형이 맞는지 검사했다. 양쪽 같은 버전 heartbeat에서 이미지 전달도 검사했다. 실제 두 브라우저에서도 양방향 이미지 전달/새로고침을 확인했다.
