# 전투 카드 정보와 챔피언 초상화 — 2026-10-15

사용자가 ⓘ→카드 정보→정보창 일러스트 터치→풀 일러스트 동선을 확인했고, 필드 카드 자체의 일반 탭은 기존 공격 선택 동작으로 유지하도록 명시했다. 패치 후 운영 배포도 승인했다.

정보창을 pointerup에서 열면 뒤따르는 호환 click이 새로 나타난 정보창의 일러스트 버튼으로 전달됐다. 실제 브라우저에서 기존 코드의 정보 버튼 1회 탭으로 풀 일러스트가 열리는 현상을 재현했다. 이제 정보창은 해당 click에서 열고, 정보 버튼 클릭 전파를 종료한다. 터치 이후 합성 mouseenter/focus가 정보창 상태를 다시 바꾸지 않도록 처리한다. 모바일과 데스크톱 모두 명시적인 닫기 버튼을 제공한다.

챔피언 초상화 내부 이름과 어두운 이름용 그라데이션을 제거했다. 이름은 별도 HUD에 유지한다. 모바일 세로는 기존 48×66에서 80×88(폭 359 이하 72×86)로, 가로는 76×96으로 키웠다. 초상화에만 COVER와 최소 1.35배 확대 및 상단 중심 구도를 적용하며 관리자 저장 데이터와 카드/컬렉션 이미지 설정은 변경하지 않는다. 이미지에만 둥근 상단을 적용해 초상화 아래의 공격 피해 안내는 가리지 않는다.

크기가 큰 초상화에서도 짧은 휴대폰 화면에 기존 전투가 한 화면으로 들어오도록 유지했다. 세로 모드의 44px 액티브 버튼을 8px 위로 옮겨 카드 하단의 공격 선택 터치 공간을 확보했다. 체력·코스트·공격력 숫자와 게임 엔진·폰트 설정은 변경하지 않았다.
