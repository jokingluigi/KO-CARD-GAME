# 전투 카드 정보와 챔피언 초상화 — 2026-10-15

사용자가 ⓘ→카드 정보→정보창 일러스트 터치→풀 일러스트 동선을 확인했고, 필드 카드 자체의 일반 탭은 기존 공격 선택 동작으로 유지하도록 명시했다. 패치 후 운영 배포도 승인했다.

정보창을 pointerup에서 열면 뒤따르는 호환 click이 새로 나타난 정보창의 일러스트 버튼으로 전달됐다. 실제 브라우저에서 기존 코드의 정보 버튼 1회 탭으로 풀 일러스트가 열리는 현상을 재현했다. 이제 정보창은 해당 click에서 열고, 정보 버튼 클릭 전파를 종료한다. 터치 이후 합성 mouseenter/focus가 정보창 상태를 다시 바꾸지 않도록 처리한다. 모바일과 데스크톱 모두 명시적인 닫기 버튼을 제공한다.

챔피언 초상화 내부 이름과 어두운 이름용 그라데이션을 제거했다. 이름은 별도 HUD에 유지한다. 모바일 세로는 기존 48×66에서 80×88(폭 359 이하 72×86)로, 가로는 76×96으로 키웠다. 초상화에 CONTAIN·배율 1·중앙 정렬을 사용하고 내부 4px 여유를 두어 원본 전체가 잘리지 않게 표시한다. 확대·상단 크롭은 사용하지 않는다. 관리자 저장 데이터와 카드/컬렉션 이미지 설정은 변경하지 않으며, 초상화 아래의 공격 피해 안내도 가리지 않는다.

크기가 큰 초상화에서도 짧은 휴대폰 화면에 기존 전투가 한 화면으로 들어오도록 유지했다. 세로 모드의 44px 액티브 버튼을 8px 위로 옮겨 카드 하단의 공격 선택 터치 공간을 확보했다. 체력·코스트·공격력 숫자와 폰트 설정은 변경하지 않았다. 아래에 추가된 보호 규칙 수정만 공통 엔진에 적용한다.

## 추가 보호 규칙 수정

- 방어가 활성화된 필드 선수는 공격과 PLAYER_CHOICE 지정 효과의 대상이 될 수 없다. 구조화 효과의 목록·실행, SCRIPT 선택·재검증, 합체 및 태그 교체 경로를 함께 검사한다. 손패·묘지 카드는 필드 방어로 보호하지 않는다. 자동 후속 효과의 SAME_TARGET은 새로운 직접 지정이 아니므로 기존 처리한다.
- 퀘스트 전용 챔피언 토큰도 자신의 필드에 있는 동안 챔피언 본체를 보호한다. 공격·직접/광역 효과 피해·피로 경로를 검사하며, 손패·묘지의 토큰은 보호하지 않는다. 토큰 자체 제거는 기존 규칙을 유지한다.
- 기존 챔피언 능력 버튼에서 불필요한 터치 정보창이 함께 열려 다른 버튼을 가리던 문제를 수정하고 자동 검사를 추가했다.
- 모바일 회귀 검사는 퀘스트 보상 연출이 끝난 뒤 다음 버튼의 접근성을 검사한다. 연출을 생략하거나 UI 코드를 변경하지 않았다.

**사용자 확정 규칙:** 방어는 다음 자기 턴 시작에 해제한다. 그동안 직접 지정뿐 아니라 광역·무작위 파괴·리타이어·제거·소멸도 막는다. 무작위 대상은 기존 시드로 먼저 선택하며, 보호된 대상을 골랐을 때 다른 카드로 다시 뽑지 않는다. 강화 등의 일반 자동 효과는 유지한다. 지정/비지정 제거 모두 성공 이벤트나 보상을 발생시키지 않는다. 기존 턴 초기화 순서를 바꾸지 않고 실제 END_TURN 경로로 보호 지속/해제를 검사했다.
