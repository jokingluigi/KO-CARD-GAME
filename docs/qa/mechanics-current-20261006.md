# KO CARD GAME 키워드·매커니즘 정리

2026-10-06 기준. PR #12의 코드와 후속 매커니즘 안내 정비를 기준으로 정리했습니다. 카드 관리에서 등록할 수 있는 효과도 포함합니다. 규칙을 새로 제안하는 문서가 아니라 현재 구현을 재정비하기 위한 목록입니다.

## 1. 카드 키워드: 11개

| 이름 | 코드 | 현재 동작 |
|---|---|---|
| 러쉬 | RUSH | 필드에 들어온 턴에도 공격할 수 있습니다. 상대 선수와 챔피언 모두 가능합니다. 도발 등 별도 공격 제한은 적용됩니다. |
| 기습 | SURPRISE | 필드에 들어온 턴에도 상대 선수를 공격할 수 있습니다. 그 턴에는 상대 챔피언을 공격할 수 없습니다. |
| 도발 | TAUNT | 공격 가능한 도발 선수가 있으면 그 선수를 먼저 공격해야 합니다. 방어 중인 도발 선수는 강제 대상에서 제외됩니다. |
| 회피 | DODGE | 받을 실제 피해를 1회 무효화하고 회피 횟수를 소비합니다. 기본 1회이며 설정·효과로 여러 회가 가능합니다. 턴이 바뀌어도 횟수는 자동 충전되지 않습니다. |
| 연타 | MULTI_STRIKE | 한 턴에 최대 두 번 공격할 수 있습니다. |
| 면역 | IMMUNE | 카드·챔피언 효과의 지정 대상으로 선택할 수 없습니다. 무작위 단일 대상에서도 제외하는 경로가 있습니다. 기본 공격과 전체 효과까지 무효화하는 키워드는 아닙니다. 무덤 대상 처리에는 예외가 있습니다. |
| 치유 | REGEN | 현재 구현은 **양쪽 플레이어의 턴 종료마다** 해당 선수의 체력을 2 회복합니다. 일반 회복은 최대 체력을 넘지 않습니다. |
| 아머 | ARMOR | 공격·반격으로 받는 피해를 설정된 아머 수치만큼 줄입니다. 최소 피해는 0입니다. 카드 효과 피해에는 적용되지 않습니다. |
| 조건 | CONDITION | 설정된 사용 조건이 충족되어야 손패에서 낼 수 있습니다. 조건 설정이 없거나 유효하지 않으면 낼 수 없습니다. |
| 방어 | DEFENSE | 등장부터 **다음 자기 턴 시작까지** 피해를 받지 않고 공격 대상으로 지정되지 않습니다. 파괴·제거 효과를 모두 막는 규칙은 아닙니다. |
| 흡혈 | LIFESTEAL | 자신의 공격으로 실제 준 피해만큼 **아군 챔피언**을 회복합니다. 일반 효과 피해가 자동으로 흡혈되는 규칙은 아닙니다. |

키워드 이름과 카드 텍스트가 별도로 저장되는 경우가 있습니다. 화면 텍스트만 보고 판단하지 말고 실제 키워드 설정과 실행 효과를 함께 확인해야 합니다.

## 2. 상태 이상·능력 상태

| 이름 | 현재 동작 |
|---|---|
| 기절 | 공격할 수 없습니다. **기절한 선수의 자기 턴 종료에 해제됩니다.** 상대 턴에 걸렸으면 다음 자기 턴의 공격을 막습니다. 자기 턴에 걸렸으면 그 턴 종료에 해제됩니다. 기절 자체가 액티브 능력까지 막는 것은 아닙니다. |
| 침묵 | 기존 능력과 키워드를 비활성화하고 전투 중 강화 수치를 기본값으로 되돌립니다. 현재 체력은 복구한 최대 체력 이하로 제한하며 잃은 체력을 자동 회복하지 않습니다. 이후 새로 부여한 카드 텍스트는 별도 효과층으로 작동할 수 있습니다. |
| 봉인 / 능력 비활성화 | 카드 능력의 발동을 막습니다. 침묵처럼 기본 스탯과 키워드를 전부 지우는 처리는 아닙니다. |
| 침묵 면역 | 내부적으로 침묵 적용을 차단하는 상태가 있습니다. 일반 카드 키워드 11개에는 포함되지 않습니다. |
| 이번 턴 공격·액티브 사용 횟수 | 다음 자기 턴 시작에 초기화됩니다. |

## 3. 효과가 발동하는 시점

| 이름 | 코드 | 현재 기준 |
|---|---|---|
| 게임 시작 | GAME_START | 초기 손패 배분 전에 덱·손패의 해당 카드에서 처리 |
| 등장 / 출현 | ENTER_FIELD | 손패에서 직접 낸 선수와 챔피언 특별 전개에서 처리. **일반 소환·부활에는 자동 발동하지 않음** |
| 퇴장 | LEAVE_FIELD | 현재 일반 카드의 퇴장 효과는 리타이어 처리에 연결됨. 파괴·제거와 구별 |
| 자기 리타이어 | SELF_RETIRE | 자신의 리타이어 시 처리 |
| 액티브 | ACTIVE | 등장한 턴에는 사용 불가. 다음 자기 턴부터 직접 사용하며 카드마다 턴당 1회. 러쉬·기습은 액티브 제한을 없애지 않음 |
| 준비 / 드로우 | CARD_DRAWN | 덱에서 뽑힌 해당 카드에서 처리. 손패 초과로 제거되기 전 준비 효과 처리 |
| 아군 퇴장 | CARD_RETIRED | 아군 선수가 리타이어했을 때 해당 감시 능력 처리 |
| 아군 소환 | CARD_SUMMONED | 아군 선수가 소환 경로로 진입했을 때 처리 |
| 아군 진입 | CARD_ENTERED | 손패 플레이·소환 등 아군 필드 진입 감시 |
| 처음 공격받음 | FIRST_ATTACKED | 해당 카드가 처음 공격받을 때 |
| 자신 공격 | SELF_ATTACK | 자신이 공격할 때 |
| 콤보 | OTHER_ALLY_ATTACK | 다른 아군 선수가 공격할 때 |
| 공격 후 생존 | ATTACK_SURVIVED | 상대 선수를 공격한 뒤 생존했을 때 |
| 자기 피해 | SELF_DAMAGED | 실제 피해로 자신의 체력이 감소했을 때 |
| 스탯 증가 | STAT_CHANGED | 효과로 공격력·체력이 증가했을 때. 첫 증가 등 추가 조건 가능 |
| 주문 사용 | TECHNIQUE_CAST | 기본 비용 1G 이상인 기술 카드를 손패에서 사용했을 때 |
| 핀폴 | EXACT_ZERO_DAMAGE | 상대 선수의 체력을 정확히 0으로 만들었을 때. 0 아래로 초과 피해를 준 경우와 구별 |
| 턴 시작 | TURN_START | 소유자의 턴 시작 |
| 턴 종료 | TURN_END | 소유자의 턴 종료. 치유 키워드와 별도 규칙 |
| 피해 직전 | BEFORE_DAMAGE | 피해 적용 직전 예방·대체 처리 |
| 리타이어 직전 | BEFORE_RETIRE | 치명적 리타이어 적용 직전 예방·대체 처리 |
| 위치 | POSITION | 지정된 필드 슬롯에 들어왔을 때 처리하는 내부 능력 |

별도 이벤트 감시 등록에는 카드 사용, 주문 사용, 카드 리타이어, 피해 수신, 이 효과로 대상 제거를 감지하는 규칙도 있습니다.

## 4. 주요 효과 매커니즘

| 분류 | 포함되는 기능 |
|---|---|
| 피해 | 단일 피해, 전체 피해, 여러 번 무작위로 나누는 피해, 피해량 증가·감소, 실제 피해량 집계 |
| 회복 | 선수·챔피언 회복, 초과 회복량 집계, 초과 회복을 최대 체력으로 전환 |
| 스탯 변경 | 공격·체력 강화, 특정 수치 설정, 현재 수치 배수, 최대 체력 변경, 공격·체력 교환, 두 선수 체력 교환 |
| 비용 변경 | 비용 증가·감소, 이번 턴만 감소, 최소 비용 제한, 남은 골드 소비 후 강화 |
| 골드 | 현재 골드 획득, 다음 자기 턴 골드 추가 |
| 드로우 | 카드 뽑기, 손패 초과 제거, 덱 소진 피로 피해 |
| 리타이어 | 무덤으로 이동. 퇴장 능력과 아군 리타이어 감시·좀비 성장 등에 연결 |
| 파괴 | 무덤에 넣지 않고 없앰. 일반 리타이어·퇴장 효과를 발동시키지 않음 |
| 게임에서 제거 | 제거 영역으로 이동. 리타이어·무덤·부활과 구별 |
| 소환 | 지정 카드·무작위 선수를 빈 슬롯에 진입시킴. 손패에서 소환하는 별도 경로도 있음 |
| 부활 | 무덤의 기존 선수를 필드로 되살림. 일반 소환처럼 등장 효과 자동 발동과 구별 |
| 생성 | 새 카드 사본을 손패·덱·덱 맨 위 등에 추가. 생성된 카드 상태를 별도로 기록 |
| 이동 | 필드에서 손패로 돌려보내기, 덱으로 돌려보내기, 덱 맨 위로 보내기 |
| 훔치기 | 상대 영역의 기존 카드를 내 손패로 이동 |
| 덱 파괴 / 밀 | 덱 맨 위 카드를 무덤으로 보냄. 이름은 '덱 파괴'이지만 필드 파괴와 결과가 다름 |
| 포획·해방 | 카드를 포획하고 저장한 카드를 다시 필드에 해방 |
| 변신 | 자신 또는 선택한 선수를 지정 카드로 변경. 대상 변신은 현재 공격력·체력 유지 규칙이 있음 |
| 흡수·복사 | 퇴장 대상 공격력 합 흡수, 가장 높은 공격+체력 합 복사·추가, 생성 카드에 원본 스탯 복제 |
| 키워드 조작 | 키워드 부여·제거, 회피 횟수 부여, 아머 등 부속 수치 적용 |
| 제어 | 기절, 침묵, 능력 봉인, 공격력 감소 후 0이 된 대상 기절·침묵 |
| 카드 텍스트 부여 | 기존 선수의 실행 가능한 텍스트·능력·키워드를 별도 층으로 부여 |
| 위치·스위치 | 왼쪽·오른쪽 분기, 양옆 선수, 양옆 빈 슬롯 대상 |
| 예약 | 다음에 내는 선수 강화, 다음 일치 이벤트에 실행, 턴 시작·종료에 지연 실행 |
| 감시 | 카드 사용·피해·퇴장 등에 한 번 또는 반복 반응 |
| 예방 | 다음 피해 무효, 다음 치명적 퇴장을 체력 1로 대체 |
| 반복·분기 | 턴 종료 효과 재실행, 조건부 효과, 횟수 반복, 이전 결과에 따라 후속 효과 실행 |
| 필드 지속 효과 | 특정 카드가 필드에 있는 동안 다른 카드의 피해·성장·회복·등장 등에 적용 |
| 패배 효과 | 손패에 남아 있으면 턴 종료에 패배시키는 카드 등 직접 승패 처리 |

### 특정 카드에서 쓰이는 특수 규칙

- **좀비 통합:** 아군 필드에 좀비는 1장. 새 좀비의 능력치를 기존 좀비에 합치며, 다른 아군 선수 리타이어마다 +1/+1.
- **힐빌:** 자신이 상대 선수를 리타이어시켰을 때 자신의 체력 2 회복. 다른 카드가 리타이어시킨 상황과 구별.
- **뱀파이어 왕자 MPG:** 등장 전체 피해 후 실제 피해 총합만큼 공격력 증가. 효과 피해는 아머를 관통하며 방어·회피 등으로 막힌 피해는 증가량에 넣지 않음.
- **하녀 판도라:** 자신의 등장 피해로 리타이어가 발생했는지 확인한 뒤 변신. unrelated 퇴장을 합산하지 않음.
- **카스토·헬퍼:** 초과 회복량을 별도로 계산하여 최대 체력 증가 또는 생성 조건에 사용.
- **태그 체인지:** 필드 선수와 손패의 비용 이하 선수 교체, 두 카드 공격력 증가.
- **생명의 교환:** 사용자 지정에 따라 현재 체력과 최대 체력을 두 선수 사이에서 각각 교환하고 기절. 이전의 현재 HP만 교환한다는 설명을 실제 효과에 맞게 수정했습니다. 기본 비용·공격·체력은 유지합니다.

## 5. 대상·조건·지속 시간

- **영역:** 필드 / 손패 / 덱 / 무덤 / 플레이어 챔피언 / 선수와 챔피언 전체. '어디에 있든'의 기본 선수 범위는 **필드·손패·덱**이며 무덤은 자동 포함하지 않습니다.
- **소유자:** 아군 / 상대 / 양쪽.
- **선택:** 자신 / 직접 선택 / 무작위 / 맨 위 / 양옆 / 양옆 빈 슬롯 / 직전 같은 대상 / 전체.
- **대상 제한:** 선수·기술, 생성 여부, 토큰 여부, 챔피언 토큰 여부, 챔피언 등급 제외, 원본 제외, 효과 없는 선수, 키워드, 태그, 비용·공격·체력 비교.
- **무작위 범위:** 기본 범위는 일반 토큰과 챔피언 토큰을 제외합니다. 전체 범위는 토큰도 포함하며 별도 필터로 제외 대상을 결정합니다. 오젠은 일반 토큰도 파괴하도록 전체 범위를 사용합니다.
- **태그:** 하나라도 일치 / 모두 일치 / 특정 태그 제외. 태그 자체는 키워드가 아니라 카드 집단을 찾는 분류입니다.
- **수치:** 기본값 / 현재값 / 최대 체력은 구별합니다. '이하·이상'은 경계를 포함하고 '미만·초과'는 포함하지 않습니다.
- **동적 수치:** 손패 수, 무덤 선수 수, 남은 골드, 필드 선수 수, 직전 공격력 증가량, 이번 턴 리타이어 수, 이번 턴 받은 피해량.
- **조건:** 기본 비용, 왼쪽·오른쪽, 유일한 아군 선수, 손패에 존재, 손패·필드 수, 태그, 첫 공격력 증가, 챔피언 체력, 턴 수, 누적 이벤트. 여러 조건을 AND/OR로 결합할 수 있습니다.
- **기간:** 이번 턴 / 다음 턴까지 / 영구. 효과 기간의 공통 구현과 방어의 '다음 자기 턴 시작'은 별도로 관리됩니다. 영구 강화도 필드를 떠날 때 초기화되는 경우가 있습니다.
- **효과 계산:** 후보 수·합·최소·최대 집계, EQ/NE/LT/LTE/GT/GTE 비교, 결과 저장, 순차 실행, 조건 분기, 반복.
- **이력 범위:** 현재 효과 처리 / 현재 행동 / 현재 턴 / 현재 경기의 사건을 구별해 조건을 계산합니다.

## 6. 기본 게임·챔피언·모드·보상 규칙

- **덱:** 일반 구성전 덱 25장, 동일 일반 3장·에픽 2장·레전더리 1장, 레전더리 총 3장 이하, 챔피언 1명.
- **필드·손패:** 필드 4칸, 손패 최대 7장. 필드 위치는 인접·좌우 효과에 영향을 줍니다.
- **초기 손패:** 선공 3장, 후공 4장. 멀리건과 덱 섞기.
- **턴 표시·턴 수 조건:** 선공과 후공의 차례를 한 묶음으로 1턴으로 계산합니다. 화면과 턴 수 조건, 경기 요약이 같은 기준을 사용합니다. 내부 행동 차례 번호와 효과 만료 시점은 별도로 보존합니다.
- **자기 차례:** 자기 턴 시작 시 드로우, 공격·액티브 사용 횟수 초기화, 기본 골드 갱신. 기본 골드는 자기 턴 횟수에 따라 1~6G, 별도 보너스 추가. 남은 기본 골드는 다음 턴으로 이월되지 않습니다.
- **전투:** 선수 간 공격과 반격, 챔피언 직접 공격, 실제 피해 적용 후 치명적 선수 리타이어. 기본 공격은 턴당 1회.
- **피로:** 덱이 빈 상태에서 드로우할 때 1, 2, 3… 피해 증가. 챔피언 보호 토큰 규칙 적용.
- **챔피언:** 고유 능력·비용·턴당 사용 제한, 인게임 챔피언 퀘스트 진행과 보상, 능력 강화, 챔피언 토큰 특별 전개.
- **챔피언 보호:** 챔피언 토큰·직접 전개 챔피언·챔피언 등급 선수가 아군 필드에 있으면 챔피언이 보호됩니다. 면역 키워드와 별도 규칙.
- **챔피언 토큰 전개:** 필드가 꽉 차면 손패, 손패도 꽉 차면 덱 맨 위에 배치하는 대체 경로.
- **필드 이탈 초기화:** 손패·덱·무덤으로 돌아갈 때 기본 비용·공격·체력·키워드로 복구하며 전투 상태를 초기화합니다. 드래프트 변이는 사본의 기준값으로 유지합니다. 덱 안에서 직접 받은 강화는 단순 드로우 때 지우지 않습니다.
- **드래프트:** 카드 후보 선택, 재선택·잠금, 특별 라운드, 변이·대변이, 시너지·혼돈 후보, 완성 덱 준비. '드래프트 선택에서 숨기기'는 후보 노출에만 적용됩니다.
- **탑:** 전투 단계 진행, 유물, 지속 강화·오라, 소환·공격·피해·리타이어·턴 시작/종료의 모드별 보정.
- **대전:** 빠른 대전·온라인·AI가 공통 엔진을 사용하며 온라인 행동은 서버 상태 버전과 대상 선택 상태로 검증됩니다.
- **별도 보상 퀘스트:** 경기 결과·행동으로 진행도를 저장하고 보상을 수령합니다. 인게임 챔피언 퀘스트와 별도 시스템입니다.
- **제작·분해:** 일반 3장·에픽 2장·레전더리 1장까지 제작. 최대 분해는 각 보유 상한만큼 남기고 초과분을 분해합니다.

## 7. 재정비할 때 명확히 할 항목

1. **치유 시점:** 양쪽 턴 종료마다 체력 2 회복하는 기존 규칙을 유지합니다. 게임 내 도움말에도 양쪽 턴 종료임을 명시했습니다.
2. **기절 기간:** 현재 자기 턴 종료에 해제됩니다. 이전 목록의 “자동 해제 없음”은 잘못된 설명이어서 정정했습니다. 게임 내 도움말에도 해제 시점을 명시했습니다.
3. **등장과 소환:** 현재 일반 소환·부활은 등장 효과를 발동시키지 않습니다. 효과 등록 화면의 일반 설명은 더 넓게 표현되어 있어 문구 통일이 필요합니다.
4. **퇴장과 파괴:** 리타이어만 무덤과 퇴장 능력으로 연결됩니다. 등록 라이브러리의 퇴장 설명에도 파괴·제거는 발동하지 않음을 명시했습니다.
5. **면역·방어·챔피언 보호:** 지정 효과 차단 / 피해·공격 대상 차단 / 챔피언 보호를 구별해야 합니다.
6. **다음 턴과 다음 자기 턴:** 공통 기간과 방어의 소유자 턴 기준은 같지 않습니다.
7. **생명의 교환 설명:** 현재·최대 체력을 각각 교환하는 실제 효과로 설명을 통일했습니다. 이미 보정된 스크립트에 옛 설명이 남아 있는 해당 카드만 백업 후 1회 갱신합니다. 다른 카드·기본 수치·사용자가 새로 작성한 설명은 변경하지 않습니다.
8. **무작위 토큰 범위:** 기본 범위는 토큰 제외. 카드 설명에서 챔피언만 제외한 경우 일반 토큰까지 빠지지 않도록 설정해야 합니다.
9. **버프와 기본 수치:** 침묵·필드 이탈·변신·드래프트 변이에서 무엇을 복구하고 무엇을 유지하는지 통일해야 합니다.

- 치유는 양쪽 턴 종료마다 회복, 기절은 자기 턴 종료에 해제. 실행 규칙은 유지하고 게임 내 안내를 정확히 수정했습니다.
- 생명의 교환의 현재·최대 체력 교환을 유지하며 카드 공개 설명·로컬 기본 목록·매치용 카드 변환을 통일했습니다.
- DB 보정 0046은 정확한 옛 설명과 최대 체력 교환 스크립트가 확인된 해당 카드만 대상으로 합니다. 원본 백업·1회 적용·관리자 새 설명 보존을 검사했습니다.
- 등장·퇴장 효과 등록 설명을 실제 실행 경로와 일치시켰습니다.
- 기존 체크포인트 문서는 과거 저장본으로 보존합니다. 현재 규칙의 근거는 이 정정본을 사용하세요.

## 12. 사용자 지정 매커니즘 변경

- 아머: 공격과 반격 피해에만 적용, 카드 효과 피해는 그대로 적용.
