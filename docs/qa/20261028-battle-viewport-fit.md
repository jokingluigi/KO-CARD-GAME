# 대전 화면을 가용 화면 높이에 맞춤

실제 공용 `GameStatePreview`에 `battle-viewport.css`를 통합했다. 기존 고정 307px 챔피언 HUD 두 개, 100px 조작부, 카드 필드/손패를 합산하던 세로 레이아웃이 모바일 높이를 넘던 문제를 수정했다. PC에서도 최소 콘텐츠 높이가 작은 창보다 큰 문제를 같은 높이 예산으로 해결했다.

- 전체 화면을 transform/zoom으로 축소하지 않는다. 실제 CSS 배치 상자의 높이를 `100dvh`와 safe-area 기준으로 계산하므로 클릭/드래그/VFX 좌표를 그대로 사용한다.
- 세로에서는 챔피언·체력 프레임을 압축하고 골드/덱/묘지를 옆에 묶는다. 내 챔피언 좌하단·상대 우상단을 유지한다. PC/가로는 대각선 양측 HUD 공간을 유지한다.
- 필드와 손패는 남은 높이에 맞춰 크기를 배분한다. 짧은 화면에서는 카드가 작아지므로 기존 상세정보/길게 누르기를 유지한다. 카드를 선택해 취소 버튼이 나타나도 화면 안에 유지하며 턴 종료와 취소의 44px 영역이 겹치지 않는다.
- 손패 영역이 상대의 덱/묘지 버튼을 덮지 않도록 PC/가로 손패를 중앙 열에 둔다. 많은 손패의 기존 가로 탐색은 유지한다. 상세창/로그 등 내부 스크롤은 유지한다.
- 가로 탐색이 브라우저 뒤로 가기/페이지 스크롤로 이어지지 않도록 대전 중에만 overscroll을 제한한다. 기존 수직으로 들어 올린 후 소환하는 드래그 판정은 변경하지 않았다.
- 전투 규칙·서버·DB·카드/스킨 데이터 변경 없음. main 병합 없음.

## 실행 검증

- 타입 검사/프런트 빌드 통과.
- `battle-viewport-browser.mjs`: 360×640,360×740,375×812,390×844,412×915,768×1024,844×390,740×360,1024×768,1280×720,1440×900,1920×1080. 기본/카드 선택 상태 모두 페이지 및 대전 영역 세로 초과 없음, 주요 영역 화면 안 배치, 선택 상태 필드 터치 크기 최소44px, 턴 종료/고유능력/취소 최소44px, 턴 종료-취소 비중첩 확인.
- `battle-viewport-input-browser.mjs`: 390×844/740×360/1440×900 실제 공용 컴포넌트+로컬 엔진에서 CDP 터치 소환, 주문 드래그 취소(상태 동일), 주문 드래그 후 대상 적용, 회전 후 상태 동일/챔피언 및 버튼 화면 안 복구 통과.
- `final-ten-sprites-browser.mjs`: 7해상도 반응/스킨/배치 회귀. 모바일390/PC1440의 실제 클릭 공격·소환·피해·회복·고유능력·각성·새 경기 초기화 통과.
- `arched-champions-browser.mjs`: 7해상도 프레임/체력/대상 공간 검사, 모바일390/PC1440의 실제 피해/고유능력/KO 및 파편 좌표·마스크, CLASSIC 표시 복구 통과.

이 검증은 실제 공용 대전 UI와 로컬 엔진을 사용한다. 실물 기기 성능, 온라인 두 계정 전체 경기, 모든 모드의 실제 네트워크 흐름 검증은 수행하지 않았다. 스프라이트 화면은 QA TEMPORARY 임시 이미지이고, 오래된 QA 카드 원화 URL은 사용할 수 없어 대체 표시가 포함된다. 최종 등록 원화의 외형 검증으로 주장하지 않는다.
