# FULL RETRO 승인 적용 및 흑구슬마스터 수정 — 2026-10-15

사용자가 전체 레트로 안(FULL RETRO)과 운영 배포를 명시적으로 승인했다. 최초 미리보기의 main/배포 금지 게이트는 이번 승인으로 해제됐다. 로그인·상점·보상·타워 진행·모바일 별도 WIP는 변경하지 않았다.

## 구현

- NeoDunggeunmo Pro 1.020 Regular를 자체 호스팅한다. 공식 웹폰트 소스 커밋 `1751c2981808869750c7df391c1d2b486e978f12`, SHA-256 `b6b28ef07a91a889587b3f2485ad77d3cd116456f8bfbc50a271cbe90b39535d`. 실제 폰트와 OFL 1.1 고지는 배포 산출물에 포함한다.
- 제목·버튼·이름·본문 모두 레트로 폰트를 사용한다. 합성 굵기/기울임은 금지하고 기존 메인 로고는 Oswald를 유지한다. 기존 한글/기호 폴백과 로고 폰트도 자체 호스팅해 외부 Google Fonts CSS 의존을 제거했다.
- 작은 카드 효과 8px, 확대 카드 효과 16px. 프레임에 맞게 줄이고 문장 자체 끝에 `....`을 붙여 가운데 정렬한다. 별도 점 요소/배경/오른쪽 여백은 없다. 키워드 정보와 상세정보 전체 원문은 유지한다.
- 실제 CardRenderer가 `FittedCardRules`를 사용한다. 카드별 ResizeObserver와 폰트 로딩 이벤트로 다시 계산하며, 운영에서는 미리보기의 전역 DOM 감시/포털 복사를 사용하지 않는다. QA의 보관 비교에는 컨텍스트로 기존 렌더링을 유지한다.
- 체력·코스트·공격력 숫자의 스타일 클래스는 변경하지 않았다. 승인된 FULL RETRO의 이전 측정값과 **10개 카드/전투 레이아웃**에서 폰트·값·크기·위치가 완전히 같다.

## 흑구슬마스터

- ID `b723c7e6-c668-4afb-b77d-da0d16f16c31`, 관리자 **v14**, 변경 시각 `2026-10-14T22:48:45.192Z`.
- 실제 최신 문구: **등장:상대 필드에 있는 선수 카드들 중 무작위로 한장을 파괴합니다.**
- 기존 관리자 세션으로 공식 프런트 프록시 `/api/admin/cards`에 GET만 수행했다. 직접 API 도메인은 클라우드에서 시간 초과였으나 프런트의 공식 API 프록시는 정상 응답했다. 로그인이나 운영 데이터 쓰기는 하지 않았다.
- 조회 목록은 166장이었고, 이번 변경에 필요한 카드 **1장만** 검증용으로 보관했다. 전체 166장 최신 효과 전수 검증을 의미하지 않는다. [스냅샷·출처·해시](../snapshots/20261015-black-orb/manifest.json).
- 카드 ID와 검토한 정확한 문구를 명시적으로 연결한다. 텍스트 런타임 분석기를 추가하지 않았다. 관리자가 향후 문구를 다시 바꾸면 자동 구현되지 않는다. 명시적 구조화 설정이 있으면 그 설정을 우선한다.
- 실제 손패 사용→소환→효과 처리에서 대상 선택 없이 적 선수 1장을 파괴한다. 묘지 이동/리타이어로 대체하지 않는다. 필드 토큰/미공개 대상도 포함하며 효과 소환/부활은 등장 효과를 실행하지 않는다. 무작위 선택은 기존 결정론적 RNG를 사용한다.
