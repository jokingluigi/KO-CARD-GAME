# 표정 등록·미리보기와 이미지 채우기 복구

- 등록용 선택 목록은 10개였으나 사건 재생 버튼은 기본·저체력이 빠지고 각성 전환이 들어간 9개였다. 이제 10개 표정의 등록 버튼을 항상 표시하며, 미리보기도 같은 10표정을 사용한다. 각성은 기존 별도 세트 설정/체크박스로 유지한다.
- 저체력 등록 버튼은 `frames.low`를 선택하며 미리보기는 체력을 5로 설정해 실제 공통 선택 로직을 사용한다. 회복 반응 종료 후에도 저체력으로 복귀한다.
- 이미지 맞춤에 전체 보이기(contain) / 여백 없이 채우기(cover)를 복구했다. 기존 `crop` 데이터를 표정·내/상대 위치별로 사용한다. 실제 프레임과 관리자 미리보기가 동일 설정을 따르며 고정 아치 마스크는 유지한다.
- 이전 `20261028-portrait-fit.md`의 contain 강제 및 cover 제거 설명은 이 수정으로 대체한다. 데이터 변환·업로드·게임 규칙 변경 없음.

검증: 타입 검사, 빌드, 표정/이벤트/스킨 단위 29개 통과. `sprite-editor-options-browser.mjs`에서 실제 편집기 컴포넌트의 등록/미리보기 버튼 각 10개, 저체력 슬롯 선택, cover/contain 변경 값과 미리보기 일치, 저체력 및 회복 후 복귀를 확인했다. `portrait-aperture-browser.mjs`는 모바일390×844/PC1440×900 양측 실제 대전 컴포넌트의 cover/contain 및 고정 마스크/확대/피격을 확인했다. 임시 이미지 구조 검증이며 실제 등록 원화의 외형 품질·실기기 성능 평가는 아니다.
