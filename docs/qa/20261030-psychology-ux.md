# 심리학 기반 사용자 기능·시각 개선 24항목 및 스프라이트 저장 복구

기존 기능을 조사해 재사용·보완했고, 실제 페이지와 공통 대전 컴포넌트에 연결했다. 게임 규칙·서버 판정·카드/챔피언 데이터·스킨 소유 정책·보상 처리는 변경하지 않았다. 별도 브랜치 `feat/final-sprite-reactions-review`에서 작업했다. main 병합·Production DB 변경 없음.

## 긴급 수정: 스프라이트 저장 타임아웃

확인한 클라이언트 결함은 업로드 완료 검증과 스프라이트 저장에 공통 `cosmeticsRequest`의 **8초** 제한이 적용되고, 파일 PUT은 **30초** 제한이었던 점이다. 서버는 새 이미지들을 저장 전에 다시 검증한다. 운영 서버의 해당 요청 로그·실제 지연 원인은 조회하지 않았으므로 모든 운영 실패가 같은 원인이라고 단정하지 않는다.

이전 커밋 `080d834`의 별도 로컬 체크아웃에서 검증 응답을 9.2초 늦추자 실제 관리자 화면에 `signal timed out`이 표시되고 설정 저장에 도달하지 못했다. 수정본의 같은 시나리오는 성공했다.

- 스프라이트 목록/업로드 준비/이미지 검증: 최대 60초. 파일 전송 및 설정 저장: 최대 120초. 다른 일반 꾸미기 조회의 8초 기본값은 유지한다.
- 준비 → 전송 → 검증 단계 표시. 설정 저장이 오래 걸리면 기다리는 상태를 명시한다.
- 저장 중 편집·중복 저장을 잠가 늦은 응답이 새 편집을 덮어쓰지 않도록 한다.
- 타임아웃/연결 오류로 결과가 불명확하면 GET으로 저장 내용을 비교한다. **실제 같은 설정이 확인된 경우에만** 완료로 표시한다. PATCH 자동 재전송 없음.
- 확인되지 않으면 편집을 유지하고 ‘저장 여부 다시 확인’을 제공한다. 서버 인증·이미지 검증·revision 충돌 검사는 변경하지 않는다.
- 모바일 관리자 도구 모음을 선택 2열 → 보조 동작 2열 → 저장 전체 너비로 정리해 좁은 버튼의 세로 줄바꿈을 방지했다.

## 사용 방법

- 대전 설정: 손패 읽기, 조작 안내, 턴 종료 확인, 줌/플래시/초상화 설정.
- 경기 로그: 카드 그림을 눌러 상세. 상대 비공개 정보는 조회 대상으로 추가하지 않았다.
- 덱: 나가기 전 저장 권장. 남은 임시 편집은 재진입 시 ‘임시 편집 복구’로 복원. 브라우저 저장소를 지우면 없어지며 기기 간 동기화되지 않는다.
- 스프라이트 관리자: PNG/WebP 5MB 이내 업로드 → 검증 완료 → 스프라이트 저장. 응답 지연 시 상태 안내를 보고 기다리고, 불확실하면 저장 여부 확인을 사용한다.

실제 모바일 기기, 실제 두 클라이언트 PvP/재접속·네트워크 저속 업로드, 운영 저장소 파일 검증 및 운영 보상 지급은 실행하지 않았다. 120초를 넘는 응답은 여전히 실패로 처리하며 저장 여부를 다시 확인해야 한다. SPA 브라우저 뒤로가기에는 확인창을 강제로 끼우지 않고 임시본 복구로 보호한다. 모든 카드의 고유한 사용 제한을 새 클라이언트 규칙으로 복제하지 않으며 최종 허용/거절은 기존 엔진·서버가 담당한다. 실제 사용자 테스트·효과 입증·실기기 성능 수치는 없다.
