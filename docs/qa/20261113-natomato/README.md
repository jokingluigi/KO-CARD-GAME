# 나토마토 집중 수정 및 검증 — 2026-11-13

## 확인한 원인과 수정

- 고유 능력의 GRANT_DODGE_ONCE가 선택 ID를 무시하고 전체 아군을 순회했다. 아군 선수 한 장의 필수 선택과 서버의 최대 한 장 적용으로 수정했다. 이미 능력을 받은 선수는 재선택 대상에서 제외한다.
- 준비 조건은 reason=DODGE를 찾았지만 실제 회피 피해 이벤트의 사유는 COMBAT/CARD_EFFECT였다. 전투 피해에도 실제 회피 소모 시 DODGE 태그를 기록하고 기존 준비 엔진에서 명시적인 태그를 판독한다. 전투 사유는 변경하지 않는다.
- 준비 목표 및 표시 분모를 8로 일치시켰다. 기존 대전의 능력 정의와 잘못된 다중 대상 선택 프레임도 사용 횟수·골드·체력을 초기화하지 않고 정규화한다.
- 기본 1골드, 자기 챔피언 피해 2, 선수마다 1회 부여, 추가 1골드 업그레이드/회복 3, 턴당 능력 사용 제한을 보존했다.
