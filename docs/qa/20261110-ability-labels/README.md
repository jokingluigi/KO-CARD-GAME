# 챔피언 고유 능력명 표시 제거

## 변경
- 관리자 기본·강화·게임 시작 능력의 이름 입력칸을 제거했습니다. 기본/강화 고유 능력은 비용과 효과를 편집합니다.
- 강화 능력의 기존 이름 유무는 런타임에서 능력 존재 여부에 사용됩니다. 기존 이름 값은 보존하고, 관리자에서는 이름 대신 ‘완료 후 강화 고유 능력 사용’ 체크박스로 제어합니다. 새 기본 능력의 내부 기본 이름은 ‘고유 능력’입니다.
- 관리자 목록·미리보기·능력 통계, 덱 편집, 컬렉션 상세, 전투 능력 설명, 준비 완료 알림, 능력 연출에서 개별 능력명 대신 공통 제목과 비용·효과를 표시합니다.
- 기존 DB/API 필드, 능력 ID·효과·비용·사용 횟수·타깃 규칙은 변경하지 않았습니다. 기존 데이터나 과거 전투 로그를 일괄 변환하지 않았습니다. 설명 본문에 작성된 문장은 그대로 유지합니다.

## 검증
- pnpm build: 전체 타입 검사 및 프로덕션 빌드 통과.
- 완료 효과 설명 관련 기존 단위 테스트 1개 통과.
- 실제 관리자 라우트/API를 일회용 PGlite DB에 연결한 Chromium 검증: 390×844, 844×390, 1440×900 통과. 이름 입력칸 제거, 기존 강화 사용 체크 상태, 미리보기에서 기존 능력명 미표시를 확인했습니다.
- 기존 능력명 및 강화 능력명, 효과 설정, 준비 조건이 실제 저장 후 보존되는 것을 확인했습니다. 저장 실패·중복 저장 방지와 모바일 미리보기 전환도 함께 검증했습니다.
- 플레이어 화면은 타입 검사/빌드 및 표시 코드 변경을 확인했습니다. 이번 작은 표시 변경에 대해 전체 PvP 실전 회귀를 별도로 실행하지는 않았습니다. 물리 모바일 기기 검증도 실행하지 않았습니다.

운영 배포 결과는 production-verification.json에 기록합니다. 운영 DB에 검증 데이터를 쓰지 않았으며 main에는 병합하지 않습니다.
