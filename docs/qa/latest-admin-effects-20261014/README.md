# 관리자 효과 구현·검증 중간 보고서 — 2026-10-14

**전수 완료가 아니다.** 이전 20261013 판정은 변경된 20261014 효과의 정상 판정을 대신하지 않는다. 초기 176개 및 배포 전 재확인에서 돌아온 2개를 포함한 카드·챔피언 178개 ID와 원문은 [coverage.csv](coverage.csv)에 기록했다. 목록은 전체 효과 및 예외·모드 교차 검증을 완료하지 않은 상태를 보수적으로 UNVERIFIED로 표시한다. 개별 성공 시나리오는 테스트 코드와 아래 실행 결과로 구분한다.

## 데이터

인증된 공식 관리자 API의 GET만으로 카드 165장(선수 144, 주문 21; 공개 85, 비공개 80), 챔피언 11명(공개 7, 비공개 3, 비활성 1), 토큰/챔피언 토큰 합집합 24장, 태그 18개와 타워 콘텐츠 설정을 확보했다. 토큰은 165장에 포함된다. 20261013 대비 카드 ID 38개 추가, 2개 삭제, 기존 레코드 65개 변경이다. 동명이인 벨모르트 선수 두 장은 서로 다른 ID로 검증했다.

[콘텐츠 전용 스냅샷과 해시](../snapshots/20261014-admin/manifest.json)는 13:01 UTC에 생성했다. 14:41 UTC 읽기 전용 재확인에서는 변경이 없었다. 이후 최종 재조회는 타임아웃되어 그 이후 최신 상태는 확인하지 못했다. 계정·구매·재화·보상·개인 덱·세션·인증정보는 스냅샷에 없다. 운영 콘텐츠 쓰기, main 푸시, 병합, 배포는 수행하지 않았다.

## 구현

65개 명시적 카드 ID/효과 원문 연결을 추가했다. 런타임 자연어 분석기를 추가하지 않았다. 관리자 텍스트만 바꾸면 구현이 자동 변경되지 않는다. 원문이 달라지면 이번 연결은 적용되지 않으며 새 명세 검토가 필요하다.

주요 수정은 실제 피해·파괴 이벤트 귀속, 벨모르트 챔피언 퀘스트와 강화 능력, 누적 아머, 등장 없는 효과 소환, 생성 무작위 풀/기존 영역 대상의 구분, 손패 추가 연쇄 처리, 이전 자기 턴 실제 회복 조건, 임시 체력 만료, 추가 선수 공격, 카드 복귀·공개 연출이다. 카드·챔피언 비용/능력치/희귀도 및 관리자 원문은 변경하지 않았다.

서버 시작 때 과거 카드·챔피언 콘텐츠를 재삽입하는 경로와 기존 챔피언 PATCH 시 삭제된 각성 카드를 재생성하는 경로를 제거했다. 명시적으로 새 각성 챔피언을 생성하는 기존 관리자 기능은 유지했다. 시작 스키마 설치에는 기존 기본 설정 행과 카드에서 태그를 수집하는 초기화가 남아 있으므로 모든 테이블에 대해 DDL만 실행한다고 주장하지 않는다.

챔피언 HP가 0이거나 게임이 종료되면 퀘스트 완료 화면·음악·완료 초상화 연출을 숨기고 진행 중인 퀘스트 연출도 취소한다. 실제 엔진 이벤트와 일반 전투/결과 연출은 유지한다.

### 사용자 확정 규칙

- 리온·영웅 탄생은 물리적 덱 맨 위가 주문이면 강화하지 않는다. 아래 선수까지 탐색하지 않는다.
- 선수 벨모르트의 파괴 감지 +2/+2는 필드에서만 발동한다. 두 ID의 손패·덱·묘지 비발동을 검사했다.
- 공격력 최솟값은 0이다. 네브라는 0에서 흡수하지 않으며, 5→2/자신 +3 규칙을 유지한다. 실제 감소/설정/강화와 임시 감소의 복원 수치도 0 기준으로 검사했다.
- 어셈블의 좀비 합체는 소환 시도로 계산하며 빈 슬롯을 채우기 위해 재추첨하지 않는다. 기존 고정 소환 시도 경로의 종료를 검사했다.
- 기본 턴 골드 최대 6이며 관리자 카드 비용 7 이상은 유지한다. 타워 보스의 명시적 덱은 비공개·토큰·고비용 카드를 허용하되 일반 보상 카드 풀은 유지한다.
