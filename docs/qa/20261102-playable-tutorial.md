# 실제 전투로 배우는 튜토리얼

2026-11-02 KST · `feat/home-battle-mode-art` · main 병합 없음.

## 사용 방법

홈 → 보상·상점·전체 메뉴 → 튜토리얼. 또는 `/tutorial`로 진입한다. 로그인은 필요하지만 보유 카드나 출전 덱은 필요하지 않다.

원하는 실습을 누르고 시작 설명을 읽은 뒤 **직접 해보기**를 누른다. 전장의 강조 표시와 중앙 조작 영역의 안내를 따라 실제 카드를 조작한다. **훈련 안내**에서 자세한 설명, 이번 실습 다시 시작, 실습 목록·나가기를 사용할 수 있다. 완료하면 다음 사용 가능한 실습으로 이동한다. 기존 8단계 텍스트 설명은 실습 목록의 **규칙 설명 보기** 및 기존 경기 설정에서 유지한다. **내 덱 준비하기**는 기존 덱 편집기로 연결한다.

## 구현한 여섯 실습

| 과정 | 완료를 확인하는 실제 행동/결과 |
|---|---|
| 첫 소환과 승리 | 멀리건 확정 → 1골드 선수 소환 → 다음 자기 턴 → 상대 챔피언 체력 0과 승리 |
| 선수끼리의 전투 | 첫 공격과 반격 → 턴 종료 → 재공격으로 양측 체력 0 및 리타이어 |
| 러쉬로 즉시 공격 | 러쉬 선수 소환 → 같은 턴에 챔피언 공격. KO의 러쉬는 선수·챔피언 모두 공격 가능 |
| 주문과 대상 선택 | 실제 확정 전 선택 취소 → 카드·골드 유지 → 다시 선택해 비용 지불과 기절 적용 |
| 액티브는 총 한 번 | 이전 턴부터 있던 선수의 실제 액티브 사용. 사용 후 및 다음 턴 재사용 불가 |
| 고유능력과 퀘스트 | 고유능력 비용 지불 → 실제 퀘스트 완료·강화 |

현재 공개 목록으로는 초보 모험가, 도적, 밀쳐내기, 그레이트 챤, 챔피언 여울이 선택된다. 개발용 이전 스냅샷과 현재 운영의 공개 목록을 각각 검사했다. 이름·이미지로 효과를 추측하거나 카드별 경로를 하드코딩하지 않는다. 실제 정의의 비용·공격력·체력·키워드·능력 구조를 검사해 이해한 실습에 맞는 카드를 선택한다. 필요한 카드가 미공개되거나 효과 구조가 달라지면 해당 실습을 비활성화하고 이유를 표시한다. 다른 효과를 임의로 꾸며 대체하지 않는다.

## 판정과 데이터 보호

기존 `Home`의 실제 경기 입력 처리, `GameStatePreview`, 소환·공격·표정·타격·퀘스트 연출과 전투 엔진을 재사용했다. 튜토리얼용으로 시작 위치만 준비한다. 기본 실습은 1골드와 공격 한 번으로 승리 가능한 상대 체력을 사용한다. 심화는 6골드의 중간 턴 상황, 이미 필드에 있던 선수 등을 제공한다. 퀘스트 실습은 마지막 비용 지불로 완료되도록 시작 진행도를 설정하고 이를 설명창에 명시한다. 이러한 상태는 실제 대전의 시작 조건이나 정상 덱 구성 예제가 아니다.

이후 카드 사용·골드 지불·타겟팅·공격·리타이어·퀘스트·승패는 기존 판정 그대로 처리한다. 전투 규칙과 원본 카드·챔피언 데이터는 변경하지 않았다. 연습 상대는 실제 END_TURN으로 행동권을 넘기고 공격하지 않는다. 제한 시간은 연습에서만 끈다. 실습과 다른 확정 행동은 안내하고 막는다. 단순 카드 선택이나 다음 설명 클릭을 완료로 세지 않는다.

AI 보상·퀘스트 제출 경로로 진입하지 않으며 계정 덱·재화·전적·보유 카드에 쓰지 않는다. 완료 표시만 계정별 브라우저 localStorage에 저장한다. 목록 이탈·건너뛰기는 완료로 세지 않는다. 새 실습은 이전 선택·타겟팅·애니메이션·취소 상태를 초기화한다. 새로고침은 실습 목록으로 돌아오며 완료 표시는 유지된다. 진행 중 전장 상태의 서버 저장·다른 기기 간 동기화는 제공하지 않는다.

## UI와 심리학 적용

- 한 단계에 한 행동을 안내하고 실습에 관계없는 턴 종료를 비활성화해 인지 부하와 조작 실수를 줄인다.
- 목표와 해당 전장 영역을 연결하는 대비/윤곽선을 사용하고 기존 대상 선택 강조를 유지한다.
- 취소 때 비용을 보존하고 확정 결과로 진행을 갱신해 행동 통제감과 인과관계를 전달한다.
- 전체 과정은 순서대로 권장하되 원하는 실습 선택·다시 시작·이탈을 지원한다. 실전 승리를 반복 강제하거나 보상을 걸지 않는다.
- 모바일에서는 기존 좁은 HUD 안내 레일 대신 실습 전용 중앙 안내 행을 사용한다. 이 조정은 튜토리얼에만 적용한다. 실제 경기의 배치와 조작은 유지한다.

이는 설계 적용 내역이며 초보 사용자 대상 학습 효과를 입증한 연구 결과는 아니다.

## 실제 검증

- 타입 검사 및 프런트 운영 빌드 통과.
- 관련 회귀 60개 통과. 여기에는 실습 엔진 8개가 포함된다. 현재 운영 API의 공개 카드 데이터를 별도로 읽어 같은 실습 엔진 8개도 통과했다. 중복 집합이므로 합산하지 않는다.
- 현재 운영 공개 데이터와 실제 이미지 파일을 격리된 HTTP 응답으로 공급해 실제 `/tutorial` 경로를 실행했다. 390×844, 740×360, 1440×900에서 여섯 실습을 모두 실제 UI 조작으로 완료했다. 전장 상태를 QA 전용 이벤트로 주입하지 않았다.
- 실제 터치 이벤트 드래그(Chromium CDP), 마우스 드래그, 화면 회전 후 소환, 전장 스크롤 없음, 완료 저장/새로고침, 새 실습 초기화 통과.
- 320×568에서 HTTP 실패→재시도, 이미지 실패 상태의 실제 소환, 타겟 크기, 실습 재시작/미완료 이탈 확인. 빈 공개 목록은 실습 차단 및 기존 규칙 설명 접근 가능. 12초 지연은 오류 안내 후 재시도하며 늦은 응답이 화면을 덮지 않음.
- 홈에서 새 튜토리얼 진입, 기존 8장 설명의 키보드 포커스·ESC·액티브/턴 횟수 안내를 4개 화면 크기에서 검사했다.
- 기존 실제 AI 경로(모바일/PC)의 덱 편집·저장→빠른 대전 자동 진입·취소→AI 경기 진입 및 읽기 설정 유지 통과. 덱 없음·잘못된 덱에서 임의 대체로 시작하지 않음.

## 한계 및 미검증

물리 모바일 기기·Safari는 미검증이다. 실제 신규 유저를 대상으로 학습 시간·오조작률·이해도를 측정하지 않았다. 모든 챔피언의 개별 퀘스트, 모든 키워드·상태·카드 효과를 체험시키는 백과형 심화 과정까지 구현한 것은 아니다. 현 과정은 기본 전투와 핵심 특수 행동을 배우는 범위다. PvP 경기 자체와 계정 보상 처리에는 변경이 없으며 이번 검증에서 운영 계정으로 양측 PvP를 진행하지 않았다.
