# 최신 밸런스 및 피니셔 선택지 연출 적용

브랜치: `feat/balance-content-20261111`. 운영 카탈로그는 인증된 관리자 GET으로만 확인했다. Production DB 수동 수정·카드 임의 공개·main 병합 없음. 배포 결과는 별도 운영 검증 기록에 남긴다.

## 확인 범위

최신 관리자 카드 195장·챔피언 12장을 전부 변환하고 원본 수치·텍스트·태그·공개 상태를 대조했다. 2026-10-30 관리자 자료와 비교해 신규 32장, 기존 변경 53장(수치·태그 포함), 신규 또는 효과 텍스트 변경 대상 43장을 확인했다. 개별 정의와 처리 내용은 [전체 감사 자료](catalog-audit.json)에 있다. 운영에 테스트 카드를 추가하지 않았다.

## 구현

- 신규 피니셔·선수 효과 및 변경 텍스트를 실제 공통 전투 엔진에 연결했다. 업그레이드, 생성/소환, 능력 교체·후속 효과, 태그 조건, 랜덤 분배, 부활, 덱 이동을 기존 시스템으로 처리한다.
- 핀폴은 실제 피해로 체력이 정확히 0이 된 뒤 실제 리타이어한 경우에만 한 번 처리한다. 초과 피해·파괴·피해 0은 제외한다.
- 판도라의 복수 대상 선택은 서버에 선택 목록을 저장하고 확인 후 해결한다. 흉내내기는 서로 다른 후보 3장에서 하나를 선택하며, 선택·재접속·중복 요청·상대 대기 표시를 지원한다.
- 블랙마카롱의 ‘따까리’ 표기는 사용자 확인에 따라 실제 ‘로마니 마피아 신입’ 카드에 연결했다.
- 엘리트 호출은 용병 소환 부분을 엘리트로 교체한다. 다른 능력은 기존 효과에 엘리트 소환을 추가하는 해석을 적용했다. 동일 능력을 이미 사용한 턴의 사용 횟수는 초기화하지 않는다.
- 프로젝트 P 주문은 기존 필드 전체 기절·침묵 후 실제 선수 ‘프로젝트 P(폭주)’를 소환한다. 폭주의 등장·턴 종료 효과는 자신을 제외하고 침묵시킨다. 기존 챔피언 토큰 침묵 면역은 유지한다.
- 소환 직후 피해로 죽은 합체 카드가 사용 전 손패로 되돌아가 AI가 같은 행동을 반복하던 오류를 수정했다.
- 준비 진행 UI는 실제 누적 횟수와 현재 영역 카드 수를 표시한다.

## 선택지별 각성 연출

기존 `BATTLE_SPRITE` 설정에 `finishers[선택지 ID]`를 확장했다. DB 스키마나 별도 에셋 저장 시스템은 만들지 않았다.

각 선택지에 `music`, `portrait`, `sprite`를 독립 저장한다. 기본 외형과 각 스킨은 각각 자신의 설정을 가진다. 선택한 스킨의 선택지 세트가 없으면 같은 스킨의 공통 설정을 유지하며 다른 스킨의 스프라이트를 가져오지 않는다. 음악은 스킨 전용 설정 → 챔피언 공통 선택지 설정 → 기존 완료 음악 순서다.

각성 후 저체력일 때도 현재 각성 세트의 기본 표정을 유지한다. 피격 등 순간 반응과 승패는 그대로 작동하고 종료 후 각성 기본으로 돌아온다. 각성 전 저체력 표현과 체력 판정은 유지한다.

선택지 ID는 실제 `selectedFinisherId`를 사용하므로 재접속과 상대 화면에서도 같은 세트가 복구된다. 기존 전환 지연·타이머·이미지 미리 불러오기를 재사용한다.

## 관리자 사용법

1. 챔피언 관리에서 피니셔 선택지를 저장한다.
2. **스프라이트 관리**에서 챔피언과 기본 외형/스킨을 고른다.
3. **편집할 피니셔 연출**에서 해당 선택지를 고른다.
4. 선택지 음악(MP3·OGG·WAV, 20MB 이하), 각성 프로필(PNG·WebP, 5MB 이하), 각성 스프라이트 기본 및 선택 표정을 등록한다.
5. 기존 액자 미리보기에서 크기·위치·반전 등을 조정하고 **스프라이트 저장**을 누른다.

선택지 전용 세트는 기본 한 장만 있어도 된다. 미등록 항목은 공통 설정을 사용한다. 해제 버튼은 해당 선택지 설정만 제거한다. 저장 충돌은 409로 차단하고, 새 이미지의 검증과 등록된 BGM 확인을 서버에서 수행한다. 사용 중인 선택지 음악의 삭제도 막는다. 변경은 새 대전에 반영된다.

## 실행한 검증

- 최신 변경 카드 실제 사용, 195개 정의의 원본 데이터 보존, 챔피언 12종 실제 능력 사용, 핀폴 경계값·연쇄·소환·부활·업그레이드·선택지 이미지/음악·스킨 분리·저체력 각성·기존 스프라이트/취소 처리·PvP 저장 및 재접속: **209/209 통과**.
- 최신 195장·12종 기준 공통 엔진 AI 대전 **100/100 종료**. 불법 행동·상태 불변성 오류·중복 인스턴스·시간 초과 없음. 실제 기록: [AI 보고서](ai-100.md). AI 실행 후 미니언 A·퍼플레인에 각성 이미지가 등록되어 표시 자료만 다시 받았다. 해당 실행 당시 챔피언 자료는 `ai-tested-champions.json`에 보관하며, 이후 능력·준비 조건 변경은 없었다.
- 실제 온라인 대전 페이지 두 개와 실제 PvP 서비스·격리 DB로 모바일 세로 390×844, 가로 844×390, PC 1440×900에서 선택/확인, 상대 대기, 재접속, 저체력 각성 세트의 양측 표시를 확인했다. [결과](branch-battle/results.json).
- 실제 관리자 API와 격리 DB로 선택지 설정·크기·음악 저장/재진입, 미등록 자산 차단, 충돌 차단, 참조 음악 삭제 차단을 확인했다. 모바일 관리자에서 크기를 수정·저장·재진입했다.
- 전체 타입 검사 및 전체 빌드 성공. 기존 Rollup 튜토리얼 재수출 순환 청크 경고는 남아 있다.

## 한계와 남은 문제

전체 과거 회귀 검사는 전부 성공한 상태가 아니다. 수정 전에도 13건 실패가 재현됐다. 이전 규칙을 기대하는 수치/아머/덱 복귀/헬퍼 문구 검사, 별도 HTTP 서버를 요구하는 검사 및 이전부터 실패한 독립 QA 스크립트가 포함된다. 확장 실행에서 발생한 추가 취소 검사 1건은 수정 후 최종 209개 검사에서 통과했다. [비교 기록](regression-summary.json).

화면 검증은 실제 대전 UI와 실제 서버 로직을 사용했지만 격리된 상태/연결 및 임시 이미지를 사용했다. 선택지 완료 상태 복구 검사는 완료된 스냅샷을 DB에 준비한 후 양측 재접속으로 확인했다. 새 운영 스토리지에 파일을 올리는 실험은 하지 않았다. 실제 선택지별 원화·음악을 등록한 뒤 최종 크롭·음량·외형 검수가 필요하다. 별도 물리 휴대폰·외부 두 사용자 네트워크 환경이나 모든 모드의 수동 전체 경기를 실행했다고 주장하지 않는다.
