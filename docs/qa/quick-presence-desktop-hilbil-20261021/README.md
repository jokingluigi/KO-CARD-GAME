# 빠른 대전 표시등 · PC 손패 · 힐빌/위마리

기준 main `3f457ac`. 브랜치 `fix/quick-presence-desktop-hilbil`.

## 수정

- 사이트 접속 표시등을 큰 제목에서 **빠른 대전** 카드 제목 옆으로 이동했다. 기존 인증 WebSocket, 다른 계정만 계산, 중복 탭 제외, 빨강/초록/회색 처리는 유지한다. 새 DB 조회나 타이머는 없다.
- PC의 고정 220px 손패 받침보다 카드 행이 커져 윗부분이 잘렸다. 받침이 콘텐츠 높이를 수용하도록 바꾸고 선택/호버 상승 여백을 확보했다. 769~1100px 가로 화면의 기존 transform과 Tailwind translate/scale 중복도 제거했다. 카드 자체 크기와 비율은 줄이지 않았다. 모바일 기존 규칙은 변경하지 않았다.
- **일반 위마리**가 힐빌의 공격 후 체력 증가 효과를 처리할 때, 이미 치명 피해를 입은 상대의 리타이어가 먼저 확정되어 처치 원인이 끊겼다. 공격 후 아군 콤보 리스너에 원래 공격의 원인 정보를 전달하여 실제 공격자에게만 처치 보상이 돌아가도록 고쳤다. 효과 문구·수치·처리 순서는 유지한다.
- 카드 163개·챔피언 11개 관리자 데이터를 2026-10-21 13:25 UTC에 재확인했다. 기존 20261021 스냅샷과 해시가 같았다. 운영 데이터 저장/마이그레이션은 없다.

## 검증

- 공통 엔진 **2,710개 통과, 실패 0**. 기존 과거 카탈로그 전용 4개 스위트는 러너의 원래 제외 정책을 유지하며 통과 수에 포함하지 않았다.
- 힐빌 집중 검사: 수정 전 **15개 중 3개 실패** → 수정 후 **15개 전부 통과**. 일반 위마리를 손패에서 실제 사용한 뒤 공격, 최대 체력 4/20, 비치명 공격, 두 힐빌 중 실제 처치자만 회복, 기존 회복/재생 조합을 포함한다. [수정 전](hilbil-before.log) · [수정 후](hilbil-after.log).

- 실제 빌드 UI + 격리 PGlite/HTTP/WebSocket: 표시등의 새 위치, 타 계정 접속/종료, 중복 탭, 재접속, 실패 시 회색, 30초 AI 전환부터 실제 전투·결과·AI 보상 처리까지 통과.
