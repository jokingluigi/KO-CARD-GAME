# 관리자 전체 개편 제안 — 아직 구현한 범위가 아님

현재 AdminLayout에는 메뉴 검색, 즐겨찾기, 최근 사용, 경로 표시, 모바일 메뉴 포커스 처리, 미저장 이동 방지가 있다. AdminEditorSections에는 키보드로 이동할 수 있는 편집 탭도 있다. 이런 기능은 재사용하면서 개별 작업 화면을 통일하는 것이 우선이다.

확인한 문제:

- 카드·챔피언·태그의 목록, 선택, 편집, 저장 흐름이 서로 다르다.
- 카드·챔피언의 많은 설정이 모달 편집기에 들어가고, 탭과 미리보기·파일 업로드가 좁은 영역을 함께 사용한다.
- admin-console.css에 10~12px 보조 글씨가 많고 일부 편집 버튼의 최소 높이는 38px이다. 모바일 작업에 더 넉넉한 글자와 터치 영역이 필요하다.

권장 공통 규격:

1. 넓은 PC: 목록 / 편집 / 미리보기. 중간 너비에서는 미리보기를 접을 수 있는 2열. 현재 선택과 검색·필터 유지.
2. 모바일: 목록 → 전체 화면 편집 → 목록 복귀. 편집 내 ‘기본 / 효과 / 이미지·연출 / 공개’ 구획과 고정 저장 바. 중첩 모달과 중첩 스크롤 최소화.
3. 미리보기는 실제 게임과 같은 카드·챔피언·액자 컴포넌트. PC/모바일 전환과 변경 전후 비교.
4. 미저장 / 파일 업로드 중 / 서버 저장 중 / 저장 완료 / 저장 실패를 구분해서 표시. 오류는 해당 필드로 이동. 현재 버전 충돌 검증 유지.
5. 목록 공통 검색·필터·선택·일괄 작업. 공개/초안/비활성은 색상과 글자로 함께 표시. 연결된 토큰·스킨·스프라이트로 이동하고 돌아와도 현재 항목 유지.
6. 본문 14~16px, 모바일 입력 16px, 주요 터치 영역 44px 이상. 고급 JSON은 기본 작업에서 접고 필요한 사람만 펼치기.
7. 테두리·칸을 줄이고 8/16/24px 간격을 통일. 금색은 주요 행동/선택 상태에 집중. 운영/초안 상태와 위험한 조작의 의미를 일관되게 유지.

착수 순서: 카드·챔피언 편집기 → 이미지/스프라이트 편집 → 나머지 운영 화면. 이번 배포는 카드 목록과 태그 관리 개선까지만 포함하며, 전체 관리자 개편을 완료했다고 보고하지 않는다.
