# 심리학 기반 시각 피드백 16항목 통합 점검·보완

별도 기능 브랜치 `feat/final-sprite-reactions-review`에서 실제 공통 대전 컴포넌트, 덱 편집, 컬렉션, 결과 화면을 수정했다. 이미 구현된 체력 잔상·타격·소환·스프라이트·대사·각성은 재사용했다. 이번에 16개를 모두 새로 제작했다는 뜻은 아니다. 규칙·판정·원본 데이터·보상·서버 인증 변경 및 main 병합 없음.

## 16개 적용 내역

|항목|이번 처리|설계 근거|
|---|---|---|
|1 행동 가능 카드|기존 엔진의 `getLegalActions`에서 실제 플레이 가능한 손패 ID를 사용해 강조한다. 부족 골드뿐 아니라 필드 포화/사용 조건도 반영한다. 사용 불가 일러스트는 기존 40% 불투명·완전 회색 대신 68%·부분 채도로 읽을 수 있게 한다.|시각적 위계, 탐색 부담 감소. 최종 허용 여부는 기존 엔진이 결정한다.|
|2 선택 카드 집중|선택 카드 윤곽·들어 올림을 유지하고 나머지 손패만 대비를 낮춘다. 크기·슬롯·입력 영역은 변경하지 않는다.|전경/배경 구분, 통제감.|
|3 공격 연결|기존 돌진·접촉 VFX를 유지하고 조준선 끝에 실제 대상 접촉점을 표시한다. 마우스 이동 외에 터치 pointerdown·키보드 포커스도 연결하며 회전·스크롤·포커스 이탈 시 오래된 선을 정리한다.|연속성, 예측 가능성.|
|4 체력 잔상|기존 액자의 실제 체력 즉시 갱신과 짧은 손실 트랙을 유지한다. 새로운 체력 숫자/가짜 피해는 추가하지 않았다.|변화 인지.|
|5 골드 소비|실제 CARD_COST/CHAMPION_ABILITY_COST 사건에만 골드 셀을 짧게 강조한다. 턴 종료 초기화를 소비처럼 초상화로 보내던 기존 연출을 수정했다. 카드 출처가 명시되면 그 카드를, 없으면 유일한 같은 처리 사건만 연결한다. 다중 카드가 모호하면 임의 카드에 연결하지 않는다.|인과관계, 피드백의 신뢰성.|
|6 턴 전환|기존 확정 새 턴의 필드·자원·손패 순차 강조에 턴 종료 버튼을 연결했다. 마지막 강조가 잘리지 않게 채널 종료 시간을 보정했다. 마운트/재접속에는 재생하지 않는다.|주의 전환.|
|7 소환의 무게|기존 코스트·레어도별 준비/착지/외부 VFX·SFX 경로를 재사용한다. 이번에 별도 소환 큐를 추가하지 않았다.|기대감, 강약 대비.|
|8 피해·방어|기존 실제 피해/ARMOR/BLOCK 및 면역 구분을 유지·회귀 검사했다. 아이콘·게임 판정은 그대로다.|결과 이해, 감각 통합.|
|9 챔피언 연결|기존 사건별 반응과 스킨/각성 세트의 움직임을 유지·회귀 검사했다.|캐릭터 존재감.|
|10 각성 대비|기존 퀘스트 완료의 주요 연출·세트 전환을 유지한다. 작은 퀘스트 진행은 새 국소 강조로 분리해 큰 사건과 경쟁하지 않게 했다.|지각적 대비.|
|11 화자 구분|기존 초상화 앵커의 챔피언 대사와 별도 진영 선수 대사 경로를 재사용한다. 대사 데이터는 변경하지 않았다.|근접성, 출처 인지.|
|12 퀘스트 진행|실제 진행 사건과 진행량 증가가 모두 확인된 경우에만 해당 진영 퀘스트 영역을 강조한다. 완료는 기존 각성에 맡기고 진행 강조를 중복하지 않는다. 임박 상태의 지속 점멸은 추가하지 않았다.|진행 인지, 피로 관리.|
|13 결과 마무리|결과 제목 → 지급 확정 보상 → 다음 행동에 0/100/180ms의 짧은 등장 차이를 준다. pending/error 보상을 획득처럼 강조하지 않는다. 버튼은 지연 잠금하지 않는다. 앱/OS 모션 감소를 따른다.|절정과 마무리, 통제감.|
|14 덱 편집|추가/제거가 성공한 편성 행에 서로 다른 짧은 피드백을 표시한다. 기존 이동 연출·임시 보관·저장 완료 구분은 재사용하고 저장 버튼 aria-busy를 연결했다. 장식 복제에서 DOM id/테스트 식별자를 제거해 원본과 중복되지 않게 했다.|인과관계, 실수 방지.|
|15 컬렉션 복귀|상세 닫기 후 동일 카드로 포커스를 복원하고 짧게 위치를 표시한다. 화면 밖일 때만 가까운 위치로 스크롤한다. 기존 필터/정렬/스크롤 복귀를 재사용한다.|공간 기억, 탐색 부담 감소.|
|16 모바일 절제|전장/카드/HUD 크기와 레이아웃을 보존하고 국소 윤곽·색 대비 중심으로 보완했다. 효과가 입력이나 게임 busy 상태를 늘리지 않는다.|주의 분산과 조작 오류 예방.|

심리학은 설계 가설이다. 실제 유저 만족도·탐색 시간·오조작 감소·반복 피로 개선을 입증한 것은 아니다.

## 공통 구현

- `player-ux/attention-policy.ts`: 확정 사건에서 읽기 전용 강조 계획 및 명확한 지출 카드 출처를 추출한다.
- `player-ux/battle-attention.tsx`: 실제 대전 HUD에만 짧은 국소 강조를 적용한다. 요소별 기존 애니메이션을 취소·교체하며 대기열/입력 잠금이 없다. 재대전·종료·언마운트에 정리한다. 레이아웃·transform·네트워크를 변경하지 않는다.
- 기존 `BattleResourceFeedback`, `BattleTurnHandoff`, `AttackAim`, 카드/체력/챔피언/각성 연출과 통합했다.
- 이번 신규 오디오/그림 에셋 없음. 기존 라이선스 관리된 외부 효과와 원본 일러스트를 변경하지 않는다.

## 실제 검증

- TypeScript·프로덕션 빌드 성공.
- 단위/회귀 **118개 통과**: 확정 소비와 턴 초기화 구분, 모호한 다중 출처, 퀘스트 실제 증가, 재대전/종료/재접속 재생 방지, 기존 VFX·스프라이트 사건/우선순위/움직임/스킨·각성·카메라·설정.
- 신규 `visual-attention-browser.mjs`: **360×740, 375×812, 390×844, 412×915, 740×360, 768×1024, 1440×900**. 실제 공통 대전 화면과 로컬 엔진에서 손패 선택 → 슬롯 소환 → 실제 골드 소비 → HUD 피드백 → 공격 대상 조준선 → 취소. 상태/좌표/애니메이션 정리/스크롤 없음/페이지 오류 없음 검사.
- 기존 `battle-viewport-input-browser.mjs`: 390×844/740×360/1440×900 터치 소환·주문 드래그·취소·대상 선택·회전 상태 유지 통과.
- 기존 `psychology-ux-browser.mjs`: 같은 3크기에서 부족 골드 설명·설정·손패 읽기·선택 취소·실제 공격 및 로그 상세 통과.
- `visual-attention-deck-browser.mjs`: 390×844/1440×900 추가/제거 행 피드백·실제 수량 변화·임시 복구·이탈 보호·저장 1회·계정 분리 검사 통과. 검사 중 기존 장식 복제 식별자 중복을 발견해 수정했다.
- `visual-attention-collection-browser.mjs`: 390×844/1440×900 상세 닫기 후 동일 카드 포커스 복귀, 검색/정렬, 제작 수량, 스킨 비교, 팩 개봉과 한 번의 요청 통과.
- 기존 `player-battle-tools-browser.mjs`: 390×844/1440×900 실제 로컬 승패 확정 → 결과/다음 행동/기록/PNG 저장 통과.

서버 응답과 인증은 브라우저 안에서 격리 모의했다. 전투는 실제 앱의 공통 대전 컴포넌트와 로컬 엔진이며 정적 목업이 아니다. 운영 DB/덱/계정/보상을 테스트로 변경하지 않았다.

## 남은 검증

실제 모바일 기기/GPU 프레임 수치, 라이브 양측 PvP/재접속, 모든 개별 모드의 종단 흐름, 운영 저장/보상, 원본 스프라이트를 모두 등록한 외형 검증, 실제 사용자 비교 테스트는 이번에 수행하지 않았다. 공통 UI 적용과 단위 회귀 통과가 모든 운영 모드 테스트 통과를 뜻하지 않는다. 신규 레이아웃/규칙/카드 데이터 변경 없음.
