# 출전 덱 진입 복구·덱 변경 버튼·보유 이모티콘

## 실제 변경

홈·대전 모드의 출전 덱 배너에서 `덱 변경`을 정보 아래에서 독립된 옆 영역으로 옮겼다. 고정 높이 배너 안에서 이름·챔피언·구성·준비 문구 뒤에 버튼을 쌓아 버튼이 잘리던 구조가 원인이다. 터치 영역은 최소 44×44px. 그림과 덱 정보는 유지한다. 긴 화면에서는 기존 챔피언 포스터 배치를 유지한다.

AI 진입 시 모든 저장 덱 대신 서버가 보유한 현재 출전 덱만 읽는다. 서버 덱 검증은 덱마다 반복했던 카탈로그/소유권 조회를 묶었다. 격리 DB에서 40개 덱을 검증할 때 해당 검증 조회는 총 5회임을 측정했다(덱 목록 자체 조회 제외). 운영 응답 속도를 측정한 수치는 아니다. 기존 덱 유효성·소유권·복사 제한은 그대로다.

실패한 덱 조회를 빈 덱 목록으로 취급하고 오류가 2.5초 뒤 사라지던 AI 준비 처리를 수정했다. 이제 오류를 유지하고 `다시 시도`에서 데이터를 새로 읽는다. 덱 GET은 네트워크/시간 초과/5xx에 한 번만 자동 재시도한다. 수동 재시도·화면 이탈 시 요청을 정리한다. 인증 거부·잘못된 응답은 자동 재시도하지 않는다. 선택 POST·저장·매치 생성은 자동 반복하지 않는다. 전체 AI 준비는 30초 안에 복구 UI를 제공한다. 출전 선택 기록은 바꾸지 않는다.

빠른 대전·친선전도 같은 덱 읽기를 써서 영향을 받을 수 있었다. 두 화면에도 취소 가능한 조회와 수동 재시도를 연결했다. 드래프트는 저장 출전 덱을 읽지 않아 이 실패 경로와 별개다.

이모티콘은 장착 슬롯 대신 활성화된 보유 목록 전체에서 사용한다. 꾸미기 화면의 이모티콘 장착 UI를 제거하고, 실제 대전의 ☺ 버튼에 보유 목록·검색·조회 실패 재시도·상대 이미지 숨기기를 연결했다. 기본 지급 이모티콘도 바로 포함한다. 팝업은 화면 크기 변경 때 위치를 갱신한다. 기존 스킨/카드 뒷면 장착 및 과거 이모티콘 장착 기록은 삭제하지 않는다.

PvP·드래프트는 아이템 ID를 받아 현재 소유권·활성 상태·유형·이미지를 서버에서 확인한다. 클라이언트의 임의 이미지 URL은 사용하지 않는다. 미보유/비활성/다른 유형은 전송하지 않는다. 800ms 제한과 중복 요청 방지는 유지하며 대전 상태·RNG·턴·버전은 변경하지 않는다. 기존 슬롯 패킷도 소유권 확인을 거쳐 지원한다. AI는 동일 보유 선택 UI에서 로컬 표시한다.

인지 부하 감소: 실패를 ‘덱 없음’으로 표시하지 않고 구별한다. 행동 통제감: 선택 기록을 보존하며 명시적인 재시도를 제공한다. 시각적 위계·피츠의 법칙: 덱 변경을 정보와 분리하고 44px 영역을 확보한다. 이모티콘은 불필요한 사전 장착 단계를 없앤다. 사용자 만족도 실험은 수행하지 않았다.

## 실행한 검증

- 수정 전 Chromium 재현: 선택된 덱이 있는데 12.5초 지연 시 시간 초과, 재시도 버튼 0개, 오류 자동 소멸 후 ‘출전 덱 없음’ 표시. 운영 로그 분석이 아닌 동일 프런트 경로의 통제된 재현이다.
- 덱 GET 단위 검사 4개: 재시도, 유한 실패, 인증 거부, 취소·잘못된 응답.
- 기존 DB/HTTP 덱 유효성·소유권·EPIC/복사 제한 회귀 17개 통과.
- 실제 격리 PGlite/Express/업로드/꾸미기/팩/WS 회귀 26개 통과. 새 검사는 40개 덱 조회 수, 선택 덱 사용자 격리·삭제·인증, 미장착 보유 이모티콘 양측 WS 전달·미보유 차단·위조 이미지 무시를 포함한다.
- 실제 격리 드래프트 HTTP 회귀 18개 통과. 미장착 이모티콘 ID 사용, 중복·잘못된 패킷·비참가자 차단, 전투 버전·heartbeat 불변 포함.
- 실제 브라우저 390×844·1440×900: 격리 HTTP/DB/WS로 두 대전 클라이언트를 연결, 4개를 넘는 보유 목록과 검색, 미장착 이모티콘 양쪽 표시, 비보유 상대 목록 제외, 기본 지급 즉시 사용, 장착 기록 불변 확인. 844×390 회전 후 팝업 화면 안 배치 확인.
- 실제 드래프트 양측 브라우저: 선택 스킨/카드 뒷면 유지, 이미지 이모티콘 양방향 전달, 재진입과 모바일 너비 확인.
- 기존 홈→덱 편집/저장/출전 지정→빠른 대전 대기·취소→AI 전투 진입 브라우저 흐름 통과.
- Chromium 390×844·1440×900: 12.5초 지연 자동 재시도 및 503 실패 후 수동 복구→VS/실제 전투 UI 진입, 선택 덱 유지·시작 1회, 로컬 AI 보유 이모티콘 표시 확인. 빠른 대전 큐/친선전 방 생성 재시도와 중복 시작 없음, 드래프트 진입 시 저장 덱 조회 없음 확인. API·WS 응답을 통제한 실제 UI/엔진 검사다.
- 홈/대전 모드 360×640·390×844·412×915·844×390·1440×900에서 버튼 전체가 배너 안에 있고 실제 터치 위치가 맞으며 출전 선택창이 열림을 확인. 360×640에서 미선택·유효하지 않은 덱의 모든 버튼도 확인했다.
- API·프런트 타입 검사와 운영 빌드 통과.

브라우저는 실제 애플리케이션 UI/엔진을 사용한다. 덱 장애 검사는 통제된 API 지연/실패와 WS 응답을 사용하고, 꾸미기 검사는 격리된 실제 DB/HTTP/WS를 사용했다. 보라색/파란색 사각 그림은 업로드·소유권 검증용 임시 이미지다. 운영 계정·운영 아이템·운영 소유권에 테스트 쓰기는 하지 않았다. 실제 사용자 네트워크/계정의 지연 원인, 물리 모바일 기기·Safari, 운영 상대와의 전체 경기는 미검증이다. 자동 로그인 문제의 해결 결과를 이 검사로 주장하지 않는다.
