# 홈 밀도·대전 모드 통합과 편의성/접근성 14항목

브랜치 `feat/home-battle-mode-art`에서 실제 앱을 수정했다. 기존 반응/효과/로그/연결 처리와 공통 설정을 재사용했다. 아래 표는 새 구현과 기존 기능의 검증·보완을 구분한다. 메타크리틱의 공식 UI 채점표나 점수 상승을 입증한 결과는 아니다.

## 사용자 지적 원인과 수정

**상단 대전에 AI·드래프트 없음:** 홈 버튼만 모드 선택 모달을 열고 상단 대전 탭 `/online`은 온라인 전용 페이지를 열던 경로 분리였다. 홈 버튼과 상단 탭을 모두 실제 `/online` 공통 모드 화면으로 연결했다. 빠른 대전·친선전·AI·드래프트 네 선택을 표시한다. 기존 빠른/친선/AI/드래프트 진입 경로와 선택된 출전 덱 흐름을 유지했다. 드래프트 조회 실패/이용 불가도 항목 자체는 남기고 비활성 이유와 조회 재시도를 보여준다.

**타이틀이 비고 덱 선택 버튼 잘림:** 큰 빈 KO 대체 영역과 반복되는 덱 미선택 설명을 제거하고 출전 덱 고르기 버튼을 명확히 표시했다. 충분한 높이에서는 홈 대전 버튼 아래 빠른 대전·AI·드래프트 바로 시작을 제공한다. 짧은 화면에서는 통합 모드 버튼으로 진입하며 세 바로가기를 접는다. 대표 배경과 관리자가 등록할 메뉴 일러스트는 유지한다. 최종 일러스트가 등록된 것처럼 임시 그림을 제품에 넣지 않았다.

**예전 광역 스타일의 간섭:** 레거시 홈의 모든 section에 패딩/하단 여백을 붙이는 규칙이 새 대전 영역까지 늘려 작은 가로 화면에서 메뉴를 밀어냈다. 해당 규칙에서 새 영역을 제외했다. 대전 모드 카드에도 이전 패널 내부 여백 규칙이 적용돼 간격이 커져 적용 범위를 분리했다. 특정 화면을 임시로 축소해 감춘 방식이 아니다. 340px 이하의 극히 짧은 가로 화면에서는 보조 테스트 계정 배지를 시각적으로 접고 접근 가능한 계정 설명과 잔액 표시는 유지한다.

## 14항목 적용표

| 항목 | 이번 적용과 재사용 범위 |
|---|---|
| 1 대상 선택 집중 | 기존 실제 유효 대상 기반 마스크·취소·리사이즈 추적을 재사용/검증. 고대비 옵션에서 유효 대상 윤곽을 점선으로 구분. |
| 2 드래그/터치 | 기존 단일 제스처 소유·원본 카드 숨김·유효 슬롯/취소 복귀를 유지. 실제 소환·긴 누름·blur/턴 변경/무효화 취소 회귀 확인. |
| 3 행동 불가 이유 | 기존 골드/턴/필드/대상/조건 이유와 카드 옆 피드백 재사용. 안내의 줄 간격과 구분선을 강화. |
| 4 정보와 전투 입력 분리 | 기존 정보 버튼/드래그 구별 유지. 손패 카드가 유효한 효과 대상일 때도 정보 버튼을 숨기고 탭 순서에서 제외해 대상 선택을 가로채지 않도록 보완. |
| 5 변화 강조 | 숫자 span을 실제 변환 가능한 inline-block으로 수정하고 증가/감소 순간의 짧은 명암 강조를 추가. 체력·골드·퀘스트의 기존 확정 이벤트 강조 재사용. 중간 수치를 만들지 않음. |
| 6 글자 크기 | 공통 설정에 카드 설명·대사 각각 100/115/130% 추가. 상세창·손패 읽기·카드 검사·챔피언 능력/퀘스트 설명·로그에 적용. 카드/필드 크기를 바꾸지 않음. |
| 7 색 외 구분 | 선택 이중선·대상 점선 옵션. 기존 상태 아이콘/의미/대상 판정 변경 없음. |
| 8 연출 접근성 | 기존 흔들림/줌/플래시/초상화/모션 감소 설정 재사용. 글자 설정을 바꾼 뒤 연출 설정을 바꿔도 이전 값으로 덮이지 않도록 현재 공통 설정을 읽고 구독하도록 수정. 모달의 큰 좌우/상하 슬라이드 대신 기존 짧은 페이드/확대만 사용해 입장 중 잘림을 줄임. |
| 9 무음 플레이 | 새로운 확정 사건 안내: 턴·양측 챔피언 피해·실제 회복·능력·퀘스트·공개 소환/퇴장·승패. 명령 안내 영역과 별도 polite 읽기 영역에 전달. 한 메시지/한 타이머로 처리하고 대기열 없음. 과거 이벤트·새 대전·피해 0·최대 체력 증가를 새 피해/회복처럼 읽지 않음. 숨은 상대 드로우 이름을 전달하지 않음. |
| 10 최근 기록 | 기존 최신순 12묶음/전체 기록·펼치기·공개 카드 상세 연결 재사용. 로그 읽기 글자 크기 설정 추가. |
| 11 턴 종료 보조 | 기존 남은 공격/능력 확인과 긴급 시간/설정 예외 유지. 남은 행동이 있으면 종료 버튼 이중 하단선과 접근 가능한 설명을 추가. |
| 12 퀘스트 원인 | 기존 확정 진행 이벤트 강조 재사용. 무음 안내에 실제 소유자와 현재 진행/목표 수치를 전달. 완료는 사소한 소환보다 우선. |
| 13 결과 정리 | 실제 지급 보상과 다음 행동을 먼저 읽도록 보조 상세 결과 버튼을 DOM 뒤로 이동. 기존 접힌 요약/오류 재시도/지급 확인 유지. 키보드 순환 검사를 새 순서에 맞춤. |
| 14 연결 복구 | 기존 전송 중/재연결/서버 스냅샷 대기·중복 전송 방지를 재사용. 확인 지연→읽기 전용 재동기화, 한 입력 한 변경, 오래된 버전/과거 소환 오디오 억제 회귀 확인. 네트워크/판정 규칙 수정 없음. |

## 설정 사용

홈 **음량 설정 → 화면 · 접근성**, 대전 **설정 → 읽기 · 접근성**에서 조절한다. 설정은 기존 전투 연출 설정과 함께 이 기기에 저장된다. 글자 확대가 필드 카드 크기나 히트박스를 변경하지 않는다. 부족한 공간에서는 설명창 안에서 스크롤할 수 있다.

## 직접 실행한 검증

- 프런트 타입 검사와 production 빌드 통과. Vite의 기존 tooltip sourcemap 진단은 비차단 경고였으며 빌드는 성공했다.
- 편의성·대상 영역·확정 사건·음량/모션/글자 설정 파싱·공개 기록·연결 복구 관련 **43개 자동 검사 통과**. 신규 사건 안내는 실제 피해 0/양수, 실제 회복/최대 체력 변화, 결과/퀘스트 우선, 과거 재생/다른 대전, 상대 숨은 드로우 비노출을 검사했다.
- 홈 일반 계정 **12해상도**, 테스트 계정 **12해상도**에서 주요 버튼 44px 이상·겹침 없음·페이지 스크롤 없음·회전 후 배치·공지/닉네임/음량/설치 안내 확인. 일반 계정 검사는 최종 테스트 계정 배지 변경 전 실행했으며 해당 배지는 일반 계정에 렌더링되지 않는다.
- 실제 컬렉션 → 상단 대전 탭 → 공통 대전 화면을 360×740, 390×844, 740×360, 1440×900에서 확인. 360/390 세로 화면은 네 버튼 전체가 화면 안에 표시됨. 드래프트 503/재시도/이용 불가, 친선 진입 경로 확인.
- 실제 `/` → 덱 편집/선택/저장 → 빠른 대전 자동 진입/취소 → 홈 대전 버튼 → AI 준비/전투 경로를 390×844·1440×900에서 실행. 홈 글자 설정이 재진입과 AI 설정/손패 읽기에 유지됨, 연출 옵션 변경 시 글자 설정 유지, 읽기 본문 20.8px(130%) 측정, 카드 폭 변화 1px 미만 확인. HTTP/WS는 모의했다. 미선택/무효 덱으로 대전이 시작되지 않음 확인.
- 실제 공통 전투 컴포넌트+실제 엔진 fixture에서 **6해상도** 공격 예측/카드 옆 이유/공격 확정/묶음 로그/설정 미리보기와 무음 변경 확인. 추가로 공격 드래그·효과 대상 마스크/취소·실제 회복과 회복 안내 확인.
- 드래그 실제 소환, 긴 누름과 충돌 없음, 보조 포인터 취소 무시, 화면 이탈/턴 변경/합법성 변경 시 취소 회귀 통과.
- 연결 확인 지연 시 재동기화, 단일 변경 요청, 입력 전송 중 표시, 과거 오디오 억제·새 소환 한 번·오래된 버전 무시·새 매치 초기화 확인. 전송 경계는 모의했다.
- 결과 컴포넌트에서 실제 엔진 결정타 기반 **7해상도 승/패**와 확정 보상·보상 대기·오류 재시도·키보드 순환 확인. 운영 재화는 변경하지 않았다.
- 기존 관리자 메뉴 그림 업로드/저장/재진입/홈 반영/사용 중 삭제 보호 회귀 통과. 업로드와 저장 API는 로컬 응답 대역을 사용했다.

## 미검증과 한계

물리적 Android/iOS·저사양 GPU FPS/메모리·실제 화면 읽기 프로그램·색각/저시력 사용자의 체감·오조작 감소율·실제 사용자 PvP·드래프트 전체 런은 이번에 검증하지 않았다. 사용자 만족도나 메타크리틱 점수 상승을 입증했다고 주장하지 않는다. 운영 계정/덱/보상·카드/챔피언 원본·게임 규칙·서버 판정 변경과 main 병합 없음.
