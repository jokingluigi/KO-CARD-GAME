# 강한 카드 등장에 대한 놀람 유지 시간

상대 레전더리·챔피언 토큰·6코스트 이상 선수/주문·준비 완료 반응에 최소 **2,000ms** 유지 시간을 연결했다. 기존 스킨에 900ms가 저장돼 있어도 이 전투 반응은 2초 유지한다. 별도로 2초보다 긴 시간이 설정돼 있으면 그 값을 유지한다. 자신의 레전더리 퇴장 등 다른 놀람 사건의 설정값은 그대로다.

놀람 몸짓은 360→**600ms**로 조정했다. 시작 움찔은 빠르게 유지하고 뒤로 물러난 자세를 더 오래 보인 뒤 복귀한다. 표정 유지와 몸짓 시간을 분리해 2초 내내 흔들지 않는다. 게임 판정·입력·네트워크는 이 시간을 기다리지 않는다.

기존 반응 우선순위를 유지한다. 강한 피격·각성·승패가 놀람을 덮을 수 있으며, 낮은 반응은 유지 중인 놀람을 지우지 않는다. 중복 사건 방지·스킨 선택·저체력 복귀도 유지한다.

검증:

- 표정 사건·몸짓 검사 **62개 통과**. 실제 강한 카드 소환 사건에 2초 하한이 포함되는지, 짧은 스킨 설정/더 긴 설정/중요 반응 우선권을 확인했다.
- 실제 공통 대전 컴포넌트와 실제 `PLAY_WRESTLER`로 확인했다. 모바일 390×844, PC 1440×900, 모바일 움직임 감소에서 1.3초 후에도 놀람을 유지했고, 약 **2,066 / 2,072 / 2,079ms**에 종료됐다. 종료 뒤 저체력으로 복귀하고, 유지 도중 실제 6피해가 오면 강한 피격으로 즉시 바뀌었다.
- [브라우저 측정](20261104-longer-surprise/results.json). 검증에는 명시적으로 표시한 임시 표정 이미지를 사용했다. 실물 휴대폰·운영 계정 검증으로 보고하지 않는다.
- 전체 타입 검사와 프론트엔드 빌드 통과. cosmetics 공통 라이브러리 빌드가 Node 전용 테스트 파일을 포함하던 구성을 분리했으며, 해당 확률 검사 **8개도 별도 실행해 통과**했다.

변경: `champion-sprite-motion.ts`, `champion-sprite-events.ts`, `champion-battle-actor.tsx`, 공유 `battle-sprite.ts`, 관련 검사 및 `lib/cosmetics/tsconfig.json`. 카드·전투 규칙과 서버 판정 변경 없음. 프론트엔드 배포 결과는 같은 디렉터리의 수신증에 기록한다.
