# Combat game feel — 진행 중

전체 프로젝트는 미완료다. 현재 변경은 공통 공격 접촉 동기화 단계만 포함한다.

기존 AttackAnimation은 접촉 시 onImpact(기본 타격음/피해표시)를 호출하지만 화면 충격, 저음 레이어, 입자와 충격파는 release(히트스톱 이후)에 시작했다. 이들을 동일 impact 콜백/impacted 상태로 옮겼다. 피격 반동과 공격 복귀는 기존 release 시점을 유지한다. 0 피해는 기존 BLOCK, 화면 충격 NONE 정책을 유지한다. 숨김 탭에서는 새 화면 충격/저음 재생을 생략한다.

실제 재사용 음원: public/sfx/summon-bass-heavy.wav, summon-bass-massive.wav. 신규 사운드 제작 없음. 기존 SFX 볼륨/중복 제한 경로 유지.

검증: presentation/audio 관련 기존 테스트45개 통과, 전체 타입검사/빌드 통과. 이것만으로 청각적 동기화나 체감 개선을 입증하지 않는다. 브라우저 최초 실행은 PORT/BASE_PATH 누락으로 실패해 명시적으로 설정 후 재실행했다.

남은 작업: 실제 카드 공격력 분포 기반 강도 재튜닝, 오디오 접촉 시차 측정, 모바일4종/태블릿 프레임시간 측정, 신규 사운드 필요성/라이선스 검토, 소환/특수효과/각성/KO/보상과 비전투 피드백의 종합 개선, 실제 게임모드 회귀 검증 및 시청각 비교 영상. 운영 배포/DB 변경/main 병합 없음.

브라우저 검증: 기존 테스트가 충격파를 release 이후에만 허용하여 첫 실행 실패. 새 요구사항대로 히트스톱 중 접촉 충격파가 나타나야 한다는 검사로 변경했다. 공격/피격 동시 정지, 반동, resize 복구, Animation API 실패 복구, 콜백1회 검증 재실행 통과(390×844/1440×900). 실제 오디오 출력 지연 측정은 미실시.

## 2차: 공격 강약과 오디오 순서

`combat-impact-profile.ts`에 표시 전용 타이밍을 분리했다. 실제 피해 0/1–2/3–5/6–9/10+ 및 확정 결정타에 각각 0/35/60/90/125/140ms 정지를 적용한다. 전체 길이는 430/480/520/580/640/760ms다. 공격력은 준비 시간에만 최대15ms를 더하며, 아머로 감소한 피해를 과장하지 않는다. 서버 타이머는 변경하지 않는다. 화면이 넓어도 준비 동작이 지나치게 커지지 않도록 역방향 이동을20px로 제한했다.

20261024 관리자 스냅샷의 선수 기본 공격력 분포: 0=20, 1=33, 2=44, 3=31, 4=10, 5=3, 6=1. 이는 토큰/공개 상태 등을 별도 제한하지 않은 정의 데이터이며 실제 경기 피해 분포는 아니다. 6+는 성장/버프를 포함한 강한 타격으로 남겨둔다.

기본 타격음 `playAttack()`이 기존 추가 음원을 정리하므로 새 저음을 먼저 재생하면 즉시 중단되는 문제도 수정했다. 기본 타격 콜백 이후 저음을 재생한다. 결정타 우선순위는 유지하여 낮은 우선순위의 추가 음원을 억제한다. 새 음원 제작/청취 평가/실제 출력 지연 측정은 아직 수행하지 않았다.

자동 테스트39개 통과, 전체 빌드 통과. 실제 WAAPI 브라우저 검사는 360×740, 375×812, 390×844, 412×915, 768×1024, 1440×900에서 공격·차단·결정타, 공동 정지, 복구, 콜백1회를 검사한다. 테스트가 고정 전체 길이를 가정하던 부분은 실제 Animation 타이밍을 읽도록 수정했다. 이는 독립 연출 fixture 검사이며 PvP/AI/드래프트/타워 전체 플레이 회귀 통과를 의미하지 않는다.

오디오 호출 순서 포함 브라우저 재실행도 6개 화면 크기 모두 통과했다. 기본 타격음 후 저음이 시작되고 이후 즉시 pause되지 않는지 실제 HTMLMediaElement 호출을 추적했다. 녹화는 `qa-results/fighting/videos/impact-{width}x{height}.webm`에 저장했다. 해당 영상은 카드 원화가 없는 개발용 연출 fixture이며 실제 게임 전체 화면 비교 영상이 아니다. 녹화 도구 다운로드403 후 이미 설치된 시스템 FFmpeg로 실행했다. 브라우저 호출 시각과 스피커 출력 시각은 구분해야 한다.
