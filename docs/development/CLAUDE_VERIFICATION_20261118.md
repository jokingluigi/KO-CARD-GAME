## 결정 및 후속 작업

1. 신규 설치 확인 절차에 `pnpm run typecheck:libs` 선행 실행을 반영했다.
2. draft 바운스 복원 실패는 Codex가 조사 담당이다. 아직 수정하지 않았으며, 실패 재현·기준 커밋 확인 후 수정 여부와 범위를 결정한다. Claude는 같은 파일을 동시에 수정하지 않는다.
3. Claude에게 필요한 추가 인계: 실행 명령, 실패 테스트 전체 이름, assertion의 expected/actual 및 스택, mock 옵션을 추가한 정확한 명령. 코드 변경 없이 보고서로 전달한다. DB 데이터 관련 실패도 테스트 이름과 필요한 fixture를 구분한다.
4. 다음 기능 작업의 담당 경로는 아직 배정하지 않았다. 두 환경이 같은 커밋을 읽을 수 있다는 사실이 자동 동기화나 코드 충돌 방지를 보장하지 않는다. 다음 작업 전에 공동 작업 안내의 경로 분담·커밋 인계 절차를 따른다.
